## 1. 研究问题和前提

利用报告、未报告及观测条件核验候选目标真实性，输出采纳、未知、拒绝。核心仍是观测条件与多源证据，联合依赖目前没有有效性证据。

用户允许核验器在未受攻击的接收车上运行，使用自身点云和未融合检测。可信不等于感知无误或处处可见。其他来源受控数量和身份未知，不假设多数诚实，在线不输入k。当前实验不含自然误检与正常错误关联到假目标；GT未匹配不补假。声明攻击范围内的经验统计判断不构成任意串谋保证。

保留远端目标采用能力是用户明确要求，不能把研究缩成只采用本车已检测到的目标。

[MATE论文与代码核对](REALLY/MATE自车可信假设_论文与代码核对_2026-11-17.md)确认，其默认方案不要求可信自车，而是信任计算中心并估计所有感知来源的信任；允许高先验，另有自身位置目标的强PSM例外。本项目的可信本地优先属于前提与判决变化，和MATE比较时须单独控制这一因素，不能归为多车依赖收益。

## 2. 已实现的计算

当前判决原型为LocalCond，即可信本地证据优先，普通本地未决时再用条件反证和消息统计。下文是已实现规则。分组tauC校准是后续已运行但未完整保留的候选，C/F共同采纳保留为未实施备选，当前不优先推进。

### 输入与窗口

输入为共同前端在当前融合前形成的预测候选、各来源消息和公开观测条件，以及固定可信接收车自己的点云和未融合车辆检测。查询不使用GT位置，在线不读真假标签、攻击数量或身份。远端观测条件是消息与公开几何形成的代理，不升级为可信物理真值。

每来源先满足基本输入与观测资格，再记录新鲜关联报告U=1、有效未报U=0，否则U=-1。缺包、无有效条件不补0，历史coast不算新支持。每个候选使用当前及最多9个过去扫描，不用未来帧。新生或无因果查询暂为未知，索引/时间不连续或来源集合变化会重启窗口。

### 四个计算量

| 量 | 实际计算与含义 |
| --- | --- |
| 本地支持I | 新鲜本车车辆框与候选参考框的BEV IoU。要求中心3米内、类别相容、正重叠和双向唯一关联。无相容检测使I不可用，不能直接判假。 |
| 本地反证F | 0.25米体素中被实际射线采样穿越且未被终点占据的体积，占候选参考框体积的比例。未覆盖仍留在分母，终点占据优先。它是几何反证分数，不是完整空闲空间证书。 |
| 条件反证R | 最近窗口所有有效U=0事件的负对数未报概率相加。当前按来源和时间直接累加，没有额外依赖修正。 |
| 消息采纳分数C | 冻结Count模型对五项窗口计数特征计算的线性logit分数。没有新增正报告条件评分，不是来源诚实概率。 |

参考框中心和yaw来自预测查询，尺寸由clean fit接收车新鲜车辆框的逐轴加权中位数固定。远端自报尺寸不能改变I/F参考形体。

令p_D,it为真实目标、正常来源条件下新鲜报告事件的预测概率。冻结D模型在正常真实目标记录上，以U为监督，使用距离、相对方位的sin/cos、FOV边界裕量、候选位置不确定性，以及由预测框形成的遮挡代理和缺失标记拟合。当前复用既有模型，未重新训练。

\[
R_t=-\sum_{\tau\in W_t}\sum_{i:U_{i\tau}=0}\log(1-p_{D,i\tau}).
\]

p_D高而未报时反证大。实现将概率截断到[10^{-6},1-10^{-6}]避免数值发散。R是正常条件下的异常强度，不是目标为假的后验概率。未知事件不参与该和。

Count输入z为窗口报告事件数n_plus、有效未报事件数n_minus、窗口扫描数w、出现过有效事件的不同来源数d、出现过新鲜报告的不同来源数m。模型使用原拟合资料的标准化和真假监督逻辑回归参数：

\[
C_t=b+\beta^\top[(z_t-\mu)/s].
\]

真假监督来自正常真实候选和预先构造的假候选。这部分仍依赖声明攻击族的监督覆盖，没有独立估计任意攻击者行为分布，也没有建立统一的真假联合后验。

### 按顺序执行三态判决

1. 公共输入故障、新生或无因果查询，输出未知。本地支持与反证同时达到门限也输出冲突未知。
2. 有效F严格超过tauF，拒绝。
3. 有效I达到tauP，且存在相容输出及身份关联，采纳。单个可信本车支持允许直接采纳；支持成立但输出或身份不相容时保留未知，不能再被远端分支覆盖。
4. 只有普通本地未知进入消息分支。窗口中至少两个来源有有效事件、至少一个有效未报，且R严格超过tauR时拒绝。
5. 尚未拒绝且窗口内至少两个不同来源出现过新鲜报告，当前输出和身份相容，C达到tauC时采纳。这里的两个来源可以在不同扫描报告，是当前程序的资格条件，不是诚实数量保证，也不是两车报告即可判真的理论。
6. 其余未知。单个远端来源且无本地支持时，当前消息分支不能采纳。

C/R单独数值失败只停用相应消息分支，不否定已有合法本地证据。没有报告、回波不足、F为0均不能直接推出目标真实或虚假。

### 参数来源及校准

I/F各自先按2%原始错误预算校准，随后按实际互斥本地决定扣除整体5%的真假剩余预算。先由正常cal确定消息拒绝门限tauR，再利用明确假侧cal及正常cal确定tauC。假侧总体和声明攻击层均检查，真实采用尽量保留。缺失假层或没有可行采纳区时关闭对应采纳，不能填零风险。预算是经验工作要求，不是部署概率保证。

原run_002的mixed LocalCond为tauF=0.440568、tauP=0.282122、tauR=12.961173、tauC=-0.465607。后续分组候选只将同一配置tauC提高到1.010394，其余保持；该候选没有满足全部替换条件，不将新门限写成已经合格。数值只适用于绑定的数据、模型与校准版本。

当前没有把本地I/F、条件R和消息C合成为一个真实性概率，也没有启用Joint或长时来源信誉递推。当前输出是回放中的目标三态决定，未将该结果反馈到完整MATE系统并验证其系统效果。

## 4. 远端风险修正的结果与当前边界

mixed的40个误采时刻来自两个实体，全部由本地证据未达门限后的message_support产生。同时该分支贡献13.90个百分点真实采纳，关闭会使TA从64.47%降到50.57%，与用户要求不符。

cal平均约束允许少数父持续误采。mixed/F1_only一父F1/k2为11/44即25%，平均后恰为层5%；反向一父F2/k2为6/44即13.64%。
