更新日期 2026-11-16。当前主线收敛为**固定基础判决上的条件反证核验模块**。保留观测条件、多车依赖与十扫描窗口，撤下二近父参考区域作为主判决。

[完整判决设计](REALLY_MAYBE/条件反证补充核验_判决层收敛设计_2026-11-16.md)已明确公式、参数来源、追加误拒预算、三态和故障处理，并完成[独立初审及书面复审](REALLY/条件反证补充核验_集合性质与设计审核_2026-11-16.md)。当前认可的是定义可实施与作用方向，不是净效果已经成立。本轮没有实现、重拟合或运行新效果实验。

## 1. 问题与范围

利用各车报告、未报及观测条件核验候选目标真实性，输出采纳、未知、拒绝。来源数及受控数量、身份未知，不假设多数诚实，不默认本车可信。正常误检和正常错误关联到假目标不在当前范围，正常漏报仍在。GT 未匹配不补假。

此次方法贡献限于相同校准误拒预算下，条件反证能否增加有效拒假，以及多车依赖是否超过同边际独立处理。它不能单独解决任意串谋，也不承诺恢复基础方法所有错误拒绝。研究仍是目标真实性核验，不重建完整 MATE、驾驶系统或研究点二。

## 2. 固定的基础判决

使用已有 Count 三态模型作为 Base。它是基于 `(n_plus,n_minus,w,d,m)` 的有监督评分及原校准门限，不是两源支持硬确认。模型、尺度、门限、窗口和资格均冻结，基础拒绝不删除。模型文件来自 `docs/evidence/rq1_report_freeze_2026_11_13/run_001/models` 及 `calibration`。

选择 Count 是依据已查看开发资料作出的设计选择。它已有较低假采纳和较多假未知，便于评价新增反证是否有实际价值，不代表已经证明其适用于任意攻击。

采纳仍继承原真假监督与声明攻击域的经验校准，不由“正常模型没有拒绝”直接产生。未知受控数量的设置保留，缺校准的攻击层继续标记，不伪装成总体安全保证。

## 3. 单车条件与联合分布

上一中央轨迹先预测形成预查询，再关联当前消息。U=1 为新鲜支持，U=0 为有合法新扫描机会却无新鲜支持，其余未知。缺包、FOV 外或基础条件不可用不补 0，coast 不算新支持，同源同扫描不重复计数。

单源正常报告概率 p_D 由距离、方位 sin/cos、FOV 余量、预测不确定性和九射线潜在阻挡 C 得到，只用 clean 正常真实样本学习。C 是代理，不是遮挡真值。C 缺失带显式指示，GT 和回波不进入在线计算。不使用报告残差更新 Z 质量状态，前端仍保留合法历史。

C>0 且主阻挡 ID 相同者成组，分组先于当前 U。组内使用独立与共单调 Bernoulli 混合，组间在模型中独立，保持同一个 p_D 边际。rho 只由 clean 折外当帧损失从 `{0,.25,.5,.75,.9}` 选择，不能搬旧 HMM 参数。

每次从最近十个合法扫描重算，不累加上次总分，不将十帧视为十次独立观测。完整事件定义、缺失和生命周期规则沿用共同前端。

## 4. 新增反证怎么算

令 P 为当前报告来源，M 为当前有效未报来源，新反证为

`R = -sum_t log Q_t(M中的来源全部未报 | P中的来源全部报告)`。

实际按同一联合分布计算

`R = sum_t(log q_plus - log q_all) = B_minus + C_pm >= 0`。

q_plus 将未报来源边缘化，q_all 为完整报告组合。未知始终边缘化；空未报集合贡献 0。使用有限单源概率、rho<1和对数域计算，不分别修改两个事件概率。

它衡量已有这些报告时，其他有机会来源的未报在正常模型下有多反常。报告来源通过条件概率和共同组参与计算。完全独立组中的新增正报告会在分子分母抵消，不靠报告数量直接冲淡已有反证。

两个 p=.7 的同组来源，在 rho=.5 时，共同未报反证由独立的 2.408 降为 1.635；一报一未报的条件反证由 1.204 升为 1.897。前者减少共同沉默的重复影响，后者增强分裂信息。这是指定模型的作用，不是实测效果。

R 是正常条件异常评分，不是真实性概率或直接有效的 p 值。新增拒绝不再要求输入接近 F1/F2 参考区域。

## 5. 门限与真实代价

只在 clean cal 上选择新增反证门限。原真类父、query epoch、时刻均衡权重保持，合计为 1，不能在可新增拒绝子集中重归一化。

若基础真实误拒为 e_B，新增预算为

`delta_add = min(.02, max(0,.05-e_B))`。

选满足新增真实误拒质量不超过 delta_add 的最小正观测门限，严格 `R>tau` 才新增拒绝。候选仅来自 Base 正常可判读且非拒绝、有合法拒绝资格、反证计算有效的 clean 记录。无正候选、预算耗尽或必要模型/校准不可用时关闭新增模块并记录原因。

已保存结果显示，mixed 的 Count cal 真拒为 4.3476%，新增预算只有 0.6524 个百分点；两个族迁移方案各可用 2 个百分点。该核对未重算新评分。

这是校准集内经验约束，不是新录制风险保证。R 的学习只用正常记录，但整体方法继承真假训练的 Base，其剩余预算也依赖 Base，不能称整体完全独立于假族。

## 6. 完整三态与失败处理

1. Base 已拒绝，保持拒绝。
2. Base 因公共数据或数值故障未知，保持故障未知。
3. 新模块未启用、不可用或当前计算失败，保持 Base 并记录 degraded 或关闭原因。
4. 其余正常采纳/未知，满足原拒绝资格且 R>tau 时改为拒绝。
5. 其余保持 Base。

原拒绝资格为至少两个有效来源且有未报；采纳资格为至少两个不同来源有新鲜支持、当前存在身份相容的可输出轨迹。单有效源和无预查询新生仍为未知，没有额外可信初始化。

失败与降级留在统计分母，不当作方法成功。新判决不反馈到查询、关联、轨迹或来源信誉，因此各方法保持共同输入。

## 7. 能确定什么，如何判断研究是否成立

相对于同一 Base，采纳集合只会缩小、拒绝集合只会扩大。因此假采纳不增加、假拒绝不减少；真实采纳可能下降、真实误拒可能增加。若新增假拒绝为 f、真实采纳损失为 a，CD 变化为 `(f-a)/2`，不能保证为正。

主要比较为 Base、Base加独立条件反证、Base加联合条件反证，另保留明确公式的组平均对照。后两种概率方法使用相同 p_D、共同预算和校准算法。条件版须超过 Base，联合版须进一步超过独立和组平均，不能只凭集合性质认领贡献。

全体保留真假六格、每族/k、父录制、实体、首窗和配对时效。总真拒及各评价假层误采纳不超过 5%，真采纳损失不超过 2 个百分点，CD 增量至少 1 个百分点等预声明门槛见[完整设计第9节](REALLY_MAYBE/条件反证补充核验_判决层收敛设计_2026-11-16.md)。校准预算相同不等于实际误拒率相同，需完整报告。
