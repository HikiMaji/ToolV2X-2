对候选目标X，利用各车的报告、未报和观测条件，考虑多源依赖与近期历史，输出采纳、未知、拒绝。核心研究问题是同样的信息和决策政策下，联合建模是否比只用单车条件更有效。

来源数、受控数量和身份未知，不假设多数诚实。当前不纳入正常误检或正常错误关联到虚假目标的案例，不重新盘点该事实。GT未匹配不能当假目标。研究不扩展为完整MATE信誉系统、驾驶系统或研究点二。

假监督来自明确注入的F1/F2目标，真实监督来自clean真实query。假侧不是已识别的任意攻击分布；新的分数及sigmoid不是部署时目标真实性概率。不存在仅凭这些消息保证识别任意串谋的主张。

## 2. 实际输入与事件

上一中央轨迹先预测到当前，形成预查询，再匹配本帧消息。所有非空预测框进入几何，不按输出或GT筛选。每源U为fresh支持1、存在有效新扫描机会但未fresh支持0，或未知。缺包、FOV外及机会不明不补0，coast不算新支持。

自车按实际来源计一次，没有默认绝对可信本车传感器。暂不增加占据图。没有新的距离裁剪或人为远距离统一权重，条件作用通过概率模型进入。

## 3. 正常条件表征

各头共用最近10个同步扫描的窗口，当前约1秒。D用直接条件logistic报告概率；T使用两状态输入驱动报告模型且来源独立。状态的离线代理是GT框内零回波或至少一个回波，不是物理消失状态。

I/J/G/Q共享完整联合过滤所得单源边际。共同组内为独立与共单调Bernoulli混合，rho从clean父录制折外完整窗口预测损失选择。当前2至7源，最多128个状态精确计算。每步先用当前条件预测报告概率，再用当前报告更新状态。

normal和rho仅用clean拟合。训练评分头时外层留一父，rho在剩余父内部再留一父，不读取被留父；cal/eval复用原六父normal模型。D也使用同一10扫描窗口，不能把D胜出解释为只看单帧更好。

## 4. 单车证据强度与总分

对来源i，在窗口内定义

`L_i+ = sum_(U=1) log p_it`

`L_i- = sum_(U=0) log(1-p_it)`

`e_i = a_plus*L_i+ + a_minus*L_i- + b_plus*n_i+`

其中a_plus、a_minus非负，b_plus自由，不设额外未报常数项。未报直接项非正，正常条件下本应易报告的未报具有更强反证。正报告项与报告次数共同决定其贡献，不能预先称每次报告必为正证据。

基础总分有7个系数

`S_I = b0 + sum_i e_i + c_w*w + c_d*d + c_m*m`

w为窗口扫描数，d为窗口内有过有效事件的来源数，m为有过fresh支持的来源数。全局项单列，不能冒充某车证据。

正常联合修正`Delta_T`为窗口内正常联合log概率减单源边际log概率之和。固定I参数后，仅拟合一个增量系数

`S_J = S_I + c*Delta_T`

它可正可负，正报告和未报都进入联合概率。G把每帧同组的前三项表征取平均再累计；Q加一个S_I平方增量，检验同容量非线性是否足以解释收益。D、T也拟合同样的7系数头。旧Q_F、epsilon及攻击者数量先验均不参与本版评分。

## 5. 参数与真假监督

26个fit攻击尝试的父、来源、k、seed、位置规则和持续时段已在看新分数前冻结。18次完成、8次不可构造，17条非空注入实体。监督为18013真记录、F1假476、F2假211。数量是时刻，不是独立实体。

基础头采用加权logistic损失，非截距L2为.005。真、假各占总权重1/2；真按父、epoch、时刻分配，假先按非空family/k，再按父、epoch、时刻分配。标准化只用本方案fit折外特征。近常量列固定系数0，优化不收敛记失败。J/Q仅作无中心RMS缩放，不增加截距。

mixed用F1/F2训练并用原F0/F1/F2校准。F1_only仅用F1训练和校准，在F2评价；反向同理，目标族不进入标准化或门限选择。它们全部可估，但这不等于覆盖了真实攻击总体。

全部基础头的a_plus拟合为0，未报条件项为正。因此本批没有支持正报告观测质量的预期作用。c只有点估计；F1/k3单父和F2/k1两父使预定父重抽区间不满足覆盖预检查，区间不可用。

## 6. 未知、时序与三态

每次从最近10扫描窗口左端重算正常表征和分数，不把旧S再次相加。旧证据移出后不保留核验后验；前端查询仍可包含合法更早历史。缺条件及状态回退沿用冻结normal规则，缺失不当0。

- 无预查询的新生，或只有一个来源有效，输出未知，保存合法事件。
- 采纳要求窗口至少两个不同来源fresh支持、当前存在相容输出，且S达到正门限A。
- 拒绝要求窗口至少两个来源有有效事件、至少一份有效未报，且S低于负门限R。
- 其余未知，支持过期后重新检查资格。数值失败保持未知并留在统计中。

双支持只是共同决策政策，不是真实性证明。没有额外两帧等待。每个方法在独立cal录制按同一规则选择A/R，经验真假错误预算各5%，假风险同时限制非空family/k层。缺假标签时不能假装采纳已校准。该预算不是迁移或部署风险保证。

复用AVstack/MATE前端、共同查询和缓存，并列运行新核验器。新分数不灌入MATE的Beta或来源信誉。MATE保留原机制参考，主机制比较另用共同资格与校准的MATE_policy，不把后者称为MATE原论文全部系统效果。

D/T/I/J/G/Q共享合法输入、窗口、监督权限和输出政策，I/J比较固定边际和基础参数。评价同时保留真假六格、CD、每族/k、父录制、初窗及配对epoch时效。Unknown不能算正确判断，不可构造、无query和未知标签不能算防御成功。

现有47段录制仍是资产范围，14父只是本批开发选择。已反复查看的eval不是未见终测。多受控eval仅一父，F3仍缺失，不认领条件污染鲁棒性。
