## 1. 研究问题和前提

利用报告、未报告及观测条件核验候选目标真实性，输出采纳、未知、拒绝。核心仍是观测条件与多源证据，联合依赖目前没有有效性证据。

用户允许核验器在未受攻击的接收车上运行，使用自身点云和未融合检测。可信不等于感知无误或处处可见。其他来源受控数量和身份未知，不假设多数诚实，在线不输入k。当前实验不含自然误检与正常错误关联到假目标；GT未匹配不补假。声明攻击范围内的经验统计判断不构成任意串谋保证。

保留远端目标采用能力是用户明确要求，不能把研究缩成只采用本车已检测到的目标。

## 2. 已实现的计算

共同前端提供因果预查询、新鲜报告U=1、合法未报U=0和未知U=-1。缺包、无合法观测条件不补0，coast不算新支持。复用十扫描窗口，不反馈源信誉或改变中央跟踪。

本地支持I使用新鲜车辆框与参考框的BEV IoU，要求3米内、类别相容、正重叠和双向唯一关联。参考框位置/yaw来自预查询，尺寸由clean fit本车车辆框加权中位数固定，远端自报尺寸不能改变核验分母。

反证F为0.25米体素中实际射线采样穿越的体积分数，回波终点占据优先，未覆盖保留在分母。F不是完整空闲空间证书。没有检测、没有回波均不能直接判假。

公共故障或支持/反证冲突输出未知。达到校准门限的本地反证拒绝，本地车辆支持采纳。单可信来源可以支持采纳，强本地支持不被远端沉默推翻；无对应可输出轨迹的强支持保留未知。

普通本地未知才进入消息分支。LocalCount用有效未报数量，LocalCond用条件反证R=-sum_(U=0)log(1-p_D)进行拒绝。余下记录由冻结Count连续分数C及重新校准的门限决定是否采纳，其他未知。复用分数，不继承旧Count三态。C/R单独数值失败不否定合法本地证据。

I/F先分别按2%原始错误预算校准，之后按实际互斥本地决定扣除整体5%的真假剩余预算，先确定消息拒绝门限，再确定采纳门限。三方案共享本地信息。门限只看相应cal资料。

23父为6fit、5cal、12eval。87计划任务69完成、18不可构造。16项新增cal构造13完成、3不可构造。评价主真21759时刻、277个GT实体；mixed主假1149时刻、28注入实体。时间点不是独立样本。

独立重计已确认保存决定、权重、指标和裁决。没有Joint贡献或完整MATE系统效果主张。

## 4. 远端风险修正的结果与当前边界

mixed的40个误采时刻来自两个实体，全部由本地证据未达门限后的message_support产生。同时该分支贡献13.90个百分点真实采纳，关闭会使TA从64.47%降到50.57%，与用户要求不符。

cal平均约束允许少数父持续误采。mixed/F1_only一父F1/k2为11/44即25%，平均后恰为层5%；反向一父F2/k2为6/44即13.64%。

已实施仅提高tauC、增加每个(family,k,parent)完整假分母5%约束的候选。三配置cal筛选均通过，随后完成一次开发评价及独立重计。分数、资格及拒绝决定保持，只有消息采纳转未知。

已有效的条件证据和本地证据保留为研究资产；下一项方法修订需解决本地未决时的远端支持区分，先给出新增合法判别信息或处理方式及采用代价依据。当前不宣称该修订已经设计或验证完成。旧单阈值正报告候选及旧Joint不自动恢复。
