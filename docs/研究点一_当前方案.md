## 1. 固定的研究问题

利用各车报告、未报及观测条件核验候选目标真实性，输出采纳、未知、拒绝。研究内容仍是单车观测条件与多车依赖，不恢复K1、驾驶系统或研究点二。

用户于2026-11-17明确允许可信接收车自身观测。核验器运行在未被攻击的接收车上，可以使用其自身点云与检测结果；其他车辆的受控数量和身份仍未知，不假设多数诚实。可信指本地数据和计算未受攻击，不代表感知无误或本地处处可见。正常误检和正常错误关联到假目标仍不在当前实验范围，正常漏报仍在。GT未匹配不补假。旧实验采用无额外可信本地通道的边界，其结果不追改；新增本地证据尚未接入。

## 2. 当前已实现、可复现的计算

预查询由上一轨迹预测产生，再关联当前消息。新鲜支持记U=1，有合法扫描机会却无支持记U=0，其余未知。缺包、FOV外及必要条件不可用不补0，coast不算新支持。所有方法共用前端及十扫描窗口，不反馈轨迹或来源信誉。

基础Count根据报告次数、未报次数、扫描数、有效来源数和曾报告来源数给出完整三态。模型与门限保持原参数。正常报告概率p_D由距离、方位、FOV余量、预测不确定性及潜在阻挡代理C预测。C不是遮挡真值，GT和回波不进入在线计算。

Cond使用 `R=-sum_(t,i:U_it=0) log(1-p_D,it)`。只在Count尚未拒绝、正常可读且具有拒绝资格时追加拒绝，其他保持。新增门限只用完整正常校准主真分母，以 `min(.02,max(0,.05-eB))` 限制新增校准误拒质量。它是异常评分，不是目标不存在概率。

Joint使用同p_D边际的独立/共单调混合，计算 `-sum log Q(有效未报 | 已报告)`。正常数据拟合得到混合强度0.25，各方案分别正常校准。Group为组内有效来源数平均反证的简单控制。Joint与Group均从Count出发，不把Cond拒绝锁死为新基础。

原独立分支门限仍为mixed 22.3020992852、F1_only 19.8337732000、F2_only 19.7615969493。没有根据追加评价重新调参。正报告仍主要由Count处理，本轮没有完成新的正报告质量评分。

实现与来源见[独立规格](REALLY_MAYBE/rq1_independent_supplement_2026_11_16/SDS.md)、[联合规格](REALLY_MAYBE/rq1_joint_supplement_2026_11_17/SDS.md)。代码可运行与研究方法有效分开判断。

## 3. 当前结果支持到哪里

原六段资料上，Cond相对Count的CD增量为10.08、8.39、18.05个百分点，且通过当时冻结风险条件。这些条件反证效用证据仍成立。CD为真采纳率与假拒绝率的均值，不是普通总体准确率。

联合相对Cond的结果为：

| 方案 | 原六段CD增量 | 追加三段CD增量 |
| --- | ---: | ---: |
| mixed | +0.071个百分点 | -0.284个百分点 |
| 基线F1/评价F2 | -0.020个百分点 | 0 |
| 基线F2/评价F1 | -0.017个百分点 | 0 |

全部未达到1个百分点的冻结主增量要求。正常拟合目标略降，但正常评价损失也没有改善，因此不把非零依赖参数当作联合已有效。

追加三段只补一次必要FOV。15任务有3个正常、6个有效攻击和6个不可构造，主假235条、6个实体，各假层只有1或2父，支持不足。与此同时已经观察到下列风险：

| 追加域方案 | Count假采纳 | Cond假采纳 | Joint假采纳 |
| --- | ---: | ---: | ---: |
| mixed | 11.93% | 11.65% | 11.65% |
| 基线F1/评价F2 | 0 | 0 | 0 |
| 基线F2/评价F1 | 23.86% | 22.73% | 22.73% |

支持不足限制推广，不能抹去已观察到的失败。这些资料是历史开发资产的追加确认，不是项目全新盲测。独立核验确认新域Count/Cond确为原模型、原门限的正确重放。

## 4. 已经定位的主要能力缺口

追加mixed的41条Cond误采、F2_only的40条误采，均来自同一个F1/k2注入实体。其中两方案各有36条记录没有有效未报，R=0且拒绝资格不成立。它们由Count先采纳，后续Cond、Group、Joint均不能改变。

实际例子为两份报告、一个未知，Count输入 `(2,0,1,2,2)`。这说明当前反证路径无法校正这类基础采纳，继续调整联合强度不会修复这些零反证记录。

不能据此直接规定所有R=0记录为未知，因为正常目标被多车共同报告时也可能R=0。需要明确正报告的采纳依据及相应真实代价，当前尚未确定新规则。

随后仅核对保存的正报告分数，在同父、同Count输入和资格的10个共同层内，正报告异常度排序AUC为0.874，假侧仍只有上述一个实体。它支持局部候选方向，不是新算法效果。所有零反证采纳改未知会损失追加域29.45个百分点真采纳，因此不采用这种规则。具体依据见[结果第8节](REALLY/同边际联合核验_结果与采纳风险_2026-11-17.md#8-解释问题时追加的正报告只读核对)。

## 5. 明确的方法取舍与后续位置

- Cond保留为有局部效用证据的研究组件和对照，不能再表述为跨录制风险已通过。
- 本轮Joint不保留为有效算法，Group保留控制，不在本批上继续调参求通过。
- 旧D_zero、旧联合、参考区域等历史结果继续保留，不因为当前失败而自动恢复。
- 下一项核心问题是采纳依据和正报告条件证据，特别是多份报告存在而缺少有效外部未报反证的情形。不能只把基础采纳交给未报反证兜底。
- 此前[正报告采纳复核](REALLY_MAYBE/条件反证补充核验_判决层收敛设计_2026-11-16.md#12-采纳复核的候选修订2026-11-17)已否决。追加mixed上即便事后选择最有利门限，真采纳损失不超过2个百分点时最低误采仍为10.51%；达到各层5%误采要求至少损失15.23个百分点真采纳。不能由单实体AUC宣布该候选可用。
- 用户已明确允许可信接收车，后续可以增加真实的本地支持和反证。其他车辆数量与受控身份仍未知，不加入任意攻击先验或多数诚实假设。

此次有界联合比较已经结束。原实验和追加不利分层完整归档；后续设计应针对已经定位的采纳缺口，不再无依据更换整套框架或反复跑同一批联合比较。

## 6. 新前提下的具体修订位置

本地未融合检测形成车辆支持；有效射线穿越且覆盖充分时形成空闲反证；遮挡、稀疏回波、缺失及冲突保留未知。零回波不等于空闲，占据不等于车辆。强本地支持不被远端沉默直接否定。

本地未知时保留条件反证与经独立假侧校准的消息统计采纳，不能直接继承旧Count采纳。无可行采纳区或缺少校准支持时未知。该分支仅具有声明攻击范围内的经验意义，不提供任意串谋保证。

先比较仅本地、本地加计数、本地加条件证据，全部拥有相同本地输入，再判断联合是否有必要。保持完整候选分母及本地未知分层，防止退化为只验证自车已检测目标。具体事件、参数来源和接入代码见文首新设计。

按用户要求控制改动规模，首版收敛为两个新增模块：本地几何证据与侧录/判决/校准入口。检测、全车跟踪融合、候选、p_D、Count分数、W10和原统计复用。固定参考形体避免远端自报尺寸操纵分母；本地支持I和采样穿越F的定义、四个门限的顺序及关闭条件已补齐，见[最小实施规格](REALLY_MAYBE/rq1_trusted_receiver_2026_11_17/SDS.md)。当前是可编码的计算规程，尚未得到新参数或方法效果；正式效果清单仍须处理既有cal覆盖限制。
