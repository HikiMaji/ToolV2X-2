# 研究点一当前方案

更新日期 2026-11-12。当前实现为真实观测条件核验候选，原实现提交 `817aa47`。几何提取、概率拟合和四法比较代码已完成并通过代码审核。实际缓存批次尚未形成模型和最终指标，不能声称取得实测收益。受控合成结果属于前一阶段，见[结果记录](REALLY/条件联合核验_修订结果与方法决定_2026-11-11.md)。

## 1. 问题和范围

针对候选目标X，根据各车观测条件确定报告与未报告的证据强度，再考虑多源依赖，输出采纳、未知或拒绝。核心问题是同样的合法信息和评价规则下，联合证据是否比仅使用单车条件证据更有效。

一车报告、其他有良好观测条件的车未报时可形成反证；只有提出者具有有效观测条件时，孤立新报告保留未知。多车报告也需要判断，不能直接当作真实性保证。

来源数量和受控数量不预设，不输入好坏身份，不假设多数诚实。主实验暂不包含正常误检或正常车辆错误关联到虚假目标，不重新盘点这一数据条件。GT和攻击身份只用于离线评价。当前不恢复K1修复、A/H隐状态系统、完整驾驶任务或研究点二。

## 2. 实际输入和候选总体

当前核验上一时刻中央输出预测至本时刻的成熟预查询。候选位置在消费当前报告前形成，不再条件于某个预指定来源当前一定报告，因此全部未报的000模式合法。当前输出后来删除的预查询仍保留。没有预查询的新生目标单列未知。

每车事件U为当前新支持1、有效机会下没有新支持0、或未知。未知维度边际化，缺包不能补0，coast不重复当新正证据。固定同帧集合统一计算，结果对来源排列不变。

基础条件X为距离、方位sin/cos、FOV余量和预查询位置协方差迹的既有变换。本批去掉上一报告等三列历史特征。额外条件C使用同帧公开传感器位姿和全部非空预查询预测框提取，几何函数不读U、GT、当前输出或攻击身份。

C为9条射线中在目标probe前遇到已知预测框的比例。probe中心为预测bottom位置上移0.75米，半边长0.5米。其他框从8角恢复OBB；排除自身、3米内可能重复框及包含传感器原点的框。同一主阻挡ID形成公开共同组，其余单独成组。详细边界见[实施计划](REALLY_MAYBE/真实观测条件接入_实施计划_2026-11-11.md)。

C是潜在阻挡代理，不是真实可见率。C=0只表示没有找到已知阻挡。历史假框、遗漏静态建筑和预测误差都可能影响它。

## 3. 单车概率与证据强度

正常侧p_i=P(U_i=1 | 目标真实，预查询总体，X_i,C_i)，预测的是fresh支持事件。用fit中clean且已标真实的记录拟合低维logistic，L2=.01，C系数约束不大于0；该约束是模型假设。标准化仅用拟合父录制，概率统一裁剪至[1e-6,1-1e-6]。

假侧Q_F是四族等权声明参考，分别为独立Bernoulli报告率.1/.2/.4，以及共同Bernoulli(.2)的全0/全1分布。单车假边际r_bar=.225。它不是从数据学到的恶意行为模型，也不保证覆盖任意串谋。

单车证据 `e_i = U_i*log(p_i/.225)+(1-U_i)*log((1-p_i)/.775)`。报告与未报都能产生不同方向和大小的证据。未知来源不产生这一项。

## 4. 联合证据与对照

固定同一单车p_i，共同组使用独立与共单调Bernoulli混合。

`P_T(U_g)=(1-rho)*product Bern(U_i;p_i)+rho*max(0,min_report p_i-max_unreported p_i)`。

空min=1、空max=0。rho在五个正常fit父录制的折外预测上拟合，范围[0,.95]；无可识别增量时回退0并说明。rho可能吸收边际模型误差，不能解释为物理遮挡率。

正常修正 `delta_g=log P_T(U_g)-sum_i log Bern(U_i;p_i)`。
假侧修正 `gamma=log product Bern(U_i;.225)-log Q_F(U)`。
完整分数 `S=sum_i e_i+sum_g delta_g+gamma=log P_T(U)-log Q_F(U)`，不是目标存在概率或Beta计数。

| 方法 | 正常侧处理 | 用途 |
| --- | --- | --- |
| B | 基础X估p，独立组合 | 基础条件对照 |
| C | X和C估p，独立组合 | 单车条件证据 |
| J | 与C相同p，加共同组联合修正 | 核验联合的额外作用 |
| G | 将C单车证据按组平均 | 简单减权对照 |

四法使用相同假侧参考、候选、资格和校准规则。G也加相同gamma，没有额外分类头。

## 5. 三态、参数来源和评价

有预查询且至少两个有效来源时可作明确决定。正分达到采纳门限则采纳，负分达到拒绝门限则拒绝，其余未知；分支可显式关闭。不再按支持数缺少校准覆盖强制整个组未知。

复用39个缓存任务。五个只有clean任务的父录制fit，四个非eval且有攻击任务的父录制cal，保留原eval父 `train/2021_08_23_23_08_17`。均为已看过的开发数据，不是未见终测。

cal分别约束假采纳和真误拒不超过5%，最大化真采纳与假拒绝的平均。权重为父等权、父内job等权、job内query等权。门限冻结后评价eval，不能把cal预算当作迁移风险保证。

同时报告真假各自采纳、未知、拒绝六格，以及正常单车NLL/Brier、联合NLL、共同组覆盖和参数稳定性。主真总体为clean且已标真；攻击真实背景单列，避免重复背景当新增独立样本。未知标签不等于算法未知。已标假的选择依赖旧输出可用性，不能把删除且未标目标补成假。

## 6. 当前证据与下一项工作

[受控条件机制](REALLY/条件联合核验_修订结果与方法决定_2026-11-11.md)在声明分布下有有限收益，但真实未知高，部分攻击族风险超出混合预算，不能外推为实际车辆效果。[旧静态试验](REALLY/静态评分_首轮开发比较_2026-11-10.md)未证明联合增量，其失败记录保留。

当前真实条件代码见 `scripts/rq1_real_cue/`。主服务器原位置为 `.worktrees/rq1-real-cue-2026-11-11/scripts/rq1_real_cue/`。2026-11-12检查时原run_001有39份特征文件，无阶段完成manifest、拟合模型或最终指标，相关进程已不存在。文件数量不能证明文件完整。后续先定位提取结束与标签合并的中断位置，复用可确认完整产物，再完成原定拟合和比较，不能直接覆盖run_001或无依据重跑感知。

保留标准不变。C须改善正常预测且任务收益可保留；J须在同边际下改善联合NLL，并在eval两类错误各不超过5%时提高正确明确率、超过C和G。否则撤下对应效果主张，按具体失败作方法决定，不追加同eval调参。

当前是静态预查询核验。尚未实现真实性时间状态，kernel采纳也不代表恢复中央输出。MATE保留原生历史机制作系统参照，未采用不能当拒绝。连续系统与出生处理仍待落实，不能把本阶段包装成完整MATE/SABER替代系统。
