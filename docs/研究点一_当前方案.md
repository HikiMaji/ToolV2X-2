# 研究点一当前方案

更新日期 2026-11-17。**独立条件反证模块已经实现，并在本次三个开发方案中通过冻结保留条件。当前保留这个有限模块，多车依赖增量尚未建立。**

最新入口为[实际结果与保留决定](REALLY/独立条件核验_开发结果与保留决定_2026-11-17.md)。本次已经完成正常门限校准、全部预测、两个简单控制和独立重计，不能再写成只完成定义或尚未运行。完整联合设计仍不是已验证算法。

## 1. 研究目标与范围

利用各车报告、未报及观测条件，核验候选目标真实性，输出采纳、未知、拒绝。研究核心仍为单车观测条件与多车依赖证据，不恢复 K1、驾驶系统或研究点二。

来源数及受控数量、身份未知，不假设多数诚实，不默认本车可信。正常误检和正常错误关联到假目标不在当前范围，正常漏报仍在。GT 未匹配不补假。目前效果只覆盖声明的开发攻击范围，不保证任意串谋。

## 2. 当前已运行的算法

1. 由上一轨迹预测形成预查询，再关联当前消息。新鲜支持记 U=1，有合法新扫描机会却无新鲜支持记 U=0，其余未知。缺包、FOV 外及必要条件不可用不补 0，coast 不当新支持。
2. 使用原 Count 完整三态作为基础判断。它消费最近十个合法扫描的报告数、未报数、扫描数、有效来源数和曾报告来源数。原模型、门限、资格及生命周期均冻结。
3. 从正常条件模型得到 p_D。输入包含距离、方位、FOV 余量、预测不确定性和潜在阻挡代理 C。C 不是遮挡真值，缺失显式标记，GT 和回波不进入在线计算。
4. 新增独立反证为 `R=-sum_(t,i:U_it=0) log(1-p_D,it)`。每次重算最近窗口，不重复累加上次总分，不将相关扫描冒称独立概率样本。
5. 原拒绝保持，公共故障未知保持。其余正常采纳/未知若有原拒绝资格且 R 严格超过正常校准门限，改为拒绝；其他保持原判断。新模块失败回到基础判断并记录降级，不改变后续前端或来源信誉。

R 是正常报告模型下的异常评分，不是目标不存在概率。正报告仍通过原 Count 和共同资格参与，本次没有新增正报告质量评分或联合依赖修正。整体采纳依据仍继承 Count 的真假监督，不声称整体完全独立于攻击构造。

## 3. 参数与校准来源

p_D 复用 `rq1_temporal_2026_11_12/run_001/models.json` 中的 D 模型。Count 复用 `rq1_report_freeze_2026_11_13/run_001/models` 与 `calibration` 中各方案对应参数。本轮没有重训这些模型。

新增门限只使用各方案完整 clean 校准主真分母，保留父、query 生命周期、时刻均衡权重。若基础误拒为 e_B，新增预算为 `min(.02,max(0,.05-e_B))`，不在可拒绝子集中重归一化。严格 R>tau 才拒绝，等于门限保持。无有效门限或预算耗尽时关闭模块。

## 4. 本次证据与决定

CD 是真采纳率与假拒绝率的均值。迁移方向指基础模型使用的假族，p_D 正常模型保持固定。

| 方案 | 原 Count CD | 条件模块 CD | 提高 | 假误采 | 真误拒 |
| --- | ---: | ---: | ---: | ---: | ---: |
| mixed | 58.88% | 68.96% | 10.08 个百分点 | 0.43% | 1.31% |
| 基线 F1 / 评价 F2 | 52.54% | 60.93% | 8.39 个百分点 | 1.14% | 1.73% |
| 基线 F2 / 评价 F1 | 57.69% | 75.74% | 18.05 个百分点 | 0.00% | 1.82% |

三方案均超过同校准预算的未报次数控制和扩大原 Count 拒绝区控制，最小 CD 差为 2.77 个百分点。真实采纳损失分别为 0.095、0.269、0.282 个百分点，从未采用生命周期比例未增加，配对首采用延迟差加权中位数为 0 秒。全部预声明实用条件及本批条件增量判据通过，独立重计一致。

因此保留当前 Cond 版本。两个控制仍保留为对照，旧 D_zero/I_zero/J_zero 及其失败结果不改写。二近父参考区域继续保持历史候选，不因本次正结果恢复。

## 5. 必须保留的限制

- 本批是已查看的开发录制，真类来自 6 个父，mixed 假类来自 5 个父、19 个注入实体。重复时刻不是独立样本，三方案也不是三批独立数据。
- 相同校准预算不等于实际误拒率相同，当前只建立固定工作点的比较，不是完整风险曲线优势。
- 首窗未改善。mixed 与 F1_only 的首窗加权假误采仍为 6.25% 和 12.50%。F2_only 一个父录制真误拒为 5.206%。不能声称所有时段、每个场景都低于 5%。
- mixed 的困难 F2/k2 假未知仍为 64.20%。当前模块不能恢复基础模型原有误拒，不能增加真实采纳，也没有解决全部虚假目标。
- 现有正常校准及基础模型的假族缺层限制保留。本批三车 k1/k2 结果不推翻旧 k3 失败。
- 多车联合与正报告条件证据仍未完成，不能把本批单车条件增益记作联合贡献或直接认领论文创新性。

## 6. 后续工作的位置

当前条件模块和其效果记录保留，不再因不能修复所有错误而反复整体撤下。后续问题是依赖处理是否在同一单车条件证据基础上产生额外收益。减少共同受限误拒是可能作用，不能在取得新证据前把它写成联合必有的收益。

经2026-11-17计划审查，首轮建议保持原 Count 判决政策、p_D、窗口、资格和校准规程，只比较独立、简单分组减权和联合证据组合。各评分用各自正常校准门限，不能共享原独立分数门限。联合强度允许为零。当前轮次不同时解除原 Count 拒绝保持，不将恢复其原有误拒列为预期结果。若后续必须更改该政策，需另保留同政策独立对照和当前 Cond 参照。

场景应按预先规定的观测条件和父录制选择，不按联合得分或已有错误挑选。当前剩余集合缺共同多份未报，不能用它证明共同漏报降权；必要时直接使用更多已有录制补足覆盖，开发与独立确认用途分开。针对性场景结果不能替代完整评价分母。

同组或同遮挡代理不等于 p_D 条件化后仍有额外依赖。正常报告组合拟合的改善与最终真实性判断改善要分别评价。真误拒转未知不增加真采纳，也不直接提高 CD；假拒绝转未知需记拒假损失。新比较须预先确定主要收益及允许代价，不沿用仅看 CD 的解释来认领误拒修复。详细审查见[候选设计第11节](REALLY_MAYBE/条件反证补充核验_判决层收敛设计_2026-11-16.md#11-联合推进计划审查2026-11-17)。这是下一阶段建议范围，尚未运行新联合实验。已完成条件实验的规则和结论不变。
