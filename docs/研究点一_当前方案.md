# 研究点一当前方案

更新日期 2026-11-16。**研究问题不变，目前实施独立条件反证的有限核验模块，尚无已确立的完整联合算法。** 用户最新要求尽快取得实际效果，本轮按[固定实施规格](REALLY_MAYBE/rq1_independent_supplement_2026_11_16/SDS.md)完成已有独立候选的接入、一次开发比较及保留裁决。不能修复全部错误不等于没有有限价值，但也不能把有限增益当作完整方案成立。

先读[本轮结果与方法取舍](REALLY/条件证据作用范围_已有结果核对与方法取舍_2026-11-16.md)。该记录说明具体保留什么、撤下什么及其依据。本轮未训练模型、拟合新依赖参数、校准新门限或运行新方法效果实验。

## 1. 固定的研究问题

利用各车报告、未报及观测条件，核验候选目标是否真实存在，输出采纳、未知、拒绝。

核心问题是，观测条件能否使单车证据强度更合理，多车依赖建模能否在此基础上进一步改善真假判断。需要同时考虑报告与未报，不能把减少未知、降低真实误拒和增加真实采纳混为一谈。

来源数及受控数量、身份未知，不假设多数诚实，不默认本车可信。正常误检和正常错误关联到假目标不在当前范围，正常漏报仍在。GT 未匹配不补假。评价针对声明的攻击范围，不声称覆盖任意串谋。

## 2. 保留的输入与实现资产

上一中央轨迹先预测形成预查询，再关联当前消息。U=1 表示新鲜支持，U=0 表示有合法新扫描机会却无新鲜支持，其余未知。缺包、FOV 外、必要条件不可用不补 0，coast 不算新支持，同源同扫描不重复计数。

正常真实记录学习单源报告概率 p_D。现有条件包含距离、方位 sin/cos、FOV 余量、预测不确定性和九射线潜在阻挡 C。C 是代理，缺失显式标记，GT 和回波不进入在线计算。p_D 是正常报告概率，不是来源诚实概率或目标真实性概率。

已有计算使用最近十个合法扫描及共同生命周期规则，每次重算，不重复累加上次总分。短窗口不是十次独立证据，也不是完整 MATE 式信誉系统。核验分数不反馈查询、关联或来源信誉，保持各方法共同输入。

这些接口、条件模型、缓存和已完成结果继续保留，不重建感知或完整驾驶系统。

## 3. 当前证据支持到哪里

在 mixed 评价中，固定父录制、五项精确报告计数及判决资格，Count 剩余可拒绝记录的条件反证排序 AUC 为 0.823。该共同范围只有真类加权质量的 4.48%、假类的 34.30%。F1/k2 为 0.999，F2/k2 为 0.622。因此支持局部增量信息，不支持稳定跨族判别或已满足误判预算。

Count 现有 3 条假采纳均无有效未报，追加反证无法修复。324 条假未知具有追加拒绝资格。已有 95 条真实误拒则被固定基础拒绝锁定，不能恢复。后两种改进目标不同。

候选几何联合在剩余评价假记录中只涉及 1 个父录制、2 个注入实体。其作用为增强报告分歧，没有共同多份未报降权情形。该结论限于本批剩余集合，不表示所有数据或校准记录没有共同漏报，也不是实际依赖或联合净收益的证明。

## 5. 后续设计必须解决的具体问题

近期先完成已讨论的独立条件候选，并用同预算的未报计数与原 Count 拒绝区扩展控制排除简单政策增益。联合部分仍须处理证据到三态判决的缺口，本轮不拟合或认领联合收益。

1. 观测受限时，应允许减轻负证据并重新判断。先固定基础拒绝再追加拒绝，无法检验恢复已有真实误拒的作用。
2. 观测条件良好却未报告时，应能增强反证，同时明确真实漏报的代价。不能从正常模型中的低概率直接推出目标为假。
3. 报告与未报的依赖应在最终判决前处理。需要分别说明共同支持、共同沉默和报告分歧的作用，不能将同组统一视为重复或统一减权。
4. 真假证据重叠、没有有效外部核验和缺少参考支持时，应保留未知。不能靠假定受控数量上限、正常似然补数或人为攻击先验补出真实性概率。
5. 仍按共同输入、同边际独立对照、真假六格、录制及攻击族分层判断效果。局部 AUC、数学算例或审核通过不能替代方法增益。
