## 2. 计算只改组合

合法事件及p_D复用已有语义，X无效的源未知，C缺失显式进入D模型。U本身非法或分组不成源索引划分是故障，不能偷偷补未知。预测与分组不读标签、family/k或攻击身份。q_all与q_plus从同一分布计算，未知维度边缘化。

分组直接使用已保存的预查询几何groups，既有规则为C>0、C非缺失且主阻挡ID相同者同组。不得按当前U重分组，也不把同组标签当作已经证明真实因果依赖。

对每个几何组，沿用已提出的独立/共单调Bernoulli混合：
Q_g(u)=(1-rho)*prod Bern(u_i;p_i)+rho*max(0,min_(u=1)p_i-max_(u=0)p_i)。
空min=1、空max=0。合法p截在[1e-6,1-1e-6]，rho网格为0/.25/.5/.75/.9。组间在模型中独立。

- Cond：原R_ind=-sum log(1-p)。
- Joint：R_J=sum_t(log q_plus-log q_all)，q_plus仅固定本帧报告源，将未报及未知边缘化。
- Group：R_G=sum_t sum_g [sum_(i有效未报) -log(1-p_i)]/|本组全部有效源|，分母包含报告源。

窗内只做复合评分，不声称帧间独立概率。无预查询、新生或无未报贡献0。实现用对数域，不分别裁剪q_plus/q_all。rho=0时Joint必须逐记录精确退回原Cond保存评分及判决，避免浮点差伪造差别。单例组和纯报告组的恒等性保留。

Joint与Group各自从原Count判断出发，不能叠加在Cond的拒绝之后，否则无法减轻Cond新增反证。原Count拒绝仍保持，故本轮不能恢复其原有误拒。

## 3. rho拟合与可识别边界

用上面的留父p_D预测得到当帧Q_rho。正常目标函数为完整报告组合的负对数概率，不用重叠W10似然。权重为父/查询epoch/时刻均衡，总和1，在全部可用正常监督行上先确定。使用冻结5点网格，最小损失并列1e-12时选较小rho。

这是利用折外单源预测来拟合rho；最小目标值仍是rho的训练选择指标，不能称rho经过独立折外验证。此处不训练新的判别头，不报告伪嵌套CV；cal和评价父不进入rho选择。按父报告拟合目标、包含非单例有效组的父/epoch/时刻及11/00/mixed覆盖，不能将来源数或窗口数当独立录制数。

无有效正常监督时Joint不可估，不把故障当rho=0成功。没有非单例有效组时记无辨识信息，退回0并保留该状态。选中rho=0也不是联合有效，标记结构退化。

**预先结束分支**：若rho=0，联合对任意输入与Cond恒等。仍运行原六父全比较确认退化与Group控制，但不启动3父的原始前端补算。该停止依据是结构恒等，不是看到评价失败后取消新数据；本批不能认领新增录制泛化结论。若rho>0，三父确认任务须全部按清单完成或明确不可构造，不根据已有六父的分数决定是否继续。
