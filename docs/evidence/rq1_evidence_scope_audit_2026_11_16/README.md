# 已有证据的可作用范围核对

2026-11-16，在新统计结果产生前固定本轮范围。用户授权先证明方法采用依据。本批是已查看开发资料上的回顾性描述，不是新方法效果实验。

- 主输入为最后一次已完成实验 `rq1_report_freeze_2026_11_13/run_001` 的 mixed cal/eval；另外两方案只使用该批已保存预测作分域描述。cal/eval 分开，不合并父或假族。mixed cal 包含 F0/F1/F2，eval 仅 F1/F2。
- 不拟合新模型、选择 rho、估计新门限、生成攻击、重跑前端或修改已有决定。原参数、特征及结果只读。
- 先按原完整主分母计算真假权重，再切 Count 非拒绝、追加拒绝资格和共同支持层。真仅 clean 真 query，假仅明确注入 target 假 query；未知标签、出生无查询和重复攻击真背景不进入主分母，覆盖单列。
- 独立反证描述量 R_ind 直接取已保存 D_head 的 -L_minus。由冻结 D 模型和原窗口函数重建一次，用于检查键、计数、概率事件及窗口对应。它不是新联合 R 的结果。
- 在同 parent、五个精确 Count 输入及 accept/reject 资格的共同层，计算高 R_ind 偏向假的加权秩一致性。层权重为 min(真全局质量,假全局质量)，同时报告各类进入共同层的质量、父和实体数。秩比较仅以10位小数处理数值并列，不改原分数或决定。不能用局部AUC推成部署效果、因果作用或预算尾部收益。
- 联合潜力按原 U 经 X 有效性处理后计算，使用真实十扫描窗口及重置语义。窗口内至少一帧同组有两个有效来源且有未报，才可能影响当前直接 p_D 条件反证。共同00与mixed分为00-only、mixed-only、both、neither，纯11另列。它是结构覆盖，不是实际非零增量或有益覆盖。cal 和 eval 均报告，不拿 eval 占比直接为全算法 CD 增量设上界。
- 原 Count 与 D_zero 的决定转移仅统计已经保存的输出，不进行新策略回放。示例优先取剩余非拒绝共同支持质量最大的计数层，再选真假各自加权中位记录；另列原 Count 误采纳实体。示例为说明性选择，不代替全体统计。
- 安全的资格上界为可追加拒绝假记录的原全局质量/2，假设零真采用损失，只是理论上限，不是可达改善。
- 本批结束必须给出方法取舍：哪些信息已有作用依据，哪些仍缺证据，是否应继续采用当前候选。不能因统计输出成功就认领新算法有效，也不自动启动下一轮实验。

必要检查限定键一致、原六格复现、权重守恒、窗口计数与缓存R对应、AUC公式自检及独立结果复核。原数据不作重复全量盘点或逐PCD哈希。
