# Joint/Group 有界规格独立审核

2026-11-17。审核对象为本目录 SDS.md、config.json 及其直接复用的代码和参数索引。结论为可实施，无阻断性必修项。本次未选择 rho、重算方法分数、校准门限或运行新增评价。

## 审核结论

1. 联合分布保留给定 p_D 边际。由同一分布计算完整事件及仅报告事件，再取对数之差，符合所定义的正常条件反证评分。未知源边缘化，不能补为未报。该评分不是不存在概率，也不能单独证明物理共同原因。
2. `features.complete.json` 确实提供六个逐父 `normal.json`，每个对应其余五父。使用这些 D 预测拟合 rho 没有让该父参与自身 D 训练。但 rho 的最小目标仍是训练选择量，不能称独立验证。SDS 对此已明确，不要求另做嵌套验证。
3. 同一 D、事件、分组、窗口及 Count 政策下比较 Cond、Group、Joint，且新分支各从 Count 出发，能够隔离组合方式的增量。分别正常校准可以避免共享分数门限制造差异，但不等于实际误拒风险相等。
4. 既有 `geometry.groups_from_cues` 在 C 正且未缺失时使用主阻挡 ID 分组，其余为单例。`extract_frame` 由预查询几何和当前来源位置生成该组，不读取 U。实现应沿用保存的 groups，不能依据报告/未报结果重分组。
5. Group 的分母包含本组全部有效来源，报告源不能被删去。rho 为零时须直接保存原 Cond 分数及判决，避免纯浮点差异改变严格门限结果。单例、空未报、全未知等合法边界应沿已定语义处理，非法 U 或非划分组不能被当作合法未知。
6. 旧结果完整保留。正常校准使用完整 clean 主真分母和 Count 剩余误拒预算，不能在可拒绝子集重归一化。原 Count 拒绝保持，因此本轮不能认领恢复 Count 原有误拒。
7. 既有 `zero._paired` 只使用 primary 真记录的生命周期，无共同曾采纳生命周期时明确返回支持不足。新分支时效必须相对 Cond 比较，并保持该口径。
8. rho 为零后不启动追加前端属于预声明的结构结束分支。rho 为正则完成三个冻结父的全部十五任务或记录不可构造，不根据原六父效果撤销追加域。追加父属于历史开发确认，不是项目盲终测。
9. 三个 regime 和两个已执行评价域分别裁决、完整真假六格、逐父与假层支持门槛均合理。三父三实体只是操作覆盖下限，不能写成 5% 风险保证。正常 NLL、最终效用及论文创新性需保持区分。

本审核确认的是有界开发比较可执行，不是联合机制已经有效。代码审核及独立结果复核另行记录，不重复既有点云、模型或历史批次验收。
