# 评分修订的拟合、族迁移与保留判据

2026-11-13。本轮新攻击构造、新判别头拟合和新评分之前固定的开发规程。已有14父数据和旧结果已经查看，不能称未见终测或追溯注册。算法定义见[7系数修订](../真假侧问题_方法取舍与落实边界_2026-11-13.md)第9节；本文件统一执行细节，冲突处以本文件为准。机器清单为同目录`frozen_config.json`。

## 1. 问题与固定范围

本批判断正常条件表征加两类监督能否改善采用权衡，以及正常联合信息是否超过同边际、同容量和组平均对照。攻击假设没有消失，训练与校准所用攻击族定义了适用域。

固定14父6fit/5cal/3eval、W=10、原正常概率模型结构、原共同三态资格、旧原始产物及cal/eval任务。不给主候选使用Q_F、epsilon或pi，不新增两帧等待，不改直接条件发射，不补F3。正常模型用于cal/eval的参数可复用原六父拟合；头训练须使用父录制折外特征。

## 2. 构造规则在读取新分数前冻结

26个fit尝试的父录制、来源ID、受控集合、正常核验来源、family/k、seed和来源清单hash写入机器清单。五个三车父各F1/F2×k1/2，一个四车父各F1/F2×k1/2/3。全部seed=0，与冻结构造器的`RandomState(0)`一致，不能只在JSON写种子而让实现忽略它。

沿用冻结原生构造规则：前80扫描，20至59注入，60至79停止后观察；候选由第20扫描的GT锚点、6/10/14米偏移及8方向产生，随机顺序最多64项，取第一个满足合法条件的候选。F1固定位置，F2跟随锚物体并检查指定正常来源遮挡条件。受控集合为冻结有序来源列表前k个，正常核验来源为第k个，目标尺寸及姿态规则以清单绑定的构造器代码为准。

构造不读取防御分数。失败保留UNREALIZABLE，不换seed、父录制或位置规则补齐数量；成功但无query、标签未知分别计数。固定角色、尺寸、注入时段等可能被学习为捷径，7参数不豁免该风险。

## 3. 三个拟合与评价方案

| 方案 | 头拟合所用假族 | 门限校准所用假族 | 主评价假族 |
| --- | --- | --- | --- |
| mixed | fit中的F1、F2 | 原cal的F0、F1、F2 | 原eval的F0、F1、F2 |
| F1_only | fit中的F1 | 原cal的F1 | 原eval的F2 |
| F2_only | fit中的F2 | 原cal的F2 | 原eval的F1 |

三方案均使用对应split的clean真实目标。normal模型只读clean数据，可以复用；头、标准化、增量系数、门限分别拟合和保存。源族单独方案的这些环节均不能使用目标族或F0，包括目标族无标签特征也不能用于头标准化。目标族只进入该方案的评价。

各对照，包括MATE_policy，使用同一方案的校准数据和规则。两个迁移方向分别报告，不能合并后抵消失败。迁移通过只能排除部分族特有规律依赖，不能排除两族共有的注入尺寸、时段、角色和位置规则，也不能证明学习到一般真实性。

这两项主要增加头拟合、校准和统计计算，无需为迁移再次生成攻击或运行感知；不将成本写为严格零。

## 4. 数据支持、数值拟合和联合信息分开判断

以下为本批最低开发支持门槛，不是样本量定理。

1. 每个用于头拟合的假族至少有6条明确注入目标轨迹，来自至少3个父录制，并同时有k=1与k>=2的样本。混合训练两族分别满足，最低合计12条。
2. 门槛计数的一条轨迹须有至少10个不同扫描时刻的明确假query。同一个注入实体碎裂成多个中央ID/epoch仍只计一条。短轨迹和短窗口继续进入拟合与评价，只不贡献该门槛计数。不得挑掉难样本。
3. 数值拟合要求两类都存在、必要输入有限、优化收敛。某列加权标准差不超过1e-6时，记录常量列并固定其系数为0，不靠放大尺度产生贡献。正则得到有限系数不等于数据已经识别全部参数。
4. 联合增量须在至少3个fit父中有非恒定Delta_T；加权RMS和标准差均须大于1e-6。否则c置0、状态为`delta_uninformative`，不得认领联合增量。

分别输出`data_support_met`、`optimizer_ok`、`delta_informative`。某个source-only方案支持不足则标该方向未能检验，不挪用目标族补训练。26只是尝试上限，不预先认定已满足上述门槛。

## 5. 损失、权重、约束和正则

输入顺序固定为`L_plus,L_minus,n_plus,w,d,m`。基础头为7系数logistic线性分数。a_plus、a_minus非负；b_plus、b0、c_w、c_d、c_m自由；未报常数项固定为0。sigmoid仅用于训练损失，不解释为部署真实性概率。

`loss = sum_j weight_j*(log(1+exp(S_j))-y_j*S_j) + .005*sum(non_intercept_coef**2)`

权重真、假类各合计1/2。真类依次对父录制、query epoch、epoch内时刻等权。假类先对实际非空family/k单元等权，再依次对父、query epoch、时刻等权。以P、E、T分别表示相应嵌套集合大小，G表示非空假层数，则每条真记录为`1/(2*P*E*T)`，假记录为`1/(2*G*P*E*T)`。实现检查两类权重总和各为.5。

这里query epoch仅定义训练权重，不作为独立样本量或第4节的注入实体计数。clean真query与明确target假query用于监督，攻击回放中的重复正常背景不作为额外真样本。所有短窗口及评分资格不足但合法可评分的监督记录保留；标签未知不参与两类拟合，覆盖统计仍保留。

标准化只用该方案fit折外特征及其权重。截距不罚，其余参数的L2系数固定.005；不搜索正则。沿用L-BFGS-B，零初始化、maxiter=500、ftol=1e-10、gtol=1e-6。不收敛记拟合失败，不能观察eval后加迭代或换正则。

正常预处理、p和rho均在外层留一父中排除该父，rho选择仅在其余父内部进行。最终cal/eval采用六父normal模型，但使用冻结的头scaler重新生成分数并在cal校准，不能沿用旧QF分数门限。

## 6. 联合、组平均与同容量对照

主对照为直接条件头D、独立时序头T、J边际基础头I、完整联合头J、组平均G、同容量平方Q及MATE_policy。

J为`S_I + c_std*(Delta_T/RMS_fit)`。先固定I全部参数，再以S_I作offset，仅拟合c_std，符号自由；增量损失追加`.005*c_std**2`。Delta只作无中心RMS缩放，不新增截距。记录原Delta尺度上的`c=c_std/RMS_fit`。Q用同样规则加`S_I**2`项。

G将每帧每组的有效来源L_plus、L_minus及n_plus表征取组内平均，再在窗口累积；w/d/m保持原定义，使用相同7系数预算、数据、损失及正则拟合。I/J/G/Q使用同一J边际和过滤；T到I的差异包括过滤和边际变化，不能只归为联合计分。

所有方法沿用原共同输出资格，主门限A>0、R<0。cal每个正负分支采用原程序，在5%分级经验风险限制内最大化相应正确决策，平手取保守门限。假类风险同时约束总体及每个非空family/k层。若对应方案的cal没有假标签，采纳分支不得假装已校准；关闭该分支并将该方案标为校准不足。缺单个层单列，不自动改变其他层资格。

## 7. c的区间及已知可用性限制

用户要求的“区间不含0”保留为联合项的必要保留门槛，但本批不把小样本区间称为完整模型的可靠95%置信保证。

先按每个原非空family/k单元的父数m计算缺层概率下界`(1-m/6)^6`。任一层该概率超过.05，就直接记区间支持不足，跳过1000次重拟合；不运行一个预期无法满足本规程的重复计算。否则，mixed拟合完成后，以fit父录制为聚类单位，有放回抽6个父，重复1000次，seed=20261113。每次携带该父全部轨迹和时刻；使用`draw_cluster_id`或显式抽中次数，不能被原parent字典去重。固定normal折外特征，重估基础头的scaler及系数、RMS和offset增量，最后回到原Delta尺度c。区间取可用重复的2.5%和97.5%分位。

固定原拟合中非空family/k单元及其目标权重。重采样缺任一原单元、缺一类、Delta无变化或优化失败，均记不可用，不重新定义层集合。不可用超过5%时，不生成可用于保留判断的区间。所有失败及原因保留，不能只展示可用重复。不含0也只说明在固定normal表征下的条件稳定性，不包括normal参数估计、攻击生成器选择和未见父录制的不确定性。

**运行前已经知道的限制**：k=3构造只来自一个fit父。若该层产生样本并进入训练，普通父聚类重抽漏掉该父的概率为`(5/6)^6=33.49%`。在上述预检查规则下，只要该单父层实际进入训练，c区间即标为支持不足。因此原26次安排不能预先承诺完成确认性的联合保留。区间不可用即记证据不足，不改seed、删k=3或改权重来制造显著性。本批仍可回答评分层的开发效果和族迁移问题，但不能在缺少区间依据时宣称联合贡献已成立。

少聚类情形下推断本就需要谨慎，参考[Cameron与Miller，2015](https://facultysites.dss.ucdavis.edu/research/Cameron_Miller_JHR_2015_February.pdf)。这里没有把其回归推断结论直接移植成惩罚logistic头的有限样本定理。

## 8. 数值保留判据

以下百分点均为绝对率差，按原分级权重计算，不用原始时刻比例替换。所有主指标在冻结门限后的eval计算。定义`CD=(真采纳率+假拒绝率)/2`。阈值是本次预声明的实际改进门槛，不是文献推出的常数。

| 项目 | 固定条件 |
| --- | --- |
| 联合系数 | 第7节区间可用且不含0；不可用为证据不足，不是通过 |
| 联合正确明确率 | CD_J−CD_I、CD_J−CD_G、CD_J−CD_Q分别至少.01；CD_J不得低于CD_D和CD_T |
| 真实采用 | TA_MATE_policy−TA_J不超过.05 |
| 主风险 | 真拒绝率及假采纳率各不超过.05；每个有明确假样本的family/k层，假采纳率也不超过.05 |
| 相对假风险 | 在同一非空family/k层，FA_J−FA_T及FA_J−FA_MATE_policy分别不超过.02；这是净率差，不是新增错例的转移质量 |
| 采用时效 | 真epoch从未采用比例J比MATE_policy增加不超过.05；双方均曾采用的同一epoch内，首次采用延迟差的分级加权中位数不超过.5秒。没有共同可比epoch则时效条件未检验 |

主风险中的family/k完整报告F0/F1/F2×k1/2/3。分母为0标未测；有eval但无cal的层标未校准层，eval仍须满足上述开发门槛，不能声称该层已有校准保证。F3保持构造缺失状态，不参与虚构的通过结论。

时效单独使用epoch级权重。从未采用比例在全部明确真epoch上按父、epoch等权。延迟差在双方共同曾采纳的epoch集合上按父、epoch重新等权，不按轨迹长度加权。起点统一为同一epoch首个具有主真标签的合法预查询时刻，首次采用也限主真记录，标签未知不冒充正确采用；加权中位数取累计权重首次达到.5的差值。

所有原始计数、父/注入实体/query epoch数及六格同时输出。单父单轨迹层即使经验风险低，也不成为总体风险上界。采用延迟的共同epoch定义在此明确，不能只比较各自已采用者的两个中位数。

## 9. 族迁移判据及裁决

两方向分别要求目标族eval总体和非空k层假采纳率不超过.05，clean真拒绝率不超过.05。目标族上的CD_J不低于对应I。相对mixed方案在同一目标族上的结果，CD和真采纳率各下降不超过.05。另要求CD_J严格大于0，排除全部未知；相对差距条件本身不能排除mixed也接近全未知的情形。整体跨族稳健主张还须mixed的保留条件成立。门限固定为源族cal结果，不得为满足这些条件重校准。

任何方向支持不足、源cal不足或目标族没有明确标签，记未检验。主结果通过而迁移失败，只能称已覆盖攻击族混合内的开发结果，不能支持跨族稳健性。两方向通过也不能证明识别一般真实性。

裁决分开给出：评分层经验效果、联合增量、族迁移、参数稳定性及覆盖。全部保留条件满足才将联合项作为下一阶段主候选；某个数值条件明确失败则不保留对应主张；区间或覆盖不可用则记证据不足。可以归档开发结果，不能预先保证任何结果都足以写成有效方法论文。

本批不因结果不足追加seed、换阈值、改层权重或删困难样本。真正需要增加独立父录制时，应作为新的数据支持决定明确提出，不能在本批结果出来后无记录扩充。
