# 远端采纳修订的下一阶段计划

2026-11-17。回应用户对下一步计划的询问。本文是工作建议，尚非冻结算法或实施规格，未运行新实验。旧结果及不通过裁决保持。

## 1. 下一步集中解决的问题

在本车没有充分证据直接判断时，怎样利用已有合法证据减少远端假目标采纳，同时保留真实远端目标。当前条件反证拒绝模块、本地明确判决、共同前端和十扫描窗口保留，暂不同时更换多车联合模型。

优先考虑一项具体改动：让本地尚未达到拒绝门限的连续反证，继续参与远端采纳判断。

依据是实际代码`run.py::_local`和`decide`。F超过本地门限才直接拒绝；进入普通本地未知分支后，采纳只检查C门限及资格，不再使用F大小。不同程度的本地穿越反证因此可能得到相同的采纳待遇。这是实现事实，不是该问题导致全部误采的证明。

## 2. 首个候选及其作用边界

首个候选仅研究远端连续分数C和有效本地反证F共同形成的低复杂度采纳区域，替代所有本地未决目标共用一个C门限。其余判决保持，只允许原消息采纳转未知。

预期作用是在有较多本地矛盾时提高采纳要求，避免为了处理这部分目标而统一提高所有远端目标的门限。真实目标也可能有部分射线穿越，F不能被当作确定判假依据。F为0或不可用不增加真实性证据，也不能补成充分观测。

这仍是统计判决，需要明确真假侧资料；不估计未知攻击者数量或诚实概率。它不产生新的物理观测，也不是已经成立的多车依赖创新。部分剩余误采F为0，首候选不能预先承诺全部修好。

另一条路线是重新学习远端正报告条件的采纳评分，但现有单分数Splus门限已被否决，不能直接恢复。该路线还需要独立的真假拟合资料和新参数依据，当前不与首候选同时实施。

## 3. 工作顺序与明确产出

1. **一次有目的的可行性判断。** 复用已保存的C/F、真假标签及原决定，考察全体远端采纳记录及可比条件下的真实目标，按父录制和攻击族列出覆盖。只回答连续F是否提供超出C的可用区分，不只挑选剩余错误实例或计算单个实体的AUC。已看过的eval只能作开发诊断，不能选最终门限或冒充独立证据。产出是采用或停止该候选的理由。
2. **完成一份最小计算规格。** 若存在作用依据，限定低复杂度采纳区域，写清实际输入、不可用处理、参数数量、真假样本来源、拟合与校准角色及完整预算。不能默认现有形体拟合资料已经具备新分类头所需的假样本。若需要补齐拟合资料，只能使用预先声明的拟合录制和冻结构造，不挪用评价标签。不在看到效果后逐个增添特征或改变区域形状。
3. **一次有界开发比较。** 规格与独立审核完成后才实施。共同本地和拒绝判决不变，对照包括原C采纳、已完成的分组C校准和新条件采纳。同类修正必须对Count与Cond两种拒绝版本公平应用，不用削弱Count制造增量。

判定仍保留总体与各攻击层误采不超过5%、真误拒不超过5%、相对各自run_002原版本真实采纳损失不超过2个百分点，以及正质量远端采纳。完整真假六格、F1/F2双向迁移和误采集中的录制均报告。不存在可行采用区，或效果只在一个开发实体出现，就停止这一候选，不继续加门限、换种子或宣称只差更多训练。

首次可行性判断若不支持C/F候选，则不进入其实现与完整比较。届时转向远端正报告的新判别依据，需要明确新信息和参数来源，不能自动启动另一轮模型尝试。

## 4. 调研的具体用途

[CAD](https://arxiv.org/abs/2309.12955)作为协作感知伪造检测的相邻工作，后续只针对其几何一致性证据和适用范围做定向比较，避免把本地几何本身认作新贡献。

[Selective Classification for Deep Neural Networks](https://arxiv.org/abs/1705.08500)提供拒判与风险、覆盖取舍的成熟研究参照。其拒判对应这里的放弃判断，不等于认定目标为假。本文不采用其网络架构，也不直接继承其概率保证；相关窗口、攻击族变化及本项目分级权重需要单独处理。引用该思想不能证明C/F候选有效。

这些资料用于约束方法设计与结果解释，不替代本项目的真假区分证据。当前尚未选定分类器或训练损失。

## 5. 多车依赖的后续位置

远端采纳问题取得可保留结果后，再在相同单车条件证据、采纳规则和输入权限下比较独立组合与依赖组合。只对观测条件有增益就如实归为条件证据收益；联合没有额外收益便不写成已完成贡献。

计划保留原研究目标。当前阶段的交付应是一个有作用依据、参数可估、范围明确的采纳修订，而不是扩展成完整MATE式系统。
