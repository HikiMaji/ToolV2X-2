# 真实观测条件接入计划独立审核

2026-11-11。审核对象为[实施计划](../真实观测条件接入_实施计划_2026-11-11.md)。本审核者此前只读核查了a5d0622的预查询提取、标签构造、sender位姿与FOV生成，以及d3c29ae和前轮独立/共单调混合接口。本次没有实现、训练、新数据扫描或研究实验。

## 初审结论

**通过。没有要求修改后才能进入SDS的阻塞项。** 本批属于把已保留的条件证据与联合计算接入实际合法输入的必要适配，不是重新启动一般泛化研究。当前计划没有把真实输入可得、参数结构可识别和实测有效混为一谈。

原受控kernel的独立提出者当前必报告条件不适用于历史中央候选。计划撤下该条件，改用当前报告到来前的完整预查询总体并允许000，是必要修正。没有根据本帧支持、存活或标签筛遮挡集合。被删除query仍保留，新生单列未知，符合实际接口的时间权限。

固定probe能减少被核验目标尺寸直接进入条件特征的机会，适合作为本批固定选择。计划已限定它是统一查询邻域的几何代理，不能称目标真实可见率。使用corners恢复历史框OBB避免将bottom位置错当三维中心。三个排除规则、probe前首次相交、确定性ID并列处理和共同主ID分组均有明确实现方式。它们仍有近邻遮挡遗漏、次要遮挡物遗漏和历史假框污染，计划已保留这些边界。

直接拟合正常fresh支持概率，取消同时估计可见状态、状态先验和C误差率，避免将合成准确率冒称实测参数。在单车边际固定、组内有至少两个有效事件且独立分布与共单调分布不同时，共享rho的分布参数结构上可识别。计划没有逐阻挡ID估计rho，并以折外边际、平坦回退和留一父稳定性描述限制实际估计。rho只能表示所设统计模型的正依赖，可能吸收边际误差，不能解释为物理共同遮挡概率。

完整预查询假参考包含全0、全1及混合模式，四族等权单源边际为.225。该参考由声明给出，不从单源注入数据推断一般攻击规律。B/C/J/G使用相同假参考；C/J共享固定边际，J相对C的差异对应正常侧联合项。G为启发式分数组平均对照，不是已归一化的组似然。

拟合、校准、开发评价按父录制隔离，调整旧fit与cal用途没有触碰原eval父。所有材料仍明确为已看过的开发数据。主真假总体避免重复攻击背景计入正常总体，同时承认旧假标签依赖当前输出造成的覆盖缺口。未知标签不会用GT未匹配补成假。

预定结束决定同时约束概率拟合、目标真实性六格、错误预算与未知代价。未满足标准时撤下本版增量主张，不以扩大回放或继续调同一eval替代决定，符合本批授权范围。

## SDS需要落实的有限细节

以下属于实现规格，不要求重开研究计划，也不构成新实验要求。

1. 明确每个OOF折的标准化、近常数处理与logistic拟合仅使用该折训练父。最终重估再使用全部五个fit父。共享rho的估计不得读cal/eval标签。
2. 固定概率数值裁剪值，并让独立与联合计算使用同一份裁剪后的边际。明确logistic正则目标、截距是否正则化及C_missing的编码。C系数非正是本批建模假设，不是数据已经证明的物理定律。
3. 明确rho优化范围、固定求解方式、无信息及数值平坦判据。只含一个有效来源的组不为rho提供信息。留一父rho稳定性分析保持相同的合法输入和拟合边界，不能据其结果改选有利rho。
4. 在完整注册源上先确定分组，再边际化未知事件。不能因未知、当前U或当前输出改变分组。对没有已知阻挡、没有可用遮挡框和几何不可用保留各自诊断计数。
5. 固定OBB边界容差和probe首交比较规则。m/k/C等报告分层不能反过来决定几何特征或筛选主分母。保存预定权重归一与门限平局规则，四法保持一致。

这些内容检查的是具体科研错误来源，不要求新增全量hash、感知回放、数据盘点或合成扫描。
