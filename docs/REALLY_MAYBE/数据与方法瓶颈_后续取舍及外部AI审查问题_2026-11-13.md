## 2. 最值得解决的一个问题

在声明的攻击范围内，现有合法共同观测条件，能否在单车条件证据之外，提供可迁移的真假判别增量？

正常事件之间存在依赖，不自动说明这种依赖有真假判别价值。固定共同条件z，令u为完整来源事件或窗口事件，P_T和P_F为某个明确总体下的真假条件分布，且有关概率为正。定义`Delta_h = log P_h(u | z) - sum_i log P_h(u_i | z)`。完整对数似然比相对于单源对数似然比之和的修正是`Delta_T - Delta_F`。只有正常侧Delta_T，不能自动得到这个差。

本式不要求恢复手工Q_F，也不说明必须分别估计完整两侧密度。当前监督头可以在训练域内尝试学习判别差异，但一个c*Delta_T是否足够表达、能否跨域，仍未解决。

[Friedman、Geiger、Goldszmidt，Bayesian Network Classifiers，1997，第133页](https://dang.cs.technion.ac.il/journal_papers/friedman1997Bayesian.pdf)指出，改善联合分布拟合不必然改善类别预测，并讨论类别条件下的依赖。这里引用其方法学区别，不将其TAN实验当成本项目效果依据，也不据此决定换成TAN。

未知受控数量下同输入不可辨识的边界已在[既有方法取舍](真假侧问题_方法取舍与落实边界_2026-11-13.md)第2节写明。本轮不重复证明，也不由此否定有明确攻击范围的经验研究。

## 3. 推荐方向和有界决定

保持当前目标、前端和有限窗口，把下一批组织成能裁决联合增量的机制比较。暂不继续叠加评分项，也不靠更换门限挽回已知开发结果。

1. 先写清下一候选依赖的可检验区别。需要说明共同条件怎样改变真实性判别，而不只是正常侧拟合。正报告和未报都纳入，不能默认真实共同未报获益而虚假共同未报不受影响。
2. 按该区别组织真假与共同条件的交叉覆盖。真实目标有共同受限和分散观测情形，假目标在相应条件中也应出现。支持数量、距离、窗口长度等尽量可比。匹配只是比较设计，不是物理反事实，也不能强行制造不存在的重叠。
3. 使用已有47段资产补齐所需独立父录制。14父是开发批次，不是永久限制。选择与构造规则在看新分数前冻结，不按模型失误挑选新评价样本。同父换seed不能替代独立父覆盖。旧eval继续作为开发资料，剩余资料只有在确认未参与相应开发选择后才可安排新评价用途。
4. 候选只保留一种联合表达，与同信息单车条件汇总、同边际I、D_old/D_zero及必要同容量对照比较。共同条件同样提供给对照，不能把增加条件信息的收益算成联合收益。具体表达仍需下面的审查作出取舍，本轮不先写新算法。

预期作用是区分条件信息的价值、联合计算的额外价值和效用代价，而不是保证指标上涨。机制子集按固定规则构建，整体六格、首窗和迁移结果仍完整报告。配平比例不能当作现实总体风险。

若条件有用而联合无增量，就保留条件建模，撤下该联合表达及其贡献主张。若联合在独立父和同风险比较中有稳定增量，再推进完整机制。若合法输入在关键真假层没有可用区分信息，应收缩可核验范围并保留未知，不能用复杂评分消除信息缺口。新数值门槛需在新实验前按具体设计冻结，不回改旧裁决。

## 4. 可直接交给外部AI的审查请求

请独立审查以下问题。研究目标是目标真实性核验，输出采纳、未知、拒绝。来源数量和受控数量未知，不假设多数诚实，也没有默认可信自车。当前范围不纳入正常误检和正常错关联至假目标，不需要再次盘点。候选、位置与潜在阻挡来自时间t可用的消息和预测框，不能把几何代理当物理真值，部分框也可能受攻击影响。

当前单车条件模型给出正常报告概率p。窗口评分使用报告log(p)、未报log(1-p)、支持次数、支持来源数及窗口长度。原评分还含只未报来源常数，最新约束将其置0。联合头仅增加正常联合相对自身边际乘积的修正c*Delta_T。监督来自clean真目标和预先冻结规则的F1/F2注入假目标，当前sigmoid不是现实真实性概率。各模型共用10扫描窗口、三态政策及校准程序。

最新D_zero在mixed的CD从71.37%升至73.76%，反向F1/k3误采纳从6.67%降至2.22%，但真实采纳从58.91%降至53.51%，未通过冻结保留条件。J未建立稳定增量。不能只依据局部正数推荐保留。完整分母和首窗不利结果见第1节引用。

请优先回答四个问题，而不是再提供一份完整系统。

1. **真假判别依据。** 已知任意串谋存在不可辨识情形。在明确的有限攻击域内，现有输入还需要哪些可检验条件，才能支持超出来源计数的真实性判断？哪些条件能由现有消息及离线标签检查，哪些只能作为威胁假设？不要新增可信来源或诚实多数而不说明改变了问题。
2. **联合表达是否对准目标。** c*Delta_T缺少哪些类别相关结构？请结合实际失败，判断应保留、替换还是撤下该表达。若推荐修改，给出成熟方法依据、实际输入、可估参数和明确失败条件，不能仅以更多表达能力证明必要性，也不能重新指定无数据依据的通用假分布。
3. **正报告证据。** a_plus反复为0可能来自表征、符号约束、支持次数替代或攻击构造。现有证据能排除哪些解释？若建议改正报告项，需明确它如何与攻击方也能发出同样报告的事实相容，不能通过强制系数非零制造贡献。
4. **最小有判别力的实验。** 怎样让真假目标在来源数、观测条件、窗口及位置规则上有可比较覆盖，且同信息强对照能够排除边际改善和计数非线性的替代解释？请给出按父录制组织的具体比较与停止条件。保留整体效用，不允许只挑共同遮挡真目标证明联合有效。

期望答复包含一个推荐取舍、所需的最少额外工作、预期作用与适用条件，以及不利结果出现后撤下什么。若证据不足，请指出缺少的具体变量或独立覆盖，不能只说数据不够或继续调参。
