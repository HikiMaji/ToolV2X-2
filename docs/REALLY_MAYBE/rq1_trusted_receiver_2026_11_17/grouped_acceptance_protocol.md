# 远端采纳风险集中修正的有界规程

2026-11-17。用户在获知关闭远端采纳将损失约13.90个百分点真实采纳后，明确要求保留远端采纳能力、继续修正风险。本轮是run_002结束后的单独候选，不回写其三个not_retained裁决。

## 具体依据与预期

run_002的mixed/F1_only校准误采集中在F1/k2的一个父录制，11/44时刻被采纳，组内25%，平均到5个父后该攻击层为5%。F2_only有一个F2/k2父6/44误采，组内13.64%，平均后仍达标。原平均预算没有算错，但允许了局部持续误采。

候选只给采纳门限增加经验最差组约束。它参考[组间风险差异及最差组原则](https://arxiv.org/abs/1911.08731)，不复现该论文的神经网络DRO算法，不继承总体风险保证，也不认领新颖性。预期是降低采纳错误的集中程度，代价是真实采纳转未知。

## 唯一改动

I/F、参考形体、p_D、Count连续分数C、条件R、tauF/tauP/tauR、数据角色、三态顺序均固定为run_002。仅分别重选LocalCount与LocalCond的tauC。

除原总体和family/k约束外，对每个已观察 `(family,k,parent)` 校准组，要求完整判决的假采纳率不超过5%。分子包含本地与消息采纳，分母为该组全部主假，沿用组内epoch/时刻权重。不能只在message_support子集归一，缺失组不能补零风险。父身份只用于离线校准，在线不读取。

候选门限为旧tauC、所有不低于旧tauC的主真假cal消息采纳C边界及正无穷。选择满足全部约束、完整正常cal真实采纳最多者；同质量取更高门限。若旧门限已满足所有约束，保持原门限。若即使关闭远端采纳仍有本地风险超限，则本候选不可行。

提高tauC仅允许消息采纳转未知，不改变任何拒绝。真假采纳均不增加，假拒绝和真误拒不变，CD相对自身旧版不会提高。目标是以有限采用损失修正风险，不是同时抬高所有指标。

## 先只看cal，达到条件才看eval

每个regime分别筛选，但同一regime的LocalCount与LocalCond都必须同时满足：

- 新增真采纳损失相对各自run_002版本不超过2个百分点。
- 仍有正质量的远端真实采纳，不能通过全部关闭远端采纳过关。
- 总体、family/k及每个校准父组假采纳均不超过5%，不存在缺层或本地风险不可行。

筛选不读取eval，不修改run_002文件。某regime不满足便停止该regime，不调整5%和2个百分点要求，不补新种子。先生成screen.json及候选门限，不写新eval决定。

通过筛选的regime才在已看过的eval上作一次开发比较，比较旧/新LocalCount、旧/新LocalCond。同输入同分母，旧结论保持。除原风险与相对新LocalCount的CD/采用/时效条件外，新增要求两方法各自相对旧版本的评价真采纳损失也不超过2个百分点；不得弱化对照制造条件增益。单列最差评价父组风险与未知增加，但不声称新父风险有保证。

输出另建 `rq1_trusted_receiver_2026_11_17/grouped_acceptance_001`。不重跑PCD、不重训或更换分数。只有门限约束变化，效果来自风险与覆盖重新取舍，不归因于新的观测信息或多车依赖。
