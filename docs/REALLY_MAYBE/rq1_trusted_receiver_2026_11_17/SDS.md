# 可信接收车最小接入实施规格

> 执行者沿用当前主会话及编码、独立审核分工。按superpowers:subagent-driven-development执行有界任务，不重新向用户索取已确认的可信接收车前提。

**目标**：在已有候选回放上提取接收车本地支持与采样穿越分数，接入有明确校准和关闭条件的三态核验，保持同本地信息的比较。

**架构**：新增一个纯几何模块和一个侧录、校准、评价入口。侧录读取已保存查询，单独重建可信ego本地跟踪；不重新运行检测骨干和全体车辆中央融合。原Count/p_D/Cond分数、W10、标签与统计可复用。

**技术栈**：现有Python、NumPy、Shapely及native tracker，不新增依赖。

**设计依据**：[可信接收车修订设计](../可信接收车观测_修订设计_2026-11-17.md)。本规格规定方法计算和实施范围，不包含已启动的研究批次或效果结论。

## 全局约束

- 执行目录为`.worktrees/rq1-score-revision-2026-11-13`。旧生产代码及冻结产物保持，新增输出另建目录。
- 固定接收车ID在数据角色配置中声明，不能按某个目标的可见性、真假或分数选择。在线只读该车原始点云、位姿和未融合检测，不读其他车PCD、GT或攻击身份。
- 接收车自己的坐标变换复用`native_adapter.imports()`提供的`run_native`读取与变换方式。真实射线始终从该LiDAR原点到原始回波，不能用融合点或体素质心反推射线。
- 原有预查询、出生规则和输出身份检查保持。新生/无查询为未知；明确本地支持允许一个可信来源，不再要求第二个报告者。
- 真/假错误预算分别计算；每个假层用该层完整分母。缺失标签、不可构造、故障不能算成防御成功。
- `fit`确定参考尺寸；与fit按父隔离的`cal`确定门限；`eval`只应用冻结参数。已经反复查看过的录制仍称开发资料。

## 改动边界

新增`scripts/rq1_trusted_receiver/local.py`与`scripts/rq1_trusted_receiver/run.py`，加必要包标记及定点测试。保留`native_adapter.py`、旧Count/Cond/Joint实现与旧门限文件。无需新增完整地图、分割网络、攻击状态模型或信誉系统。

### Task 1: 本地几何与独立侧录

接口 `measure_local(query, fresh_boxes, origin_world, points_world, shape_hwl)` 返回 `I`、`F`、资格、状态及必要诊断计数。输入不接受label、GT或controlled_sources。query含xyz/yaw，fresh_boxes含本地ID、时间、新鲜度、类别及几何。

- [ ] I采用参考框与本车新鲜车辆框的BEV IoU。沿用3米中心关联界，要求类别相容和正重叠。相容关系在同一job/frame全部查询与本地框间计算，查询和框均只能有一个相容对象，歧义时I不可用。
- [ ] 参考框h/w/l来自clean fit接收车新鲜车辆框的逐轴加权中位数。权重先父、再局部轨迹、再时刻均衡。shape缺失或非法时停止本地模型生成，不填默认形体。参考框xyz/yaw来自当前因果查询。
- [ ] F在参考框局部坐标内构造0.25米栅格，只遍历相交真实射线的框内段。最后一格采用截断体素；分数采用穿越体素的实际体积占参考框体积，避免末格大小不同造成偏重。只标记有正长度穿越的体素；点所在终点体素标occupied，occupied优先；其余unknown。几何边界采用半开格，最外边界归最后一格，角点擦过不增加体积。
- [ ] 点云为空且输入合法时F=0并标记无覆盖。点云/位姿损坏、时间不对应、非有限geometry为故障未知。无检测仅使I不可用，不使F自动为反证。
- [ ] runner每父只重建一次可信ego本地跟踪，复用冻结npz检测，按完整时间顺序更新及调用既有fresh_tracks。每job使用其原查询单独关联，不能把不同攻击回放的重复查询放入同一个匹配问题。
- [ ] 相同父、ego、frame只读取一次PCD与位姿，供该帧全部job/query使用。存储`local.jsonl.gz`侧录，键为原job/frame/id，附receiver_id、I/F、raw资格、frame/时间和状态，不写入GT。
- [ ] 定点验证包括回波在框前/框内/框后，零点与缺文件区别，终点占据覆盖穿越，旋转框与坐标变换，稀疏射线只影响穿过体素，以及重复/歧义检测不能成为支持。检测和跟踪不因侧录改变。

### Task 2: 顺序校准、三态与共同输入比较

接口 `calibrate(cal_rows, required_layers, mode)` 返回tauF、tauP、tauR、tauC及分支状态、预算、父/实体覆盖。`decide(public_row, policy, mode)` 只消费在线字段和冻结参数，返回decision/reason，不接收标签。

- [ ] 按设计第6节顺序确定四个门限，raw F与raw I校准不借冲突减少各自错误质量。F、R使用严格大于；I、C使用大于等于。关闭门限为正无穷，I资格必须严格正重叠，不以数值0代替缺失。
- [ ] 先冻结共同本地门限并形成local accept/reject/unknown/conflict。冲突与输入故障直接unknown。强本地分支不受消息数量覆盖，普通localunknown才进入消息分支。
- [ ] 分别计算实际本地真误拒、假误采后，再使用整体5%剩余预算。若任何已有本地风险已超总预算，返回不可行，不能截成0后声称已通过。tauR先确定且只看正常cal，tauC后确定且检查每个声明假层。无正质量可行区关闭采纳。
- [ ] 校准资料缺少声明的假层时关闭本地及消息采纳，并标明不可估；不能跨族默认为零风险。小样本父/实体数完整报告，不声称总体保证。正式效果清单必须在运行前绑定；本规格不私自重分旧数据角色或用旧eval挑新门限。
- [ ] 三方案共用同一侧录和本地门限：Local（只有本地），LocalCount（本地未知时以有效未报数量作为拒绝分数、Count作为采纳分数），LocalCond（拒绝分数改为现有条件R，Count采纳分数相同）。后两者分别按同一规程校准消息门限。可见性、候选、真假分母和错误预算相同。
- [ ] 复用既有primary、weights、六格、父/实体分层及配对时效。额外输出local状态分层与相对LocalCount的决定转移。完整候选保留，本地未知不得移出分母。结果不归因于尚未接入的Joint。
- [ ] 定点验证分支冲突、单一可信支持、无可行门限、缺假层、假层分母、真/假预算分离、远端沉默不能翻转本地支持、普通unknown可按冻结规则决定、故障unknown不得变成拒绝。用手算小表检查校准结果及关闭行为。

## 实施验收与效果验收分开

工程验收是侧录完整对齐、输入权限正确、几何和校准定点检查通过，旧结果未被改写。它不代表方法收益。

研究假设是新增本地观测能提供可用的真实性证据，且同本地信息下条件反证能超过未报计数。研究结果至少同时报告真假六格、整体与攻击层风险、真实采用损失、本地未知组效用及运行成本。相对LocalCount沿用2个百分点真实采纳损失、5%工作风险和1个百分点CD增量作为初始比较要求；这些数值及数据清单须在效果运行前绑定，不因失败放宽。

本轮可以进入上述方法实现。效果运行还须形成确切fit/cal/eval、固定receiver和required_layers清单，并一次核对现有校准覆盖。已有cal假侧覆盖薄弱是已知限制，不重复盘点全数据，也不把函数返回门限当作覆盖充分。清单不足时先明确哪一项参数/层不可估，不能盲目启动正式结果批次。
