本文保留当时经独立核对的计算设计，独立与联合分支现均已执行，效果状态以最新结果为准。它是目标真实性核验中的有限方法模块，不是任意串谋安全的完整系统。唯一主入口为[当前方案](../研究点一_当前方案.md)。

## 1. 为什么选择这一改法

上一版二近父规则可以计算，但其度量没有充分任务依据，明确拒绝还受有限假参考区域限制。继续剪尾、增加邻居数或分上下文，会同时引入新的统计选择。因此，撤下其主判决地位，保留原文和审核作为历史设计。

本次不重新学习整个真假评分。采用已经保存的 Count 作为固定基础核验器 Base，新增条件反证只允许将 Base 的正常采纳或未知改为拒绝，其他判决保持。由此能在实验前证明，不会新增假采纳，既有假拒绝不会减少；真实采用可能损失，须单独控制和报告。

Count 是有监督的五变量评分，不是两车支持硬确认。选择它是基于已查看的开发结果作出的设计决定，不是独立终测结论。最后一批 mixed 中其假采纳为 0.43%，假未知为 40.86%，为新增核验留下了明确任务空间，但不证明新增模块能识别其中多少。

## 2. 保留的任务与信息边界

来源数、受控数量和身份未知，不假设多数诚实，不增加可信自车。正常误检和正常错误关联到假目标不在当前范围，正常漏报仍在。真实标签来自明确 GT 对应，虚假标签来自声明注入；GT 未匹配不补假。

预查询、消息关联和当前条件保持原因果顺序。U=1 为新鲜支持，U=0 为有合法新扫描机会却未新鲜支持，其余未知。缺包、FOV 外和条件缺失不能补 0；coast 不算新支持，同源同扫描重复消息不重复计数。

p_D 使用距离、方位、FOV 余量、预测不确定性及九射线潜在阻挡 C，来自 clean 正常真实记录。C 缺失带显式指示，基础条件无效则该源未知。C>0 且主阻挡 ID 相同的来源构成共同组。分组先于当前 U，GT 和回波不进入在线计算。

每目标保持最近十个合法同步扫描，当前约一秒。每次重算窗口，不把上次总分再加入。生命周期重启、注册源集合改变或时间不连续时重开窗口。前端可携带更早合法历史，不恢复 Z 残差过滤、攻击身份过程或目标消失模型。

新判决不反馈到共同前端、查询生成、来源信誉或后续轨迹状态。全部对照使用相同候选流。这是后文判决集合性质的必要实施条件。

## 3. 基础判决到底从哪里来

固定原 Count 的输入顺序为

`x_B=(n_plus,n_minus,w,d,m)`。

其中 n_plus/n_minus 为窗口有效报告/未报次数，w 为扫描数，d 为有效来源数，m 为有过新鲜支持的不同来源数。其分数为

`S_B = intercept + coef^T*((x_B-mean)/scale)`。

系数、尺度及采纳/拒绝门限全部复用原模型，不因新增反证重拟合。它原来使用真假加权 logistic 损失，非截距 L2 为 0.005。原三态资格及门限保持，不能把 Base 改成只有采纳输出，再与原完整 Count 比较来制造拒假增益。

实际产物位于 `docs/evidence/rq1_report_freeze_2026_11_13/run_001/models/{regime}.json` 和 `calibration/{regime}.json`，读取其中 Count 项。源码语义见 `scripts/rq1_report_freeze/run.py` 的 `count_inputs`、`fit_count` 及原共同决策函数。

mixed 使用原 mixed 模型；两个族迁移分别复用其源族训练与校准的 Count。目标假族不进入模型或门限。现有部分 family/k 缺校准的标记继续保留，不因新模块而变成已经校准。

因此，采纳仍来自声明攻击域下的经验判别与风险校准，不来自“正常模型未拒绝”，也不来自“两个来源必有一个诚实”。Base 的局限完整继承，新模块只改变反证处理。

## 4. 新反证的唯一计算式

每帧按同一 p_D 构造正常联合分布 Q。组内为独立 Bernoulli 与共享均匀变量生成的共单调 Bernoulli 的混合，组间条件独立。

\[
Q_g(u)=(1-\rho)\prod_{i\in g}\operatorname{Bern}(u_i;p_i)
+\rho\max\{0,\min_{i:u_i=1}p_i-\max_{i:u_i=0}p_i\}.
\]

未知维度先边缘化，空 min=1、空 max=0。p_i 截在 [10^-6,1-10^-6]，rho 只在 {0,.25,.5,.75,.9} 中选择。三种事件概率从同一个分布计算，不分别截断联合概率。

令 P_t 为当前实际报告来源，M_t 为当前有效未报来源，定义

\[
R_W=-\sum_{t\in W}\log Q_t(U_i=0,\ i\in M_t\mid U_j=1,\ j\in P_t).
\]

等价的实际计算是

\[
R_W=\sum_t[\log q_t^+-\log q_t^{all}]=B^-+C_{\pm}\ge0.
\]

这句话的含义是：**在已有这些车辆报告的情况下，如果目标真实且报告过程符合正常参考，其余有机会车辆出现这些未报有多反常。**

空 M 时本帧贡献为 0。空 P 时 q^+=1，成为完整未报事件的信息量。计算使用对数域。明显数值失败不能当作强反证，详见第 6 节。

报告来源也参与条件概率及共同组计算，不是仅保留未报。如果报告和未报来自同一正常共同组，报告可能提高对另一来源报告的预期；若新增正报告属于完全独立的组，其概率在分子分母中抵消，不会靠更多独立正报告直接冲淡既有反证。固定其他条件时，新增 p 趋近 0 的未报源对 R 的增量趋近 0。

P/M 是观测后得到的集合。因此 R 是用于校准的正常条件异常评分，不是直接有效的 p 值，不是不存在概率。跨帧只作窗口复合分数，不假装十帧独立或给出完整时间序列概率。

## 5. 参数怎样得到

p_D 继续使用现有 clean 模型及完整留父规程。rho 用 clean 折外当帧联合负对数概率，从上述固定网格选择，平局选小值；不能复用旧 HMM 的 rho。fit 留出父不能进入该父的 rho 选择，必要时在其余父内部选择。最终 rho=0 时，完整退回独立反证版本。

R 的门限只看 clean 校准，不读取假目标来最大化拒假率。所有真记录沿用原父、query epoch、时刻均衡权重 w_i，合计为 1。标签未知不补真或假。

R 的学习只用正常记录，但 Base 本身来自真假监督，其既有误拒决定剩余预算，所以 tau 也间接继承 Base 的选择。不能将整个方法宣称为完全不依赖假族。

先计算 Base 在同一完整 clean cal 分母中的真实误拒率 e_B。新增真实误拒预算为

\[
\delta_{add}=\min\{0.02,\max(0,0.05-e_B)\}.
\]

0.02 是预声明的额外真实代价上限，0.05 是原总误拒工作点，两者都是实用容差，不是理论常数。如果 e_B 已超过 0.05，关闭新增模块仍不能声称总误拒合格。若 delta_add 为 0，新增模块关闭并明确原因。

令 E_i 表示 Base 正常可判读且非拒绝、合法查询与原拒绝资格成立、新模块必要计算有效。门限候选仅来自这些记录中的正 R_i。选择满足

\[
\sum_i w_i\mathbf1\{E_i,R_i>\tau\}\le\delta_{add}
\]

的最小正观测值 tau。并列等于门限时不新增拒绝。权重不能在 E 子集中重新归一化。无正候选、必要模型不可估或必要校准评分发生数值失败时，新增模块不可用，不能静默删记录后重新校准。合法的机会未知不是数值失败。

候选最大值总能让校准新增拒绝为 0；找到门限只说明经验约束可计算，不说明模块有实际识别能力。不能把关闭或零新增判决包装成方法通过。

## 6. 最终三态规则

顺序固定如下。

1. Base 已经拒绝，保持拒绝。
2. Base 因公共数据或数值故障而未知，保持故障未知；不能把故障未知变成新方法成功拒绝。
3. 新反证模型不可用、校准分支关闭或当前计算失败，保持 Base，并记录未启用或 degraded 原因。
4. 其余正常可判读的采纳/未知，若具有原拒绝资格且 R>tau，改为拒绝。
5. 其他情况保持 Base。

原拒绝资格为至少两个来源有有效事件且有至少一次有效未报；原采纳资格为至少两个不同来源有新鲜支持、当前有身份相容的可输出轨迹。单个有效来源、真正新生无预查询等情况仍为未知，不新增可信初值。

正常计算得到的未知可以被反证拒绝。模块计算失败不能通过临时把有效来源改成未知来装作成功。降级和失败记录留在共同六格分母，并单列模块有效覆盖，不作为效用证据。

这里不存在“必须接近 F1/F2 才能新增拒绝”的条件。未见攻击是否能拒绝，取决于有效反证，而不是与已知假轨迹的几何距离。

## 7. 实验前能够确定的作用

对固定共同输入和同一个 Base，有

`Accept_new subset Accept_Base`

`Reject_new superset Reject_Base`。

因此，对同一输入分布，包括任意给定攻击样本分布，假采纳不会增加、假拒绝不会减少。真实采纳不会增加、真实误拒不会减少。它是相对 Base 的逐输入性质，不是任意攻击绝对风险不超过 5% 的保证，也不适用于两套算法改变了各自后续候选的闭环系统。

clean cal 中，真实采用损失不大于新增真实误拒，后者不超过 delta_add。新录制上仍需评价，不能继承成部署风险保证。

若真实采纳损失为 a、新增假拒绝为 f，则

`Delta_CD=(f-a)/2`。

因此不能承诺 CD 必然提高。原 Base 的错误拒绝也不会被本模块恢复。这是有意收缩的能力范围，不再宣称本次同时解决全部误采纳、误拒绝和未知问题。

## 8. 联合机制的两个可计算作用

固定两源 p=0.7、rho=0.5。

- 同组两源都未报，该组无报告条件时，独立反证为 -log(0.09)=2.408，联合反证为 -log(0.195)=1.635。该模型减轻共同未报被重复计算的程度。
- 同组一源报告、一源未报时，独立条件未报概率为 0.3，联合为 0.105/0.7=0.15。反证由 1.204 增至 1.897。该模型加强报告分裂的不相容程度。

所以联合不是统一降低反证。如果门限落在对应两分数之间，二者可以产生不同决定；实际门限须由 clean 校准，不用算例指定。异质边际和其他组合不承诺统一方向，实际分组是否可靠也仍需证据。

## 9. 必须怎样比较，什么才算有效

核心比较只有固定 Base、Base+独立条件反证、Base+联合条件反证。后两者共享 p_D、输入、窗口、资格、clean 预算和相同校准算法，只有 Q 的依赖结构不同。简单组平均反证作为额外减权对照，定义为逐帧按有效组大小平均各有效未报的 -log(1-p)，再在窗口累积；它不额外平均计数或更改 Base。

具体为 `R_G=sum_t sum_g [sum_(i in g且U=0) -log(1-p_i)]/|E_gt|`，分母 E_gt 是组内全部有效事件来源，包含报告者和未报者，空组贡献 0。它是简单减权分数，不伪装成条件概率。Base 窗口及其重置完全复用，新模块不能另外改变被冻结计数输入。

判决层效果看新增的假未知转拒绝、假采纳转拒绝，以及真实采纳/未知转误拒的代价。整体真假六格、CD、family/k、父录制、实体和配对时效完整保留。基础 Count 的原拒绝不删除，不能与被弱化成全未知的基线比较。

预声明开发标准保持为：总真拒绝及每个已评价假层误采纳不超过 5%，相对 Base 真采纳损失不超过 2 个百分点；新增模块相对 Base 的 CD 至少提高 1 个百分点。联合主张还要求相对同边际独立及组平均的 CD 各至少提高 1 个百分点，不能只比 Base。真 epoch 从未采用比例增加不超过 2 个百分点，共同曾采用 epoch 的配对首次采用延迟差加权中位数不超过 0.5 秒。

未知受控数量设定不变，指标按实际 k 分层，空层和缺校准层明确标记。族迁移两方向分别评价，不平均抵消失败。旧评价材料已看过，仍是开发证据；本轮不自动安排新任务清单或启动实验。

如果只减少未知但误拒超过预算，或联合不超过独立对照，则相应方法主张不成立。模块全部关闭不算通过。不在看结果后放宽剩余预算或重新训练 Base 求通过。

## 10. 依据、局限和当前状态

条件概率的分子分母来自同一个正常联合分布，计算本身是概率链式分解。独立与共单调混合复用 [Bae 与 Iscoe 的已有构造思路](https://onlinelibrary.wiley.com/doi/10.1155/2014/838625)，异质 p_D 与几何分组仍是项目建模选择。

固定评分后，用独立正常校准限制某类错误与 [Tong、Feng、Li 的 NP 思路](https://pmc.ncbi.nlm.nih.gov/articles/PMC5804623/)相关，但这里是相关窗口的经验预算，不冒称其独立同分布下的概率保证。不是引用了检验论文就得到总体风险证书。

真实目标在恶意消息操纵下的过程未必符合 clean 参考，条件代理也可能失准。Base 可能错误，新增模块只能继承并有限修正，不能恢复其原有错误拒绝。没有独立可信观测、又允许任意串谋时，完全相同输入的真假仍不可识别。

本次研究贡献的候选是**相同校准误拒预算下，条件反证及依赖处理能否比固定基础核验和独立条件处理拒绝更多假目标**。各方法离散门限对应的实际误拒率不必恰好相同，须完整报告。公式可算、集合性质成立或工作量完成，不足以证明达到论文标准。

独立研究审核已确认概率定义和逐输入性质，要求补齐故障未知、门限候选集合及共同前端条件，本稿已修订。书面复审见[设计审核与性质记录](../REALLY/条件反证补充核验_集合性质与设计审核_2026-11-16.md)。独立与联合分支均已另立规格完成比较，最新取舍见文首链接。

- 真误拒转未知只能称减少明确误拒，不是恢复真采纳，其本身不提高 CD。假拒绝转未知也计入代价。预先写明主要效用、允许拒假与采纳损失，以及同校准预算不等于实际误拒率相同。冻结具体数值后才运行新比较。
- 需要更多已有录制时，按预定观测条件和父录制选取，不能按模型失误或得分选择。无需等两条旧案例先证明效果才扩覆盖，也不重新进行数据盘点。机制分层只支持该条件内结论，完整分母用于整体效用，未参与设计选择的录制用于独立确认。
- 本次不撤下已有 Cond，也不声称联合算法已完成。下一阶段交付应是明确作用对象与判决范围的联合实现及有界比较，不再将方向认可等同于效果认可。

**后续状态：本节的单阈值正报告异常度候选已否决。** 即使在追加mixed评价资料上事后选最有利门限，真采纳损失不超过2个百分点时最低全局误采仍10.5114%；若全局及各攻击层误采都不超过5%，最低真采纳损失15.2277个百分点。见[可达性上限记录](../evidence/rq1_positive_report_scope_2026_11_17/oracle_gate_feasibility.json)。这是候选否决检查，不是正式校准或新效果。下文保留提出时的依据与边界，不再作为待实施方案。用户随后允许可信接收车，新设计另见[本地观测修订](可信接收车观测_修订设计_2026-11-17.md)。

考虑了三个做法。继续调联合强度不能改变无有效未报的记录，撤下。所有零反证采纳转未知在追加资料会损失29.4477个百分点真实采纳，撤下。建议保留Cond拒绝端，对拟采纳记录补做正报告条件复核，优先使用已计算的 `Splus=-sum_(U=1)log(p_D)/n_plus`。现有同父、同计数比较有局部排序信息，但只涉及一个失败实体，不能预设可达到风险目标。旧整体D_head已经用过这些信息且没有建立完整方法效果，不自动恢复旧评分。

候选规则只允许把Cond拟采纳但正报告异常度过大的目标改为未知，其余保留Cond。高Splus表示正常模型下反常，单靠它不足以判假；低Splus表示未发现这种反常，也不是物理存在证明。正常模型预测的是给定真实目标与条件的报告行为，不是报告来源诚实概率。来源数量未知、受控数量未知、无默认可信自车的范围保持。

若实施，门限应在独立正常校准组按完整主真分母限定新增真实采纳损失，而非在这36条错误上选值。候选损失预算为2个百分点，须在实施规格中冻结。固定同输入时，误采纳只能下降或不变，但真假拒绝均不变、真采纳只能下降或不变，故CD不会因此提高。评价目标应明确为同等真实采纳损失下减少误采纳，不能复用“CD增加1个百分点”的旧拒绝端收益标准。与仅收紧Count采纳门限的简单控制比较，三态六格和族迁移完整保留。最终还须评价原5%风险目标，校准上满足损失预算不构成跨录制保证。若风险和采用代价无法同时满足，应拒绝此候选，不能靠扩大Unknown宣布完整成功。
