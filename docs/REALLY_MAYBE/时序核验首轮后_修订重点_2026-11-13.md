# 时序核验首轮后的修订重点

2026-11-13。依据[首轮结果](../REALLY/时序条件联合核验_首轮开发结果与方法决定_2026-11-13.md)提出的下一步候选，不是已实现算法，也没有新效果结论。目标仍是目标真实性核验，不重开K1、驾驶或攻击者身份动态系统。

## 已经能够作出的决定

当前联合计算不是首要瓶颈。J相对T只有0.64个百分点正确明确率增量，假侧s变化使J真采纳变化接近19个百分点。主结果相对同政策MATE损失20.18个百分点真采纳，不能靠更多明确拒假解释为整体改善。

下一轮以采用权衡为主线，同时完整报告拒绝和未知。原5%主结果及预声明保留条件不追改。先固定联合算子、窗口和三态资格，不同时替换多个模块。

## 最小正常侧候选

当前报告发射只读取X和回波代理Z，C经初始化和转移间接进入；h_C的C系数实际为0。候选改为让同一合法几何条件直接进入报告概率：

`logit P(U_i=1 | Z_i,X_i,C_i) = beta0 + betaX^T X_i + betaC*C_i + delta*Z_i`。

这沿用输入输出HMM的形式。原始论文允许输出模型同时依赖状态与当前输入，参见[Bengio与Frasconi的IOHMM](https://proceedings.neurips.cc/paper/1994/file/8065d07da4a77621450aa84fee5656d9-Paper.pdf)。文献支持模型形式，不证明该适配能改善V2X真实性核验，也不是新的算法创新声明。

具体意图是避免要求几何线索先能预测“GT框内有无一个点”，才允许它改变报告证据。保留delta非负和betaC非正的首轮约束作为可审候选。使用与D一致的合法条件；若去掉Z作用，正常侧应能退回直接条件模型，防止复杂模型通过减少输入而输给D。

可优先删除已无增量的独立h_C初始化拟合，复用h_B初始化。缺C不能伪装为无遮挡，缺失编码和回退需在短规格中明确后再实现。此处不是“只差训练”的完整新方案。

预期作用是改善受限未报告的单车概率，同时保留时间信息。失败条件同样明确：如果D仍更好、只把更多目标改为未知，或多控F2假采纳升高，则不保留此改动。不借修改rho、s或门限掩盖结果。

## 假侧与初始化先澄清什么

s=.9只是参考，不是学得的攻击转移率。不能因s=.5的结果好看就改用它。需要把哪些报告模式由威胁条件允许、哪些只是参考先验，以及哪些属于全受控不可辨识边界分开。

尤其应区分“主实验至少有一个正常来源”和“算法在每个窗口保证至少有一个始终正常来源”。后者不能仅凭本批录制条件默认成立。如果要限制假侧给全部来源支持分配的概率，须先明确正常来源不报假目标及来源身份在窗口内的假设，不能暗中加入诚实多数或固定攻击数量。

本轮唯一误采在首个核验窗口，显示初始多源报告可能被给出过强相对证据。下一规格需要明确新生选择条件或共同初始策略。若使用等待帧数等政策，必须对所有对照同样施加，不能归为联合建模贡献。暂不引入A/H联合动态状态，也不凭这个单例指定一个“保证有效”的暖启动长度。

## 有限推进顺序

1. 先完成假参考和首个窗口的短语义修订，明确不能识别的情况。当前已实现的四族参考保留作对照，不冒充真实攻击行为分布。
2. 在同一语义和固定参照下，只实施直接条件发射这一项正常侧变化。复用本批已完成的消息、query和标签，不重跑检测或扩大数据盘点。
3. 先回答是否减少真实采用损失，以及是否超过D/T/G；再评价联合项的额外作用。涉及F3时先补足可构造性，不能把本轮缺测当作鲁棒证据。

这是由实际结果约束的修订路径。新参数、实现与效果尚未产生，本轮有界实验在此结束。
