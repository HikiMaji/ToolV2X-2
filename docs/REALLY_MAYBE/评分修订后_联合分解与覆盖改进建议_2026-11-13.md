# 评分修订后的联合分解与覆盖改进建议

2026-11-13。用户问“怎么改进”。这是根据实测、代码和文献提出的讨论候选，不是新主方法已经获批、完整SDS已冻结或新效果。实际方案仍以[当前方案](../研究点一_当前方案.md)为准，旧数值裁决不修改。

## 1. 优先改什么

推荐先解除当前联合增量中不同报告模式共用一个系数的限制，保留正常表征、固定基础I、10扫描窗口、监督与共同三态规则。D继续作为开发底座和必须超过的强对照，不同时把normal换成D后再将差异全归因于联合修正。

比较过三条路径。只改训练损失不能恢复被单个delta压缩掉的模式信息；直接换树模型、Copula或完整状态模型会同时改变太多部分。组内共同未报分解可以只多一个系数，明确回答现有表示是否绑住两种不同作用，因此优先提出这项。

## 2. 问题依据与可计算修正

[代码审查与解析特例](../REALLY/联合修正同号与参数语义_代码审查_2026-11-13.md)表明，A报告且同组B/C未报，与A/B/C都报告，可以得到相同的正delta。这不是概率错误，但一个c会把两者的联合修正一同提高或降低。

令H_t为截至前一时刻的合法历史与当前可用条件。对当前几何共同组g，取有效事件集合V_g。保持原预测状态及原发射模型，计算

`delta_g,t = log P_T(U_Vg | H_t) - sum_(i in Vg) log P_T(U_i | H_t)`

组外当前报告和组内未知来源均被边缘化，不先用当前U更新状态。只有V_g至少两个来源且全部未报时，将该组delta加入

`Delta_00 = sum_(t,g) 1[组内至少两份有效事件且全为0] * delta_g,t`。

新候选为

`S_new = S_I + c*Delta_T + eta*Delta_00`。

- 原Delta_T仍包含报告、未报、混合组合及历史跨组依赖。
- eta只允许共同组的全未报模式与其余模式有不同修正。A=1、B/C=00仍会进入该项，不要求整帧全未报。
- c与eta均由fit真假监督估计，符号自由，允许为0。不能预先强迫真实目标恢复。
- eta=0时模型形式包含原J。由于正则和特征缩放会影响拟合数值，不能据此声称重新拟合必然复现原J的具体系数。
- 不用组delta之和替代全局delta，因而不默认为当前各组历史独立。

统计框架仍是固定offset的正则logistic交互项，不增加攻击者身份状态、任意攻击概率先验或新的目标消失模型。具体分解是本项目候选适配，不冒称文献已有完整同款算法。

## 3. 预期作用与必须保留的反例

若原单系数确实使共同漏报与一致报告的两种用途相互牵制，新项可在保留其他报告模式作用的同时，减少有共同原因的漏报对真实目标的重复反证。独立、良好条件的未报若没有对应共同组，不应仅因数量多就得到同一额外修正。

预期是可检验的假设，没有承诺数值增益。当前几何组可能错误、Delta_00可能接近常量或主要反映事件数量，增加一个系数也可能过拟合。

关键不利情形是假目标先多源报告、随后共同沉默。它也可能得到共同未报修正，降低假拒绝或延长错误采纳。只展示真拒绝下降不能判成功。来源未知时，真实和虚假过程的全部合法输入若相同，当前方法无法凭空区分，证据不足时只能保留未知。

正报告仍进入正常边际、基础头和完整Delta_T。a_plus=0不强制改成非零。若后续要更换正报告表征，应单独解释新增可辨别信息，不能以作者希望正报告质量有效作为依据。

## 4. 一次有明确结论的比较

最先只改变增量表示，固定normal与I参数、输入、W、训练权重、损失、共同政策及校准程序；不同时加入GroupDRO或新攻击构造。新分数各自按同一cal规程选门限，不沿用旧分数数值门限。

至少保留以下对照，新增的三个增量头均为两个自由系数。

| 对照 | 要排除的解释 |
| --- | --- |
| I与原J | 是否超过不加联合、只加原delta |
| I + v1*Delta_T + v2*Delta_T^2 | 是否只是多一个非线性参数 |
| I + v1*Delta_T + v2*n_00 | 是否只记住共同全未报组出现次数 |
| D及既有G | 是否值得优于简单条件模型和组平均 |

n_00为同一窗口中满足新增项触发条件的组次数，使用相同在线条件，不含真值或攻击身份。模式判断使用当前U属于待分类事件的合法特征；分组本身仍只能用当前U之前的条件。

完整六格和分层预算继续保留。重点同时比较共同未报真目标、良好且分散的未报假目标、多源伪报后的共同沉默。需要同时给采纳/未知/拒绝转移，不能把真拒绝转未知全部当作真实采用提升。只有局部收益且整体不超过D，仍不能称主方法成立。

在拟合之前冻结缩放、正则参数化、两增量可辨识与父覆盖要求、统计区间及数字通过门槛。本建议没有用看到的新分数选择这些值，也没有宣称实施规程已经完整。旧版c区间的限制不能被两个点估计替代。

若只有多参数对照也能取得同样增量，不能归因于共同原因机制；若该分解仍没有额外收益，不再沿此分解连续堆更多模式系数。

## 5. 假侧与数据应该怎样改

仍保留声明攻击域内的两类监督，不重新手设一个假目标概率去解释所有情况。双向迁移失败尚未识别唯一捷径，因此不提前认定位置或持续时间就是原因。

若上述结构候选显示必要性，下一批应改善研究覆盖，而不是给旧批次补样本凑通过。利用已登记47段资产选择新的独立父录制，优先四车以上，使k=3等关键训练/校准/评价层分别有多父支撑。不得以多seed代替多父，不恢复数据全量盘点或训练感知骨干。

在预先指定的可比较层内，同时覆盖真假两类的有效来源数、支持来源数、窗口长度及粗观测条件。可采用预定配额或分层权重，未覆盖层保留报告而非删掉；补充匹配分析与原部署分母分开。目标是避免仅凭构造时段、固定角色或数量关系取得高分，不将匹配当作已证明消除了所有捷径。

候选结构和新的覆盖安排应分步比较，不能一次改两者后将改善全归算法。源族单独实验继续排除目标族的训练、标准化及校准；不能借补覆盖破坏迁移定义。少数攻击实体仍不足以支持一般真假分布。

## 6. 相关文献究竟支持什么

1. Roos等，2005，On Discriminative Bayesian Network Classifiers and Logistic Regression，Machine Learning 59:267–296。核读作者PDF第1至4页关于联合与条件似然、统计量及logistic参数化的论述。它支持依赖模型用于分类时应关注判别目标，以及使用结构化统计量进行logistic学习；文中的图条件和等价定理不能自动套到本项目隐状态核上，也不证明本次Delta_00分解有效。[作者原文](https://www.cs.helsinki.fi/u/ttonteri/pub/mlj05.pdf)
2. Sagawa等，ICLR 2020，Distributionally Robust Neural Networks for Group Shifts。核读原文摘要、问题设定及组风险讨论。它研究预定义训练组的最坏损失与正则，不能保证从F2外推到未见F1，也不能替代缺失的组覆盖。因此暂不把GroupDRO作为首轮修法。[原文](https://arxiv.org/html/1911.08731v2)
3. Zhou等，ICML 2021，Examining and Combating Spurious Features under Distribution Shift。本次核对原始摘要，指出预定义分组没有覆盖相关伪相关时，group DRO也可能失败。这里只用于限定“换损失即可解决捷径”的说法，没有直接采用其算法或声称完整复现。[原始摘要](https://arxiv.org/abs/2106.07171)

当前没有新的实现、训练、攻击或结果。独立只读审查已核对组边缘提取及跨组历史依赖边界；完整实现规格仍须在采用此候选后明确。

独立讨论审查未发现阻塞性逻辑错误，但这不等于完整规格审核通过。明确Delta_00是按合法报告模式选取的判别特征，不是新的完整窗口联合log概率；假目标在A持续报告、B/C未报时同样可能获得补偿。新项胜过计数和同容量对照也不能独自证明几何组就是物理共同原因。
