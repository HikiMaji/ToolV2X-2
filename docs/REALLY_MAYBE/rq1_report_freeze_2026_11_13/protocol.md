# 汇报前唯一一次实验规程

2026-11-13。用户要求尽快拟定可制作PPT的方案，汇报前仅保留一次实验。**方案定稿，实验包装器尚未实施，未消耗这次实验机会。** 本批冻结现有方法，扩大当前评分模型之外的父录制评价，并补必要对照。机器清单为[config.json](config.json)，设计审核见[design_review.md](design_review.md)。它不是新联合算法开发，也不重判旧失败。具体汇报正文见[六页PPT文案](../../研究点一_汇报PPT文案_2026-11-13.md)。

## 1. 方法选择和本次要回答的问题

汇报主候选固定为D_zero，D_old保留为原评分对照。主候选不是已通过整体替换的最终算法。I_zero/J_zero用于检验现有联合机制，不将它们接到D_zero后面冒称同一概率路径。三项比较在同一批完成。

1. D_zero对Count/CountQ，判断连续观测条件是否提供超出计数的判别价值。
2. D_zero对D_old，判断只未报来源常数约束在额外父录制上是否维持效用。
3. J_zero对I_zero/G_zero/Q_zero，判断现有联合修正是否超过相同边际的基础头、组平均和同容量增量。

采用这一路线是因为D_zero已有结构与正负效果依据，而新的事件交互尚无可靠跨父作用依据。仅在原评价集重算不能增加跨父证据。另起新检测或新联合表达会把这次机会变成前端和方法共同变化的开发批次。

## 2. 主算法固定内容

对已有候选X，预测查询先于当前消息匹配。来源事件为fresh支持1、有效扫描机会下未fresh支持0、未知-1。缺包、FOV外、机会不明均不补0。自身来源计一次，不默认可信。

以距离、方向、FOV余量、预测不确定性及潜在阻挡C估计正常报告概率p。D_zero使用冻结直接条件模型；GT、回波和攻击身份仅离线使用。概率是正常情况下的报告概率，不是目标真实概率。

窗口为最近10个同步扫描，当前约1秒。对每源计算：

`L_i+ = sum_(U=1) log(p_it)`

`L_i- = sum_(U=0) log(1-p_it)`

`e_i = a_plus*L_i+ + a_minus*L_i- + b_plus*n_i+`

`S_D = b0 + sum_i(e_i) + beta*m + c_w*w`

其中m为窗口内曾fresh支持的不同来源数，w为实际扫描数；a_plus/a_minus非负，其余自由。现有拟合中a_plus为0，不强制改成非零。只未报来源的条件无关常数gamma严格为0。固定其他项时，低p未报的直接贡献接近0，高p未报反证更强。正报告还通过次数和支持来源数进入评分，不保证每次报告都正向加分。

正常模型仅用旧clean fit拟合。评分系数来自旧fit的真实与明确注入F1/F2假目标，训练用父录制折外正常表征。假侧由声明攻击范围内的监督提供，不恢复手工Q_F。未知受控人数不作为在线输入，不保证任意串谋可识别。

每帧重算窗口，不重复累加旧分数。采纳需至少两源fresh支持、当前输出相容且S达到A；拒绝需至少两源有效、至少一次未报且S低于R；其余未知。新生无预查询或单源有效为未知。A/R沿用独立cal选择，经验两类错误预算各5%，不是部署风险保证。

联合扩展维持`S_J = S_I + c*Delta_T`。I的p来自现有正常联合过滤，Delta_T为同一正常模型相对逐步同边际乘积的窗口log概率修正。固定I再学c，报告与未报都参与。与D的差别不只一个c，故只有I/J可作该增量归因。

## 4. 九个方法及参数来源

| 方法 | 参数处理 | 比较目的 |
| --- | --- | --- |
| Count | 仅旧fit一次拟合 | 无条件概率的计数对照 |
| CountQ | 固定Count后加一个平方增量 | 避免把简单计数非线性当条件贡献 |
| D_old | 复用旧模型与门限 | 原基础评分 |
| D_zero | 复用旧模型与门限 | 唯一主候选 |
| I_zero | 复用旧模型与门限 | 同联合过滤边际的基础头 |
| J_zero | 复用旧模型与门限 | 已有联合增量 |
| G_zero | 仅旧fit一次拟合 | 同概率表征的组平均对照 |
| Q_zero | 固定I_zero后加一个平方增量 | 与J同增量参数数的对照 |
| MATE_policy | 复用旧数值门限及原机制 | 同政策底座对照，非原论文整系统复现 |

新增对照不是新增主算法。Count使用`n_plus,n_minus,w,d,m`五个原始计数加截距，系数自由，最多6参数。n_minus必须来自实际有效U=0，不得用w*d减n_plus推算。Count与D_zero参数数相同但函数形式不同，该比较不提供对所有计数函数的普遍优越性证明。

CountQ=`S_Count+q*S_Count^2`；Q_zero=`S_I_zero+q*S_I_zero^2`。固定基础分数，增量无截距、无中心RMS缩放，最多多1参数。G_zero使用现成G的分组特征，只将原d系数置0，保留m和分组信息，重新拟合其他项。

新对照沿用加权logistic、非截距L2=.005、常量阈值1e-6、L-BFGS-B零初始/maxiter500/ftol1e-10/gtol1e-6。真假各占一半权重，真按父/epoch/时刻，假按family/k、父/epoch/时刻。G_zero前两系数非负，其余自由；Count所有系数自由。全部尺度只用各自旧fit。

mixed为主结果；F1_only/F2_only为预定压力比较。新增对照也分别按原源族拟合及旧cal校准，目标族不进入标准化、平方缩放或门限。源族评价只取目标假族与clean真记录。既有模型与门限逐项复用，不重新拟合D/I/J或normal/rho。所有新增对照参数和A/R须在新增评价分数生成前完成保存。

## 5. 输出与事前判据

旧、新结果分表，不能合并平均掩盖旧失败。新批每方案输出真假六格、CD、各family/k、逐父、原始计数及独立实体数。CD沿用真假各占一半的原分级口径。另列首窗w=1、短窗w=2至9、满窗w=10，以及配对epoch从未采纳比例和共同曾采纳epoch的首次采纳延迟。

冻结以下开发判断标准，不将其解释为统计显著性或部署保证。

- 主候选在每个方案的总体假采纳及真拒绝均不超过5%，各非空family/k假采纳也不超过5%。
- 相对同方案D_old，D_zero真采纳及CD下降各不超过2个百分点。mixed相对MATE_policy的真实采纳亏损不超过5个百分点。
- 从未采纳真epoch比例相对D_old增加不超过5个百分点；共同曾采纳epoch的首采纳延迟差加权中位数不超过0.5秒。无共同集合记不足。
- 条件贡献仅在上述风险及效用条件满足，且mixed CD分别超过Count、CountQ至少1个百分点时，记为本批正增量。两个迁移方向完整报告，若不满足对应风险或效用条件，不称可迁移条件优势。
- 联合贡献为次要。J_zero相对I_zero、G_zero、Q_zero的CD须在相同评价总体上分别至少高1个百分点，且自身满足上述风险要求，真采纳相对I_zero下降不超过2个百分点、mixed对MATE亏损不超过5个百分点。逐方案裁决，不以一个方向抵消另一个失败。
- 每个计划family/k至少出现于3个不同父、且有3个明确假实体，才用于本批超出个案的方向性裁决；不足记覆盖不足，照常报告比例，不补任务。这个下限只是防止单父个案决定结论的操作门槛，不提供统计把握度保证。任何整类缺失、模型失败、主要任务未完成均不能判通过。

首窗不利结果必须和总体同页展示，不能用满窗改善宣称早期有效。少量父不提供可靠性或显著性保证，本批以逐父配对点差和原始分母为主。即使新增k1/2通过，也不推翻已有k3失败或D_zero未整体保留的历史决定。

## 6. 一次机会的边界及实现安排

一次实验指本规程下的一次固定比较批次，包含全部既定对照和三方案，不是只运行一个命令。先冻结配置与构造，再一次拟合新增对照、一次生成新评价结果、一次独立核对统计。技术故障可恢复同任务并保留日志；不能因效果不好改方法、阈值、种子或新增录制后再跑。

新输出单独放`docs/evidence/rq1_report_freeze_2026_11_13/run_001`。旧产物只读。新增包装器显式登记六父为eval，复用recording_spec、preprocess_new、construct_attack、replay_online、attach_labels及既有评分统计函数。若原函数依赖data.SPLITS，在本批独立进程仅追加六个eval映射，不改旧角色，不热改原文件。预处理仍逐源核对来源、时间与冻结检测检查点，缓存FOV对齐，标签仅在公开回放之后附加。

代码及必要fixture审核通过才启动这一次批次。必要检查限于父/源族隔离、真实未报计数、固定旧分数/门限复用、G_zero约束、标签时序和六格分母。完成后独立重计主要结果，不重训、不再选门限。

## 7. 结果如何进入PPT

通过哪项就报告哪项，失败或覆盖不足同样是本批交付。条件头有效但联合没有增量时，汇报条件证据的阶段性作用及联合未建立，不改称完整联合方法已完成。条件头没有超过计数时，不用已有对MATE的CD优势代替条件贡献证据。技术或覆盖不足时报告实际完成范围，不制造成功。

方法依据使用成熟的条件判别学习和独立校准思想。[Roos等2005](https://www.cs.helsinki.fi/u/ttonteri/pub/mlj05.pdf)讨论概率图模型判别学习与logistic的联系，其结构等价结论不直接覆盖本项目所有约束。[Tong等2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC5804623/)讨论分数与风险门限分离，并指出经验错误率限额不等于总体保证。本项目只保留经验校准，不声称取得其有限样本保证。
