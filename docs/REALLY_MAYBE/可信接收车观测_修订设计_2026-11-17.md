# 可信接收车观测下的目标真实性核验

2026-11-17。用户已确认允许可信接收车自身点云和检测。本文保留当时的设计定义，已按[最小SDS](rq1_trusted_receiver_2026_11_17/SDS.md)实现，并完成固定开发比较。条件反证存在有限增益，完整风险尚未通过；后续分组采纳修正也未满足全部条件。实际状态以[当前方案](../研究点一_当前方案.md)、[初轮结果](../REALLY/可信接收车核验_开发结果与远端采纳缺口_2026-11-17.md)和[修正结果](../REALLY/远端采纳分组校准_开发结果与停止条件_2026-11-17.md)为准。正文原设计时态保留，不表示目前尚未实现。

## 1. 保持的问题与改变的前提

仍核验候选目标是否真实存在，使用报告、未报告及观测条件，输出采纳、未知、拒绝。接收车的本地点云、定位和计算不受消息攻击者控制，但会有漏检、噪声和定位误差。其他车辆受控数量与身份未知，不假设多数诚实。远端消息所报的占据或观测条件不能升级为可信物理证据。

本地传感器攻击、接收车失陷不在这个新前提内。当前数据仍不包含自然误检、正常报告错误关联到虚假目标的情况，不声称已验证这些问题。局部占据物不等于车辆，GT未匹配不补假。

已有单阈值正报告复核候选已否决。评价资料上事后选取最有利门限，仍不能同时满足原5%假采纳和2个百分点真实采用损失要求。不能继续实施它，或把局部AUC写成已有效。此次改变是在用户明确允许下增加本地传感器证据，不恢复旧评分或联合有效性主张。

## 2. 实际输入与接入

- 候选是现有中性前端的预查询框、时间、预测不确定性和身份关联，不用GT框代替查询框。
- 本地输入只来自预先指定的接收车，包括当前原始点云、传感器标定、位姿、时间和未融合的本车检测/跟踪。禁止把融合后的框当独立本地支持。
- 其他来源仍提供当前消息、轨迹新鲜度、报告/有效未报/未知事件及条件代理。未知不补未报。
- 复用现有十扫描窗口和前端，不增加攻击身份隐状态、来源信誉递推或长时消失模型。

执行位置为 `.worktrees/rq1-score-revision-2026-11-13`。`scripts/rq1_temporal/native_adapter.py` 已从每源检测npz建立本地跟踪，再进行中央融合；新本地支持应在融合前提取。`query_geometry`、原始PCD与位姿路径已有，不需重训检测器。现有缓存没有保存完整的独立本地核验事件，不能把接口可接称为已接通。

接收车身份须在查看目标标签和方法分数前固定，并在攻击构造中排除。不能逐个目标挑一辆看得最清楚的正常车充当接收车。旧攻击回放仅在固定接收车确未被注入时可复用；在线决策不读取controlled_sources。所有候选仍保留，不能删去本地不可见目标来提高指标。

## 3. 本地证据的具体语义

### 本地支持

本车未融合的新鲜车辆检测/跟踪与查询框通过类别和空间关联检查，才形成支持。首版支持分数I固定为本车新鲜车辆框与查询参考框的BEV IoU，限定中心距离不超过已有3米关联半径、类别相容、正重叠且双向唯一相容。超过一个相容对象时不取最大分强行支持。只有回波、只有占据、只有历史coast，均不能直接形成车辆真实性确认。关联误差和定位误差的影响由完整正常校准、真假评价保留，不能将3米关联界称为测量精度。

本地支持首次接入先复用已有冻结检测与关联方式，不凭新数据逐例调整匹配门限。必要的位置/尺寸容差须用正常fit资料确定，再在cal检查。新生候选暂沿用共同前端的预查询资格，不用新局部模块额外改出生政策。

### 本地空闲反证

使用带有实际回波终点的本地射线，只在候选参考框内按0.25米体素记录射线穿越、终点占据和未覆盖。首版反证分数F固定为采样穿越体素的实际体积总和除以参考框体积，末格截断并按实际体积计权。未覆盖体素留在分母，终点占据优先于穿越；无射线或全部在遮挡物前终止时F为0，不产生反证。这里是采样射线形成的分数，不代表整个体素已完整观测为空闲。0.25米采用CARLO的工程粒度，不继承其分布分离结论。

参考框的中心和yaw来自因果预查询，h/w/l固定为clean fit接收车新鲜车辆框的逐轴加权中位数，按父录制、局部轨迹、时刻均衡。相同参考尺寸用于全部cal、eval与对照，远端自报尺寸不能控制F的分母。I也用该参考框与本车原始框计算重叠。它核查的是固定车辆参考体积，不证明攻击者所报整框及身份、速度全部正确。真实车辆尺寸差异须保留为分层误差；参考形体不是物理定律。无法从fit取得有效尺寸时本地模型不可估，不编造默认形体。

前方已终止的射线提供遮挡信息；没有回波的方向不当作穿透。框内零回波、没有检测、FOV外或少量射线穿过车窗，都不足以判假。位置、尺寸及定位误差会影响射线判定，须使用固定的几何容差和覆盖要求。不能无条件相信攻击者自报的尺寸，也不能把整个车辆包围框当成实心物体。

第一版只查询候选附近射线，不重建完整占据地图或训练分割网络。自由空间/穿透检查借鉴[CARLO第7节及附录C](https://arxiv.org/html/2006.16974v1#S7)，其作用依据是可检查的观测几何；本文不继承其阈值、分离结论或攻击成功率。

### 未知与冲突

本地不可见、被遮挡、覆盖不足、感知关联不清、数据异常均为未知。本地支持与空闲反证同时成立时标记冲突未知，先检查关联或几何错误，不用远端报告票数裁决冲突。可信指输入未被攻击，不等于观测绝对正确。

## 4. 判决采用分支规则

不新造本地证据与远端证据的任意加权总分。

1. 公共输入故障或本地证据冲突，输出未知。
2. 达到冻结质量及校准条件的本地空闲反证，拒绝。
3. 达到冻结质量及校准条件的本地车辆支持，采纳。该分支不要求第二个车辆报告，也不被任意数量的远端未报直接推翻。
4. 本地无法明确判断时，进入下面的消息统计分支。没有合格的统计判据则保留未知，不直接继承旧Count的采纳。

这些是候选程序的语义顺序。首版支持条件为有效I达到tauP，反证条件为有效F严格超过tauF。两者同时成立为冲突未知。四个门限的选择规程见下一节，数值由cal产生，不能据此声称已有可靠的强支持/强反证。

## 5. 本地未知时如何处理消息

保留现有Count连续分数C作为计数参照，以及Cond条件反证R。此处复用分数，不复用旧三态门限或已保存的采纳决定。

- 有合法反证且R超过正常校准门限，拒绝。
- 未被拒绝且满足共同采纳资格时，只有C进入经过假侧校准的采纳区域才采纳。
- 其余未知。无对应假侧校准资料、样本层覆盖不足或没有可行采纳区时，关闭该采纳分支。

远端采纳是声明攻击族与数据范围内的统计判断，不是任意串谋下的物理证明。未知受控数量是在线不输入k，不等于无需在评价中覆盖不同k。不得用多数投票、任选诚实先验或“大家都说有”补出保证。

已有Count/Cond输入可能包含接收车的消息事件。分支校准必须保留这一实际条件，不把本地结果再乘为一份独立似然。未来若拆除ego计数须在全部对照中同步处理，并重新确定模型，不能偷偷沿用旧参数。

## 6. 参数和校准资料从哪里来

本地匹配与反证资格先用正常fit资料及已有检测关联设置确定，正常cal检验错误反证和采用代价。假侧使用明确注入且已核实不存在的候选以及标签完整的背景候选；未知标签、任意GT未匹配不能补假。背景候选要匹配查询生成、距离和形状条件，且不能冒称覆盖把虚假车辆放在其他占据物旁的攻击。

能估计的是本地事件在明确真假条件下的经验频率及分数分布，不需要攻击者的行为转移概率或来源诚实先验。自然误检缺失意味着对应部署误差没有得到检验；不能估一个零误差就宣称感知无误。没有充分资料的条件保留未知。

校准以完整主真/主假分母计权，父录制、实体、时刻按既有分级规程处理。先计算本地判决消耗的错误质量，再给消息分支分配剩余预算，不能每个分支各用5%后声称整体5%。在本地未知子集选择消息门限时，门限筛选也必须计入完整分母和各攻击层残余假采纳。

首版固定以下顺序，不联合搜索四个门限。

1. tauF只用全部正常cal分数确定。候选为正常有效F的不同取值及关闭值正无穷，选使原始F告警质量不超过完整主真2%的最小门限。此步不利用I冲突解除误拒，也不看假侧效用。
2. tauP用cal中全部有效正I及关闭值正无穷。要求原始I支持在总体及每个声明family/k层的错误采纳均不超过2%，其中各层分母为该层全部假候选。符合者最大化正常支持质量，同质量取更高门限；没有正质量可行区域则关闭。此步不利用F冲突降低假风险。
3. 冻结本地门限，形成实际互斥的采纳、拒绝、未知、冲突状态。按这些实际决定计算全局真误拒与逐假层误采，分别从总5%预算扣除，不能把真假预算合成一个数。
4. 消息反证门限tauR只用正常cal，在本地未知、非冲突且原拒绝资格成立的记录中选择。沿用最小门限/严格超限规程，新增误拒质量不超过完整主真上的剩余预算。
5. 最后选择消息采纳门限tauC。仅本地未知、未被tauR拒绝且共同采纳资格成立的记录可参与；保持本地误采后，各假层和总体错误不得超过5%。在cal有限Count分数边界与关闭候选中，选真实采纳最多者，同质量取更高门限。缺少声明假层或没有可行正质量采纳区时关闭，不退回旧政策。

2%为预先分配给各本地错误类型的工作预算，不是传感器常数；5%为整体工作预算，不是统计置信保证。数据支持须记录独立父数及实体数，缺失的假层不能置零风险。已有cal资料的缺层和小样本限制未因加入ego自动消失，效果比较前必须在明确清单中解决或将对应结论标为不可估，不能只因校准函数能返回门限就宣布方案通过。

只有在独立cal存在可行门限时，才开放相应统计采纳。有限候选集合中选择满足风险约束、真实采纳最多的门限，同分时取更保守者。若本地分支已超预算，不能靠关闭远端分支掩盖；该本地机制本身不通过。独立评价不得重新挑阈值。旧5%风险预算与2个百分点真实采用损失作为初始工作要求保留，正式比较基线须获得同样本地信息。经验预算不是相关窗口上的总体概率保证。

## 7. 为什么值得做、什么结果才有用

预期作用是本地可靠检测支持单个可信来源的真实目标，本地有效穿越反证纠正多车一致虚报。对本地不可见且没有其他有效反证的情况，预期只能减少无依据的采纳并增加未知，不能承诺成功拒假。此前第三来源U=-1的错误尚不能据此宣称有本地空闲反证。

所有方法共用本地点云、检测、候选、窗口、资格和校准资料，比较顺序为：仅本地三态，本地加计数，本地加条件证据。只有后两者在同等风险/采用代价下建立增量，才继续比较同边际独立和联合。可信本地信息属于共同部署前提，不能作为依赖建模创新。

同时报告完整候选六格及本地支持、本地反证、本地未知分层。不能只报告可见域；如果收益全来自本地，或者采纳域只剩本车原来已经检测到的目标，则只能证明本地核验作用，原多源研究目标尚未完成。

邻近工作[CAD第5节](https://arxiv.org/html/2309.12955v2#S5)已经研究占据与感知一致性，并明确存在正常车辆均不可见时的限制。因此，本地射线检查本身不是新的论文贡献；本项目需要证明观测条件处理及后续依赖处理在同本地信息下的额外作用。

## 8. 本轮具体落点

已确认并写入的是可信接收车前提、单阈值候选否决、实际接入位置、证据分数、形体来源、四门限的确定顺序及判决边界。[最小实施规格](rq1_trusted_receiver_2026_11_17/SDS.md)把改动收敛到两个新增模块。实际门限数值、消息采纳区及效果尚未产生，不能把计算定义完整叫作有效算法。
