# 一次协作驾驶：冻结权重诊断规格

用户在 2026-09-16 确认开始。后续主方案为 LLM 请求决策、共享数值驾驶器和既有 P/F；小请求网络作为对照。本批只执行共同驾驶器定位，不训练、不接入 LLM、不改变生产驾驶器或 P/F 服务。

## 数据与模型

- 使用 `structured_driver_expanded_2026_09_15_v1/rows.jsonl` 中全部 39 个完整开发帧、两个已有开发录制组。每帧从各真实任务取最终 Ego/P/F/PF 阶段，保留此前失败导致的 g5557 整帧排除；不根据收益筛帧。
- 主检查点为既有选中的 step500；step0、step3200 是固定的初始化/终点诊断。不得根据本批结果重选模型。
- 读取并核验真实归档的 prepared input、receipt/ledger 与原特征；复用正式 collator、模型和轨迹评价。完整保存 DriverSpec、ExecutionSpec、输入定位、权重身份和运行环境，不新写完整检查点。
- 本批是真实模型、固定已购证据的离线重放，不重新调用 provider/MTR。归档请求是先前模型和轨迹产生的，不能将重放称为新策略在线实验，也不能把 PF 归档称为全量信息或最优上界。

## 预先确定的对照

1. **无 prior 的一次输出**：Ego/P/F/PF 都清除归档数值 prior，输出一次。用于观察固定证据下的直接作用；P/F 是已经购买的输入，不宣称零成本取得。
2. **共同 Ego prior 下的一次修订**：同帧同权重的首次 Ego 输出作唯一 prior，分别输入 Ego/P/F/PF 证据，再各生成一次。若 prior 不合法，报告并统一清空，不隐瞒失败。以 Ego 同证据修订作为通信证据的对照。
3. **无新增证据重复修订**：Ego、P、F、PF 各自在第二步之后再修订一次，区分重复修订和信息作用。该步是离线诊断，不算方法优越性。
4. **输入干预**：共同 Ego prior 下，分别移除直接远端字段、移除全部 forecast、屏蔽 scene patches、屏蔽全部环境信息。每次重新构造 mask，保留本车合法运动/历史和同一无远端 prior。干预结果不伪装成合法新 receipt；屏蔽导致分布变化，不能替代相应条件训练的正式基线。
5. **恒速参考**：直接调用现有模型的 causal motion base，单独计数，不把它当神经网络生成。
6. **基底分解**：对共同 prior 下同一次前向的输出，减去该 prior、加上因果恒速基底。只分离累加基底的数值作用，不修改网络，不称作已训练的新驾驶器或正式改善。

各输出保存完整六点轨迹、合法性、ADE3/FDE3/原前缀 L2，以及相对对应 Ego 输出的逐帧误差差和轨迹位移。配对阈值为 0.01 米，表示实用数值变化分类，不表示统计显著。报告两个录制组，帧不当独立录制样本。

## 内容检查与场景分层

同时记录实际入模远端历史、F、远端独有实体、已关联实体和 unresolved 实体。距离本车原点不超过现有 `ego_position_threshold_m` 的 unresolved 实体单列，不能自动认定为真实 Ego 或自动删除。

使用当前时间可得内容预定义“附近交互代理”：远端 P 的 causal tracking-state motion proxy，或真实 F 的最高分模式，在六个相同未来时刻距因果恒速参考中心不超过 8 米。单列 unresolved 后，再报告 role=obstacle 的代理分层。该代理不使用未来 GT、不表示真实碰撞或交互标签；不按本轮轨迹误差挑帧。

## 本批终点

交付可复跑诊断入口、回归测试、原始逐帧轨迹、独立指标复算和书面定位。只对证据直接支持的位置提出修正，不因均值接近就断言无条件信息价值为零，也不因生成变化就宣称协作有效。若识别到模型表达/任务瓶颈，停止追加相同训练；不自动进入调用策略训练。
