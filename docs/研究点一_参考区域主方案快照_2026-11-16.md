# 研究点一当前方案

更新日期 2026-11-15。当前设计为**条件联合表征与类别参考区域核验**。单车条件解释报告和未报的信息量，多车联合处理它们的依赖，最终分别判断输入是否得到真实参考及虚假参考支持。

本轮已完成计算定义和独立设计核对，**尚未实现或验证新方法效果**。旧 D_zero/J_zero 未通过的结论保持，不再作为已有效主算法。完整公式和参数契约见[完整设计](REALLY_MAYBE/条件联合表征与类别参考区域_完整设计_2026-11-15.md)，审核问题及处理见[设计核对记录](REALLY/条件联合参考区域_设计核对与作用边界_2026-11-15.md)。

## 1. 研究问题与边界

对候选目标 X，根据各车的报告、未报和观测条件，考虑多车依赖及近期信息，输出采纳、未知、拒绝。要证明的是条件信息是否超过计数，以及多车联合在同样单车条件下是否还有额外作用。

来源数、受控数量和身份未知，不假设多数诚实，不默认自车绝对可信。当前不纳入正常误检或正常错误关联到虚假目标，不重新盘点该事实。正常车辆仍可漏报。GT 未匹配不直接标假。

真参考来自 clean 明确真实候选，假参考来自声明的 F1/F2 注入目标。算法不输入真实 k，也不将双支持当真实性证明。效果证据限定在实际参考与评价域，不声称识别任意串谋。真假在线输入完全相同时，当前信息不能区分。

## 2. 输入及单车条件信息

上一中央轨迹先预测到当前，建立预查询，再关联当帧消息。每源事件为新鲜支持 1、确认有效新扫描机会却未新鲜支持 0，或未知。缺包、FOV 外、机会不明及必要基础条件缺失不补 0，coast 不算新支持。同源同扫描重复消息只计一次。

条件 x 包括距离、方位 sin/cos、FOV 余量和预测不确定性。C 是九射线对其他预查询框计算的潜在阻挡比例。C>0 且主阻挡 ID 相同者成组，分组先于当前 U。C 是代理，不是遮挡真值。GT 和回波只用于离线监督。自车作为实际来源计一次，暂不加入占据图或可信射线。

主路径采用已有直接条件报告模型 `p_D=P(新鲜报告 | 正常真实参考、x、C、有效机会)`。不再依据报告残差更新 Z 质量状态；前端轨迹仍保留合法历史。当前模型不估计物理消失 H 或攻击过程 A。

单车报告信息量为 `b+=-log p_D`，未报信息量为 `b-=-log(1-p_D)`。高 p 未报信息量更大，低 p 未报接近中性。这些是正常侧信息量，不能单独称真假似然比。报告次数与支持来源数另外保留。

## 3. 多车联合和三个窗口量

每个同帧组使用独立 Bernoulli 与共单调 Bernoulli 混合，保持每源 p_D 不变。组间在该模型中条件独立。rho 仅用 clean 折外当帧损失从 `{0,.25,.5,.75,.9}` 选择，不能搬用旧隐状态模型的 rho。

分别计算三种概率，均从同一个当帧联合分布边缘化得到。

- q+ 为当前所有报告来源都报告的概率，其余来源边缘化。
- q- 为当前所有有效未报来源都未报的概率，其余来源边缘化。
- q_all 为完整当前报告组合的概率。

最近十个同步扫描内定义

`B+ = -sum log q+`

`B- = -sum log q-`

`C_pm = sum(log q+ + log q- - log q_all)`

恒有 `B+ + B- + C_pm = -sum log q_all`。C_pm 可正可负，不强制解释为矛盾惩罚。报告、未报及二者组合的信息分别保留，不再统一乘一个 c 加入真假分数。

rho=0 时，B+、B- 回到单源信息量之和，C_pm=0。联合与独立比较固定同一个 p_D。最终选择 rho=0 时，使用完整独立版，包括其参考库与校准。

十扫描约一秒，每次只重算当前窗口，不叠加旧分数。这里是短窗口复合表征，不冒称跨帧完整序列概率。没有新增长期信誉系统。

## 4. 真假侧怎样处理

窗口表征固定为

`z = (B+, B-, C_pm, n+, m, w)`。

n+ 是新鲜报告次数，m 是支持过的不同来源数，w 是窗口扫描数。有效来源数 d 只用于资格，不加入未报次数或只未报来源常数。

分别建立真实 T、假族 F1、假族 F2 的 fit 参考库。每个参考窗口按父录制折外编码，留出父不能参与自身 p_D 或 rho 估计。距离尺度仅由 clean 折外特征确定，每维使用 `max(标准差,1)`，校准及评价不改变尺度。

对于类 y，先求待核验表征到每个父中该类参考窗口的最近距离，再取不同父中的第二小距离 a_y。这样一个父的重复样本不能独自提供两个父支持。至少两个非空 fit 父才可计算；这不是足够独立覆盖或风险保证。

二近父区域不是高密度水平集。跨父出现的少量尾部窗口也能提供支持，尺度缩放不自动消除坐标相关性或决定最优权重。这些仍是当前度量的效用风险。

不再设置手工假报告率、攻击持续率或攻击数量先验，也不拟合完整假侧 HMM。假侧由实际注入参考的支持范围表示，不称任意攻击概率分布。参考库属于非参数模型，容量随参考点数增加，不能以六维为由声称天然不易过拟合。

## 5. 校准和三态判决

T 半径取独立 cal 真样本的加权 95% 经验分位。每个假族先在已观测 k 层内分别取分位，再取最大半径。分位采用经验累计权重首次达到 .95 的观测值，等于半径时保留相容。

权重沿用父、query epoch、时刻均衡，假侧在 family/k 内计算。重叠窗口和碎裂轨迹不当成独立实体。5% 是校准集内的经验工作点，不是新录制或部署保证。

| 真参考 | 假参考 | 输出 |
| --- | --- | --- |
| 相容 | 全部声明假族可用且都不相容 | 满足采纳资格才采纳 |
| 不相容 | 至少一个可用假族实际相容 | 满足拒绝资格才拒绝 |
| 相容 | 至少一个假族相容 | 未知，参考重叠 |
| 不相容 | 全部可用假族不相容 | 未知，参考无法解释 |

缺失假参考只能阻止采纳，不能支持拒绝；真参考不可用则不明确判断。数值失败不作为排除某类的证据，记录并输出未知。缺某 k 层不意味着在线能识别该 k 并自动转未知。

采纳资格仍要求窗口内至少两个不同来源新鲜支持、当前存在身份相容的可输出轨迹。拒绝资格要求至少两个有效来源且有有效未报。只有一个有效来源、新生无预查询或其他资格不足均为未知。

没有单源可信概率初始化。单源事件仍记录，但不能独自明确采纳或拒绝。两个来源支持也只是输出资格。输出包含各类距离、半径、相容状态和三态，不伪装成一个已校准真实性概率。

明确拒绝仍要求假参考相容，所以拒绝域受有限假参考区域限制，不保证未报信息量越大就越容易拒绝。两类均无法解释的强异常仍为未知。外部 re2 建议的定向尾拒绝尚未加入，也不直接实施剪尾或删除 B^+；具体取舍见[参考区域与尾拒绝审查](REALLY/gemi_re2_参考区域与尾拒绝审查_2026-11-15.md)。

## 6. 本次改动预期解决什么

- 用直接条件模型，避免候选自身连续未报通过 Z 残差更新显式降低预期报告率。未建模真实遮挡可能仍有代价，不声称删除 Z 已被证明有效。
- 分别保留报告、未报及组合信息，减少一个全局联合系数的表示限制，不强制所有共同报告加奖或减分。
- 用两类实际参考关系判决，使两类重叠和表征空间参考外输入进入未知。正常侧异常不会独自证明不存在，正常侧未被拒绝不会独自支持采纳。
- 在已观测校准层中分别保留假族风险，不用混合平均掩盖困难层。扩大假区域可能损失真实采用，仍需完整评价。

这些是具体结构预期，不是净效果保证。若参考区域高度重叠、概率条件失准、假样本过于稀疏或攻击模仿真参考，方法仍可能无效。全部未知不算成功。

## 7. 框架、对照和当前状态

复用 AVstack/MATE 前端、消息和查询，并列运行核验器，不向 MATE Beta 或来源信誉反馈新分数。MATE_policy 使用共同资格和校准，内部保留其原生历史，不能称内部记忆完全相同。

主要对照为同决策的计数参考、单车条件参考、定向联合参考、单个总 Delta 的同维参考及组平均参考。条件贡献、联合贡献和决策器变化分别归因。全部保留真假六格、CD、family/k、父录制、首窗和配对时效。完整公式及预声明效用门槛在[完整设计第 12 节](REALLY_MAYBE/条件联合表征与类别参考区域_完整设计_2026-11-15.md)。
