# 研究点一汇报PPT文案

2026-11-13。可直接按以下六页制作。已有结果均为开发证据，最后一次实验尚未运行。研究题目保持为面向目标真实性核验的观测条件与多源依赖证据建模，联合效果仍是待验证部分。

## 第1页 研究问题

标题：多车报告不完整时，如何判断目标是否真实？

- 某车报告目标X，其他车未报，不能直接按未报数量判假。
- 其他车有较好的观测条件却未报，应提供更强反证。
- 其他车缺少观测条件时，现有信息可能不足，应保留未知。
- 多车受同一原因影响时，重复证据可能被过度累计。共同报告也需要考虑依赖，不能只处理沉默。

讲述句：研究对象是目标是否真实，重点是证据应有多强、多个来源应怎样组合。没有默认可信车辆，也不假设诚实多数。

## 第2页 输入与处理过程

建议画为六个框：已有目标预查询、各车新鲜报告匹配、报告/未报/未知、观测条件与报告概率、有限窗口评分、采纳/未知/拒绝。

- 在线条件包括距离、方向、FOV、查询不确定性和潜在阻挡代理。
- 有有效扫描机会却未报告才记为未报。缺包和FOV外记未知。
- GT、原始回波标签和攻击身份只用于离线建模或评价。
- 最近10个扫描约1秒，每次重算窗口，避免把旧证据重复累加。

讲述句：正常报告概率表示这个条件下真实目标通常是否会被报告，不等于目标本身真实的概率。

## 第3页 单车证据和多源评分

标题：用观测条件决定未报的反证强度

`e_i = a_plus*sum_report log(p) + a_minus*sum_miss log(1-p) + b_plus*n_i+`

`S_D = b0 + sum_i e_i + beta*m + c_w*w`

- m为曾报告目标的不同来源数，w为窗口扫描数。
- a_plus、a_minus非负，其余系数由真假监督拟合。
- 取消只未报来源的固定惩罚，p很低时单次未报贡献接近中性。
- 真侧用clean目标监督正常条件模型，假侧用预先冻结的F1/F2注入案例训练判别分数。
- 不再手工指定通用假侧报告率。分数不解释为现实部署的真实性概率。

讲述句：当前正报告条件项系数为0，正报告仍通过次数和支持来源数参与。我们没有把正报告质量收益写成已经成立。

## 第4页 联合扩展和三态判决

联合候选为`S_J = S_I + c*Delta_T`。Delta_T比较正常联合事件概率和相同边际下的乘积，正报告与未报都参与。I/J共享同一正常联合过滤边际，D使用直接条件概率，因此不能用D/J差异直接归因联合项。

- 采纳要求至少两源新鲜支持、输出相容且分数达到采纳门限。
- 拒绝要求至少两源有效、有未报证据且分数低于拒绝门限。
- 新生缺少预查询、单源有效或证据不足时保持未知。
- 观测条件不能区分的攻击不保证可识别，双支持也不是真实性证明。

讲述句：联合表达已经实现，但尚未建立稳定额外收益。本次不会通过强制加权或删除不利结果把它包装为已完成贡献。

## 第5页 已有阶段结果

标题：条件评分有局部改善，迁移与早期判断仍有代价

同一开发批次、共同三态政策下的mixed结果：

| 方法 | 真采纳 | 假采纳 | 假拒绝 | 正确明确率CD |
| --- | ---: | ---: | ---: | ---: |
| MATE_policy | 60.61% | 0.00% | 33.72% | 47.16% |
| 原条件评分D_old | 57.55% | 0.00% | 85.20% | 71.37% |
| 约束评分D_zero | 58.04% | 0.37% | 89.48% | 73.76% |

CD是真采纳率与假拒绝率的平均，未知计入分母。MATE_policy使用共同资格和校准，不是MATE原论文完整系统复现。主评价6519真时刻、531假时刻，来自3父、99个真query epoch和11个假注入实体。

同页保留不利结果：

- F2训练/F1评价时，D_zero真采纳58.91%降至53.51%，损失5.40个百分点，未通过原保留条件。
- mixed首窗真采纳47.04%降至26.29%；假首窗原始1/10条误采纳，分级加权20%，样本少，不能作总体风险率。
- 现有联合增量没有稳定超过强对照。

讲述句：这些结果支持结构修改确实改变了证据作用，并出现局部效用改善。目前还不能声称跨攻击类型稳定有效。

## 第6页 汇报前最后一次实验

标题：冻结算法，用一次跨父比较裁决三项问题

- 复用旧6父fit、5父cal，已有模型和门限固定。
- 增加六段未参与当前评分批次的三车录制，使用已有检测和FOV，最多30任务。
- 比较条件评分与计数、约束前后、联合与同边际及同容量对照。
- mixed为主，双向源族迁移为压力比较，旧k3失败保留。
- 输出完整真假六格、逐父差异和首窗代价。结果失败后不追加调参或换数据。
