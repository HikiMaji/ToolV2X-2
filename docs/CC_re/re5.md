## 1. 动机（两条，均来自首轮冻结结果）

**1a. 假侧范畴错误。**目标为假时，诚实来源的未报概率在「无自然误检」范围假设下 ≈1，不是声明参考给的 .6–.9。静态版的精确后果：e_i = log((1−p_i)/.775)，p_i→0 的盲源每帧沉默给出约 +0.25 的「支持真实」证据，两个盲源十帧 +4 > 首轮门限 A=1.153；时序版的持续族把泄漏压到每窗一次，但量纲仍由声明值决定——s 敏感性 19pp 就是读数。修法：假侧改为复合假设「某受控子集按攻击参考报告，其余诚实来源按 1−ε 沉默」，对子集取最优解释。沉默在真假两侧同源相消，报告证据随**独立报告者数量**增长而不随攻击者自选的声称条件增长。

**1b. 首窗冷启动。**首轮唯一误采：首个核验窗口仅 1 帧、3 个受控支持者，J=2.21>A。报告集中在单帧时，任何按报告模式打分的方法都缺乏时间证据。修法是政策层的，见 2.4。

## 2. 方法规格

### 2.1 新假侧 false_window_mcs

输入：U（时间×来源，取值 −1/0/1，与现 `false_window` 相同）、s（沿用）、ε、π。

对每个受控子集 S ⊆ {0..n−1}（n≤7，枚举 ≤128 个）：

```
logL_F(S) = |S|*log(pi)
          + false_window(U[:, S], s).loglik          # 现有四族马尔可夫，原码复用，仅限 S 列
          + sum_{i not in S, t: U[i,t]==1} log(eps)      # 诚实来源误报
          + sum_{i not in S, t: U[i,t]==0} log(1-eps)    # 诚实来源沉默
logL_F_MCS = max_S logL_F(S)        # S*=argmax，m*=|S*|
```

- S=∅ 时 `false_window` 部分为 0（全诚实解释）。未知维（U=−1）两部分都不产生项，与现有边际化一致。
- π 每窗口对每个受控来源计一次（先验代价），不逐帧累计；ε 逐**事件**计。
- 返回结构与现 `false_window` 同形（loglik、steps、family_weights），另加 `m_star`、`S_star`、`per_k`：`per_k[k] = max_{|S|<=k} logL_F(S)`（k=0..n），供输出「采纳该目标所需的最小受控解释数」。
- steps 的逐帧边际 q_{i,t}：i∈S* 取 U[:,S*] 上现有族混合的边际，i∉S* 取 ε。Jind/G 的 delta_F 按此 steps 计算，定义式不变。
- 性质（必须写成单元测试，见 3.2）：全体沉默时 logL_F ≈ 0，因此沉默分数 = Σlog(1−p̃) ≤ 0，**沉默永不为正证据**；持续报告者总由某个 S∋i 解释，其正证据上界 ~ −log π + 族似然差，不随声称条件无界增长。

### 2.2 参数 ε：先测量，后声明回退

测量：在 fit/clean 的已标注记录上，ε̂ = 加权（父等权、父内轨迹等权、轨迹内时刻等权）的 P(U_i=1 | 有效机会，query_truth==0)。该层样本数 <200 个有效机会时判不可测，改用声明值 ε=1e-3。无论测量与否，敏感性网格 ε∈{1e-2, 1e-3, 1e-4} 都要跑。ε 不从 cal/eval 估计。

### 2.3 参数 π：声明值加网格

主值 π=.1（每受控来源 2.3 nat 先验代价），网格 π∈{.3, .1, .03}。π 是本设计仅存的声明自由度，这一点如实写入结果文档；配套交付 m* 分布与 per_k 曲线，使「采纳需要假设几辆受控车」成为与 π 弱相关的可解释输出。

### 2.4 政策追加（对所有方法与 MATE_policy 一致施加）

采纳资格在现有条件（机会≥2、支持者≥2、query_present、output_present、identity_ok）之上追加一条：**窗口内含有效 fresh 支持的帧数 ≥2**（`support_frames>=2`，不同帧、可同来源组合但仍需满足原双来源条件）。回归目标：首轮 F1/k3 首窗误采样例在新政策下不具资格。拒绝资格不变。

### 2.5 其余全部不变

正常侧七法、rho、W=10、门限校准程序（cal 上真假各 5% 分级预算、父/轨迹/时刻逐层等权）、评价口径与指标、MATE 原生旁列。每个配置重新校准 A/R，不跨配置复用门限。

## 3. 实现映射与必做检查

### 3.1 代码改动点

1. `kernel.py`：新增 `false_window_mcs(U, s, eps, pi)`，内部调用现 `false_window`（对列子集）；`_score_window` 与 `score_window` 增加参数 `false_side∈{'qf','mcs'}`（默认 'qf' 保持旧行为）与 `eps, pi` 透传；资格计算增加 `support_frames` 项（由传入开关控制，开关对两种假侧配置都开启，保证对照同政策）。
2. `run.py`：score/report 阶段加 CLI 参数 `--false-side --eps --pi --support-frames`；输出目录按配置分开（`run_002_mcs_main` 等），沿用防覆盖。manifest 记录全部新参数与 ε 测量结果。
3. prepare/fit 产物复用 run_001 的（models.json 不变）；只重跑 score 与 report。

### 3.2 单元测试（新增，全部必须先红后绿或构造性验证）

1. 暴力对照：n≤4 随机 U 上，子集枚举 max 与独立实现的逐子集计算一致。
2. 符号性质 A：任意 p̃、全沉默窗口下 MCS 分数 ≤ 0（对比：构造 p̃<.225 的旧 QF 用例给正分，确认差异）。
3. 符号性质 B：单来源持续报告、其余沉默时，分数不随该来源声称条件变好而无界增长（上界含 −log π 项）。
4. 来源排列不变性；未知维边际化；S* 与 per_k 单调（k 增大 logL_F 不降）。
5. 政策回归：复刻首轮 F1/k3 首窗样例的 U 结构，新政策下 accept_eligible=False。
6. ε 测量函数在小 fixture 上可复算、样本不足时按声明回退并记录。
