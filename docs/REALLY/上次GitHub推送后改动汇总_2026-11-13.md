## 3. 第一轮实际修改：从手工假侧改为监督评分

### 方法改动

- 新主评分不再使用手工Q_F、攻击报告率r、持续参数s及其真假似然比。原实现保留作历史，没有删除或回写。
- 正常侧仍提供每源报告概率。报告log(p)、未报log(1-p)、报告次数与窗口/来源计数进入可分解的7系数基础头，使用真假监督拟合。
- 固定基础I，再单独拟合一个正常联合修正系数。保留直接条件D、独立时序T、同边际I、联合J、组平均G和同容量平方Q对照。
- 先按父录制折外生成头训练表征，rho在外折剩余父中再内折选择。cal/eval复用原六父normal模型。正常模型结构未改，新增的折外拟合是为了避免头训练泄漏。
- 构造规则、种子、损失、权重、符号约束、最低支持条件和数字裁决先冻结，再运行。

这是正常条件表征加声明攻击域内的判别评分，不是从数据估出了任意攻击者的真实概率分布，sigmoid也不当作部署真实性概率。

### 数据与评价改动

在原6个fit父的已有缓存上执行26次F1/F2构造尝试，18次完成、8次不可构造，其中17条形成非空明确假目标轨迹。没有新采集、训练感知骨干或改变原cal/eval用途。

判别头监督为18013条clean真记录、476条F1假记录、211条F2假记录。来源是11条F1实体和6条F2实体，不是687个独立攻击。新加入mixed、仅F1训练/校准后评价F2、仅F2训练/校准后评价F1三个方案，目标族不进入源族标准化和门限。

### 结果与决定

新J真采纳从旧版40.43%提高到57.11%，但联合增量对同边际I的CD仅+0.174个百分点，未达到1个百分点门槛。直接条件D的CD71.37%，高于J的69.05%。两个迁移方向也未通过，反向F1/k3层J假采纳13.33%。

因此保留监督评分实现及D强对照，不认领稳定联合收益。c区间因父覆盖不足不可用；该限制不是数值条件失败的唯一原因。详见[第一轮结果](判别评分修订_开发结果与方法决定_2026-11-13.md)。

## 5. 第二轮实际修改：约束只未报来源的常数为0

将计数部分写为`beta*m+gamma*n0`，n0表示窗口内只未报、从未支持的来源数。D_zero/I_zero令gamma=0，保留条件概率反证和支持信息后重新拟合，最多6个自由系数；J_zero再重估同一个联合增量。

这轮直接复用第一轮的所有折外及cal/eval特征，没有新增攻击或重新拟合normal。另设I_cut，固定旧参数只扣除gamma*n0，并分别使用旧门限和重新校准门限，区分直接删项与重拟合/校准。

主方法预先指定为D_zero，I_zero/J_zero为次要。真实采用/CD损失、假风险、时效及改善门槛均在新分数出来前固定。

| mixed指标 | 第一轮D | 约束后D_zero |
| --- | ---: | ---: |
| 真实采纳 | 57.55% | 58.04% |
| 虚假拒绝 | 85.20% | 89.48% |
| CD | 71.37% | 73.76% |
| 假采纳 | 0.00% | 0.37% |
| 真实误拒 | 3.59% | 3.96% |

反向迁移F1/k3假采纳从D的6.67%降至2.22%，但真实采纳从58.91%降至53.51%，损失5.40个百分点，超过预定2个百分点。I_zero/J_zero也因对应真实采纳损失未通过。mixed首窗真采纳从47.04%降到26.29%，须保留该不利分层。

因此结构性质得到确认、局部效果改善，但没有整体替换旧研究基线。直接删旧项并沿用旧门限时，I_cut的mixed假采纳反而达14.93%，不能声称简单删项有效。详见[第二轮结果](只未报来源常数约束_开发结果与方法决定_2026-11-13.md)。
