# gemi_re/re1 方法意见审查

2026-11-15。依据[外部原文](../gemi_re/re1.md)、[当前方案](../研究点一_当前方案.md)、现行数值代码和已归档结果。本文是文献、代码及条件数学审查，没有重拟合、改门限或新增车辆效果实验。原文保留不改。

**结论**：外部意见正确提出了拒绝与采纳的依据不对称、单个联合特征表达受限、状态适应可能削弱反证等问题。但它没有证明这些是现有失败的主要原因，也没有完成可替换的采纳机制。不能接受“分开两侧就立即解决权衡”“只用 clean 就无条件保证 5%”“两三帧后必然饱和”等结论。当前方法未通过的决定不变，不因指出外部意见错误而恢复旧方法有效性主张。

## 1. 逐项取舍

| 外部意见 | 审查结论 |
| --- | --- |
| 拒绝与采纳需要不同的证据依据 | 采纳为设计要求。允许比较不同评分，但不等于必须废除所有单分数方法 |
| 当前 A/R 门限互相绑架 | 与代码不符。门限分别校准，共用的是训练后的评分表示 |
| 用 clean 校准拒绝可减少攻击族依赖 | 可以作为候选，但不自动提供任意分布、任意攻击下的真拒率保证 |
| 未被拒绝加独立视角支持就能可靠采纳 | 尚未解决。没有显著反证不是存在性证明，几何分离不是来源诚实证明 |
| 单个 Delta 不能分别学习不同共同事件的作用 | 有条件成立，已有解析记录支持；不是新发现的唯一根因 |
| Delta 同号必然导致净效应抵消 | 不成立。取决于真假分布、基础分数和数据支持 |
| I 的边际已吸收历史，Delta 只剩当帧发射残差 | 不准确，完整联合预测状态仍保留历史依赖 |
| 当前组全为单例就有 Delta=0 | 一般不成立，过去形成的依赖可能跨当前组继续存在 |
| 未报得分两三帧后饱和在 log pi0 | 所给下界推不出该结论，也没有本项目实测支持 |
| a_plus=0 主要因为原始正报告特征方差小 | 未确认，且忽略了评分头先标准化再正则化 |
| 删除窗口长度项即可消除攻击时长捷径 | 未确认，w 是上限为 10 的局部窗口长度，不是完整攻击持续时长 |
| 增加视角分组、置换对照或本车射线即可形成完整解决方案 | 都需补适用条件和副作用，不能作为已经成立的修复 |

## 2. 拒绝和采纳的区分有价值，但现行门限并未绑在一起

现行 `scripts/rq1_temporal/run.py:247` 的 `calibrate` 分别处理 A 和 R。

- A 用假样本约束误采纳，用真样本衡量正确采纳。
- R 用 clean 真样本约束误拒，用假样本衡量正确拒绝。
- 固定分数 S 后，A 的选取不读取 R，R 的选取也不读取 A。两分支另外限制为正分采纳和负分拒绝。

所以当前存在的是共享评分表示、训练域和统计权衡，不是两个门限在程序中互相决定。R 的可行错误预算已经来自 clean；但评分头训练和 R 的效用目标仍使用假样本。若改为纯 clean 异常分数，其实质变化是去除这些攻击域依赖，而不只是把门限分开。

一个符合适用条件的真实性似然比分数本来就可以使用上下两个门限。现有受限线性表示可能不适合本任务，但不能由“用了一个分数”直接证明其数学结构错误。分成两个评分也会增加参数与协调问题，不保证消除误采纳和真实采用之间的权衡。

### 只用正常数据能保证到哪一步

[Tong、Feng 与 Li，2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC5804623/) 的 NP umbrella 使用独立同分布样本和独立留出的校准类，通过次序统计量控制风险超过 alpha 的概率。它包含容忍概率 delta，不是任意一次部署都绝对低于 5%。其评分函数可以由两类数据学习，不要求评分头本身必须纯 clean。

[Oliveira 等，2024](https://jmlr.org/papers/v25/23-1553.html) 明确指出普通 split conformal 的原始保证依赖可交换性，对非可交换过程需要额外条件和覆盖惩罚。[Xu 与 Xie，2023](https://proceedings.mlr.press/v202/xu23r.html) 的时序方法也专门处理这种差别。

本项目存在重复轨迹、相邻及重叠窗口和父录制聚类。不能把所有时刻直接当作独立校准样本。即便采用适当的校准方法，也要区分单个随机目标时刻、每条轨迹曾误拒、条件分层和长期重复决策的风险。只控制一个总体量，不自动控制其他量。

更根本的是，clean 校准所控制的总体是正常真实目标报告过程。如果主张还覆盖受到恶意消息操纵的真实目标，必须证明这些输入仍满足相应零假设或另设鲁棒条件。拒绝正常报告模型，不必然等于证明物体不存在。

## 3. 建议的新采纳分支仍有关键缺口

无显著反证可以用于决定暂不拒绝，但不能单独用于确认真实。两个处于不同方向的受控车辆，仍可以同时报告假目标。几何独立可能减少正常观测的冗余，不等于安全意义上的独立可信来源。

因此，“没有显著反证加有效独立支持度”仍须给出分数定义、参数来源、采纳条件及误采纳边界。原文没有给出可以使多源盲区假目标自动进入 Unknown 的完整可观测规则。不能把这个待解决步骤写成修改后必然获得的结果。

原文的不可辨识表述也需要缩小。全部诚实来源不可用、且攻击者能够复制相同消息分布时，可以构造不可区分情形。但“诚实来源的报告概率很低”本身不等于真、假在线输入严格同分布；只要正常情况下仍有非零报告机会，分布就可能不同。一次高概率来源未报同样只是统计反证，不是确定证伪。

至多一个固定受控身份、正常来源不支持假目标、身份可靠且查询语义一致时，两个不同来源的支持可以取得结构性保证。但这不是当前未知受控数量的威胁模型。不能为了使新方案成立，悄悄恢复 k=1 的主前提。

本车自由空间证据可以增加独立信息，但属于信息权限变化，只覆盖有有效本车观测的区域。一条射线穿过预测包围框不等于穿过实际实体，框内可能有空隙，还存在定位、时间和射线覆盖误差。不能未经观测模型就宣称一票证伪任意数量攻击者，也不能把当前无可信本车通道的任务直接替换掉。

## 4. 联合项表达限制存在，但符号推断需要保留条件

### 固定状态的正确部分

对于两个同组来源，固定状态及非退化发射概率，rho>0 时，全报和全未报的共单调混合概率都高于独立乘积，混合报告组合则更低。一个 c 无法分别调整同号全报和全未报项的方向。这已在[联合修正同号审查](联合修正同号与参数语义_代码审查_2026-11-13.md)记录。

但这不是概率分布不合法，也不能推出必然抵消。共同报告可能同时支持真实目标；其真假判别方向取决于两类分布。强行禁止所有全报联合项加分，相当于引入新的保守假设，可能损失正常共同报告信息，需要单独论证。

高阶组中的混合模式也不能一律按负修正归类。例如固定状态下 q=(0.9,0.9,0.1)，U=(1,1,0)，独立概率为 0.729，共单调概率为 0.8。rho>0 时该混合组合的修正为正。

### 完整过滤不能缩成当前组内的符号表

`kernel.py:85` 传播完整联合状态，89 行计算预测边际，95 至 102 行用完整联合概率计算 Delta。边际保留了历史的一部分作用，但不能代替整个联合分布。对于二源同组全报，联合概率与预测边际乘积之差还包含 `Cov_b(q1,q2)`，再加一个非负的共单调修正。前一项的符号不能由固定状态混合公式决定，所以固定状态下的正号不能无条件推广到完整过滤。

下面是独立审核给出的解析反例，不是新的车辆实验。

两源初始状态独立且 P(Z=1)=1/2，发射 q(0)=1/4、q(1)=3/4，rho=1/2。首帧同组，观测 U=(1,0) 后，按状态 (00,01,10,11) 排序的后验为

`b=(1/8,1/24,17/24,1/8)`。

下一帧分成两个单例组，每源转移表均为 `[[0.9,0.1],[0.1,0.9]]`。其预测报告边际为 `(19/30,11/30)`。当两源全报时，完整联合概率为 `23/100`，边际乘积为 `209/900`，所以

`Delta=log(207/209)<0`。

这个可达例子说明，当前没有共同发射组也可以保留历史联合修正。全局 Delta 不能直接用当前组的全报、全未报、混合符号相加还原。若提出分组分量，必须明确是否计算组边缘以及如何处理剩余跨组依赖。

### 拆分方向不能重复包装成已确定修复

[既有作用核对](评分改动前的作用核对与暂缓决定_2026-11-13.md)已确认，一组历史迁移误采纳中没有至少两个有效未报来源的共同组，因此新增共同未报项不能直接改变那些错误。它可能改善别的情形，但不能据此承诺修复全部多源假采纳。

原文提出的独立反证与共同受限反证场景值得保留为机制假设。然而给出 0.09 和 0.25 两个正常漏报概率，尚不能算出总体 5% 工作点。还缺两种场景的比例、假侧事件和其他可能报告组合。视角正交也不直接证明条件独立。

组归属置换是可考虑的对照，但不是无条件的物理因果证明。需要说明置换是否重算过滤。固定原边际只置换评分时，检验的是显式评分结构；重算过滤时，边际也会变化。新增分量的参数数量变化后，原一参数 Q 对照也不能自动视为同容量对照。

## 5. 所谓两三帧后饱和不是由下界得到的定理

对整个窗口内真正独立、全部未报的单源，原文所列一直处于 Z=0 的路径，确实给序列概率提供了一个下界。在恒定参数下，下界的对数是

`log(pi0)+log(1-q0)+(w-1)*[log(T00)+log(1-q0)]`。

T00<1 或 q0>0 时，右侧仍随 w 下降。一个下降的下界不能证明总分两三帧后稳定于 log(pi0)。特殊近吸收状态可能使有限窗口内的增量变小，但需要实际参数和逐步预测支持。

当前实现还将发射概率裁剪到 `[1e-6,1-1e-6]`。因此在理想延长的全未报序列中，每步 log(1-p) 仍为负，不能由模型结构宣称无条件的有限常数饱和。实际 W=10 只使用有限窗口，这是另外一种限制。

对已经与其他来源形成联合历史的来源，逐步边际概率还会依赖其他来源的过去事件。仅仅本帧为单例组，不足以把其累计项等同于只观察该单源的边缘序列概率。

所以“状态适应可能解释持续未报”是合理机制，“静态遮挡就是本项目病根”“两帧后消音”“等效 1.5 至 2 帧”目前均未成立。窗口重算避免了旧分数重复相加，但不能由此证明 1 秒窗口已经最优。

## 6. 正报告、时长及条件污染建议中的其他问题

`heads.py:105` 至 110 行先对特征标准化，再在标准化系数上施加 L2。原始 L_plus 数值较小不能直接解释为何其系数为 0。共线性、符号约束和训练分布仍可能有作用，但原文的 p 集中区间及原因排序没有数据依据。放开符号后得到负系数，也只能说明对应条件拟合偏好，不能独立证明某种攻击构造是根因。

w 是上限 10 的当前窗口长度，满窗口后不随整个攻击持续时长增长。F1/F2 原构造具有相同的注入时段规则。窗口长度与候选选择仍可能形成捷径，但不是已确定的“纯作弊项”；它也可能补偿不同窗口的证据暴露量。不能在没有具体作用依据时将删除 c_w 写成确定修复。

线性支持次数确实可能在指定系数和输入下抵消一个来源的反证。它是否是各实际失败的主因、怎样限制才不伤害真实采纳，需要区分。a_plus=0 也不等于最终采纳只看计数，因为未报条件项仍参与总分。

只使用已采纳框构造 C 会改变信息生成过程。若使用当前采纳决定，须解决同帧因果顺序；若使用上一帧决定，则存在合法但需要分析的历史反馈。误采纳的假框仍可能进入，未知或未采纳的真遮挡物反而可能被删掉。当前采纳不等于物理可信，不宜直接称 C_accepted 为可信代理。

## 7. 当前处置和下一步设计优先级

当前 D_zero 和 J_zero 未通过的结论保持。此次不实施删除窗口项、不引入视角硬门控、不强行分裂联合项，不重新运行已结束实验。

建议首先补齐拟替代方法的证据语义：正常侧异常只能支持何种拒绝、什么额外依据允许采纳、其余情形怎样保留未知。若采纳仍只靠未被拒绝和两个相隔较远的来源，完整真实性核验问题仍没有解决。

然后才比较纯正常侧拒绝统计量是否值得替换现有共享分数，以及是否需要报告模式相关的联合特征。两者均应写出明确公式、估计单位、适用前提和可能代价，再判断实施，不以一轮失败自动证明任何替代有效。候选状态见[修订方向记录](../REALLY_MAYBE/gemi_re1_修订方向与成立条件_2026-11-15.md)。
