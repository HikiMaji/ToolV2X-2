# MATE自车可信假设的论文与代码核对

2026-11-17。回答用户是否MATE也断定自车可信并大量利用。仅核对论文和项目实际使用的代码，没有修改算法或运行实验。

**MATE不要求某辆接收车的感知绝对可信，也没有把它对所有目标的观测设为优先裁决依据。论文明确估计所有参与者的信任。但MATE信任融合计算中心，允许设置高信任先验，代码另有参与车辆自身位置附近目标的满置信度支持分支。**

## 1. 论文区分了哪些前提

核对版本为[Security-Aware Sensor Fusion with MATE，arXiv:2503.04954v1](https://arxiv.org/html/2503.04954v1)。

- 第2节明确指出，以自车绝对可信为前提的方法适用范围受限，MATE转而估计所有参与者的信任。不能把它表述为默认某辆接收车感知可靠。
- 第3.2节将融合中心AGG称为可信计算中心。这里信任的是执行计算的中心，不是给某辆感知车的报告固定真实性。
- 第6.1节允许用先验表达已有信任信息，并讨论部署高信任来源以增加其影响。因此，不要求可信自车不等于无法使用高信任来源。
- 第6.3节用各车本地轨迹、视场与融合轨迹的一致性构建PSM，目标PSM强度依赖对应来源的估计信任，没有指定本车对所有目标拥有特殊优先权。

上述是不同层次的假设。估计所有来源信任不构成任意串谋下的保证；论文也未把所有可能的输入攻击都纳入验证。

## 3. 不能遗漏的自身位置例外

`measurement.py:169,276–297`定义默认`d_self_thresh=1.0`。对某来源未关联的中央目标，如果目标的平面位置距离该来源自身位置小于1米，代码认为这个目标可能就是该参与车辆本身，生成value=1、confidence=1的正目标PSM，且不因此处罚该来源漏检自身。

这个分支确实直接使用了车辆自身位置作为强支持。它针对每个来源附近的自身车辆目标，不是接收车对任意外部目标的感知可信假设。它生成PSM后仍经过正常目标更新与输出规则，不等于单条PSM直接保证目标被采纳。

本次没有统计该分支的触发频率或性能贡献，因此不能认定它在当前实验中贡献很大，也不能声称MATE完全没有任何特殊的自身信息处理。

## 4. 对当前研究比较的影响

本项目新版本明确允许可信接收车自身点云和未融合检测作为优先核验依据，这是相对于所查MATE默认感知信任设定的实质性变化。MATE本身也会利用各车本地轨迹与点云导出的FOV，差别在信息可信程度、具体消费方式及判决优先级，不能说MATE没有用本地观测。

因此，新增可信本地证据后的总改善不能全部归因于观测条件模型或多车依赖。论文比较应保留原生MATE参照，并增加获得同样可信本地信息的对照和相应消融。高先验MATE可以作为一种适配对照，但有限高先验不自动等价于本项目的本地优先判决，具体配置和是否允许后续降信任必须说明。

可信接收车前提已经由用户批准，不因此撤回。它限定了研究场景，尚不构成独立创新或优于MATE的证明。
