# 条件联合核验修订结果与方法决定

2026-11-11。已完成有文献依据的算法修订、代码实现及一次冻结比较。**按预定标准保留当帧条件联合核验核心和真假分布分离接口。收益限于声明参考分布，不能认领一般串谋防御或高覆盖。** 本批结束后不追加合成扫描，不再重新选择融合公式。

## 实际修改

1. 真侧由固定共同倾向改为带噪声当帧条件的组Bernoulli混合。先由条件读数计算可见状态权重，再求单车报告概率和组联合概率。其依据是成熟的条件独立混合构造，非新发明的概率公式。
2. 假侧从默认继承正常几何分组改为四种独立定义的参考过程，三种独立伪报率与一种全源协调伪报。工作头按四族等权混合，权重是声明参考，不是数据学得攻击比例。
3. 总分显式分成单车log证据、真侧组联合修正和假侧联合修正。报告、未报告、缺失都进入同一接口；无外部有效事件保持未知。
4. 在运行前已撤下最坏情况envelope作为默认头的资格，保留为Ec对照。它包含全协调恒报分布，因此全报告模式不能采纳。这是解析能力边界，不以事后改参数回避。

具体计算、参数和文献见[修订计划](../REALLY_MAYBE/条件联合核验_修订实施计划_2026-11-11.md)及[SDS](../REALLY_MAYBE/rq1_conditional_revision_2026_11_11/SDS.md)。本批参数均为受控值：可见先验.8、线索准确率.8、clear报告率.9/.65、blocked报告率.1/.05；假侧r=.1/.2/.4与全协调条件分布等权。C由外生可见状态生成，真假共用其分布，算法不读取状态真值或攻击身份。

代码新增三个文件，冻结提交`d3c29ae80ab0e55c661812e0ff41691dfcd6a7a4`，位于`.worktrees/rq1-conditional-revision-2026-11-11`。实现了可变长度来源输入；本批只枚举N2/3/4且提出者物理上独立的子场景，不能扩写成所有出生/关联情形已解决。

## 条件作用与联合作用分别来自哪里

固定N4、全部peer同组、高质量、三个peer均未报。无当帧线索J0分数为-.910并拒绝；当C提示受限，Jc分数为.002并未知。C提示清晰时，Jc为-2.118并继续拒绝。相同报告模式会随观测条件改变强度和决定，符合本轮条件修订的目的。

但有C的独立Ic在该受限例中也未知，不能把这份改善归给额外联合项。整个全未报类别同时存在有C后拒绝转未知和未知转拒绝，没有证明该类别总体误拒下降。

正常侧联合的独立归因看JcF到Jc。以eligible真实总体为分母，真采纳净增2.34个百分点，其中全报告贡献+6.92个百分点，混合报告贡献-4.58个百分点。全未报没有拒绝转未知，真误拒反增0.065个百分点。故本版正常联合的主要收益来自对报告组合的重新评价，**撤下把其增量解释为共同漏报恢复的主张**。

固定N4高质同组、C提示清晰且所有peer报告时，JcF=.839保持未知，Jc=.939采纳。这个变化同时影响真假输入，F4全协调伪报的采纳也会增加，不能只展示真实获益。

共同Ic门限下只替换Jc评分，真误拒4.9434%降到4.7048%，混合假采纳2.9062%降到.7352%，但正确明确率16.3724%降至16.0340%，真未知升到90.72%。主22.14%是评分和其合法工作点共同形成的结果，不能全部归为相同门限下的纯评分增量，也不能仅凭这个固定门限例断言它只是缩放。

## 假侧风险与未知代价

Jc在F1/F2/F3/F4的假采纳分别为1.27%、2.82%、6.26%、9.27%。4.91%只满足四族等权混合的平均预算。允许根据公开context选族时，固定context权重下最坏假采纳为14.25%；单context最高100%。这些都保留，不能用平均值掩盖。

JcF到Jc将F4假采纳从0提高到9.27%，因此正常侧联合的真实全报告收益伴随协调伪报代价。本批保留的是参考混合下的有限效用，不是全面降低两类错误。

## 已落实的方法决定

- 保留当帧条件模型、完整联合计算、真假分离接口及可解释证据分量。主5%下超过预定独立、组平均和仅假侧联合对照，不再重新筛选融合公式。
- 正常侧残余依赖只保留为本批1%/5%工作点的条件增量；撤下全预算优势、联合项恢复共同漏报、一般串谋稳健和高覆盖表述。
- 四族等权混合是实验工作参照，不能将其权重作为生产参数。Ec仅用于展示保护范围和未知代价，不更换权重追求漂亮结果。
- 本批合成验收结束。下一工作应是把C落实为现有合法输入中的具体观测量，并明确参数的估计/参考来源；不再追加合成扫描。C实际接入、提出者非独立情形和连续历史更新均未完成，不能称只差训练或可直接迁移。
