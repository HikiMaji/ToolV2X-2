# re6外部建议审查与采纳边界

2026-11-13。依据[外部原文](../CC_re/re6.md)、当前数值实现及已归档结果审查。源码版本6c83424，其中数值模块仍为已冻结版本。本轮只读核查一条已知错误记录，未计算全体V分层、拟合模型、重选门限或启动新效果实验。独立研究审核已完成。

**结论：保留按观测条件分析效用、独立父覆盖和不强制正报告系数的建议；不按原文关闭联合方向，也不直接实施新增2至3项。V的不可辨识推论、条件化必然吸收依赖、分布重叠即无信息及配平即完成归因均不能成立。**

## 1. 开头的效果归因和基线混用

re6第2行的59.4%是旧J的CD，不是旧D。旧D为58.20%，新D为71.37%。旧版对MATE的20.2个百分点真采纳差距也对应J，新3.06个百分点对应D。跨版本整体结果可以报告，但不能称同一个D头只替换假侧后的净变化。

该轮同时改变监督、评分表示、系数及校准结果。新结果支持整体改进，不支持瓶颈已被唯一归因为手工假侧并彻底解决。最新D_zero也尚未通过整体替换门槛。

依据：[旧时序结果第2节](时序条件联合核验_首轮开发结果与方法决定_2026-11-13.md)、[评分修订结果第1及3节](判别评分修订_开发结果与方法决定_2026-11-13.md)、[最新约束结果](只未报来源常数约束_开发结果与方法决定_2026-11-13.md)。

## 2. V可以粗分层，不能定义信息有无

第17行断言V=0且至少两源支持时，任何方法不能超过计数。该断言错误。相同两个支持源、一个未报源，后者p分别为0.10和0.49时，V都为0，但正常未报概率为0.90和0.51。若其他类条件项相同、假侧该源确定未报，则两种条件的真假似然比也不同。阈值计数没有保留完整的条件信息。本例仅反驳普遍断言，不表示当前数据中已经验证该增量。

已有任意串谋下的同输入不可辨识例，不能推广为所有V=0记录不可辨识。无高概率未报源还可能包含若干较低概率未报、先支持后未报、报告条件变化等不同情况。

V定义本身尚不完整。需要明确使用D还是时序模型的p，窗口内取当前、最大还是其他汇总，以及非支持指当帧未报还是整个窗口从未支持。后者会排除曾经支持但后来在良好条件下未报的来源。0.5只是候选展示分界，不是物理可见性的界线，更不是真实性阈值。V的阈值不能未经依据进入采纳资格或方法关闭规则。

在线可观察未报，不等于知道该来源诚实。攻击方可以选择候选位置；当前C还依赖预测框，是潜在阻挡代理。不能将它称为唯一且不可操纵的证据。当前离线GT框与回波代理也不是完备物理可见性真值。F3条件污染尚无已完成效果证据。

## 3. 已知错误并非都落在无高概率未报层

复用此前六条误采的首条记录，job `cf2ad1a17529d018`、id185、epoch1、index23。其w=1、d=4、m=3，只有一个有效未报源。冻结特征文件为主服务器`docs/evidence/rq1_score_revision_2026_11_13/run_001/features/eval/cf2ad1a17529d018.jsonl.gz`。

| 概率来源 | 该源L_minus | 由唯一未报恢复的p |
| --- | ---: | ---: |
| D_head | -2.235662388851328 | 0.8930787170741823 |
| I_Jmargin | -1.8461564652872988 | 0.842157324276722 |

这里p=`1-exp(L_minus)`，仅因窗口中该源恰有一次未报才可如此恢复。两种概率均高于0.5，故这一已知错误属于V=1，不属于V=0。不能由此推断多数错误在哪一层，但re6的总体预期还只是待验证假设。

该窗口Delta_T及候选Delta_00为零的事实已在[作用核对](评分改动前的作用核对与暂缓决定_2026-11-13.md)记录，不重做该实验。它有高概率反证，但没有多源共同未报；增加共同沉默项不能直接改变这条记录。

## 4. 联合项未建立效果，但两个理论理由需要纠正

完整对数似然比的联合修正可写为Delta_T减Delta_F。但只有基础分数已经是真实单源似然比之和等条件成立时，将其替换为c乘Delta_T才对应固定比例的假侧修正。当前I是带计数和受限系数的监督分数，不能从这个形式反推真实Delta_F必须遵守某个比例。

当前表达只有一个正常联合特征，可能不足以表达类别差异，这是合理疑问。现有I/J比较不支持稳定联合贡献，也足以撤下当前实现已有效的主张；不能把当前监督实现说成理论上必然无效。

观测了C也不必然消除依赖。只有C充分刻画相关共同原因、其余扰动满足相应独立条件时，条件独立才成立。当前C为九射线比例及主阻挡代理。源码`geometry.py:139`按主阻挡分组；`kernel.py:35`的发射明确允许在既定概率和分组下继续有共同随机成分。模型允许残余依赖不证明真实残余依赖存在，但足以说明分组和条件化没有在定义上将其消除。

[Friedman等1997，第133页](https://dang.cs.technion.ac.il/journal_papers/friedman1997Bayesian.pdf)支持联合分布拟合与类别预测的目标应区分，并讨论类别相关依赖；它没有证明本项目的代理C足够，也没有证明当前c的生成分布含义。不能借该引用完成本项目的失败归因。

## 5. a_plus为0的原因不能由两个建议检查裁决

两类分布有重叠仍可能有判别信息。即使逐报告边际分布相同，也不排除给定其他变量后或窗口组合中的信息。当前a_plus非负约束、正则、计数替代及训练域均可能影响零系数。删除计数再拟合可用于变量替代诊断，但不能单独识别共线性为原因，更不是零新实验。

源码`heads.py:58-76`的sources仅存每源窗口累计的L_plus、L_minus、n_plus，没有逐次p和事件顺序；`run.py:331`还从评分记录剔除了sources。故不能直接从该数组画逐报告log(p)分布。需要用既有模型和缓存重算相应概率，不必训练感知或正常模型。重叠窗口中的同一事件还须去重或明确权重，不能算作独立报告。

F1/F2构造在`native_adapter.py:218-222`检查支持者有报告资格，并没有要求正常报告概率高。F3在205至208行引入伪造遮挡物，测试条件污染，不是唯一可能产生低p正报告的攻击。因此合法报告资格不能直接解释a_plus为0，正报告不合理性也不必等待F3才可能出现。

可采纳的是不强制a_plus非零。当前结论保留为本批受限评分未使用此项，正报告仍经支持计数参与；不能改写为正报告质量普遍无用或只能承担计数。

## 6. 配平、覆盖和停止条件

- V和距离配平能改善部分可比性，不能直接排除计数非线性、单源边际变化、角色和窗口历史差异。
- 条件头对计数头检验条件信息；联合头对固定同边际基础头检验联合增量。还要保留同信息、必要同容量对照，不能只凭三种头的名称完成归因。
- V计数跨窗口出现，不保证同一帧存在两个有效未报源，更不保证它们同组。仅检查V大于等于2且共享阻挡会漏掉其他联合模式，包括较低p共同未报和共同支持。
- 覆盖不足5%没有给出分母或统计依据。新增至少4父也不保证关键层跨父覆盖或足够精度。它们最多可作有说明的资源选择，不能成为否定整条研究方向的科学标准。
- 未检出增益不等于排除了有实际意义的增益。覆盖不足与条件化吸收不能在结果前写成负结果原因。
- 依据新发现的层改模型或政策，应另设规程和新评价。旧D_zero未保留决定保持；按V切片不能追认其整体通过。
- 若最后只有政策、校准和机制分析，是否构成论文贡献仍须单独审查，不能将其作为当然满足毕业或投稿标准的退路。

## 7. 采纳决定与后续边界

保留当前条件模型作为开发底座和强对照，联合实现保留作研究比较，撤下已有效的主张。不实施re6提出的2至3个联合特征，不按5%覆盖或4父自动关闭联合研究。原外部文本保留不改。

V可作为候选描述指标，但需先补齐定义，并与已有连续条件反证`-L_minus`、窗口长度和实际资格并列解释。V分层本身不能因果分离政策与评分；共同资格是否阻止采纳需要直接读已有accept_eligible等字段。任何新重拟合或层特定政策都应明确为新的开发实验。

此处是对审查建议的取舍，不是已授权的新实验规格。候选组织方式维护在[后续讨论材料](../REALLY_MAYBE/数据与方法瓶颈_后续取舍及外部AI审查问题_2026-11-13.md)。
