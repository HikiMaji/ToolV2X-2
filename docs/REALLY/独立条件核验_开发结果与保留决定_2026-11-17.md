# 独立条件核验的开发结果与保留决定

2026-11-17 归档，数值批次于 2026-11-16 完成。**独立条件反证补充模块 Cond 在 mixed 和两个族迁移方案中均满足预声明保留条件，并超过两个同校准预算的简单控制。本次保留 Cond 作为已获得开发支持的有限核验模块。**

这是有实际代价和明确范围的正结果，不是完整联合方案已完成。原模型、攻击、窗口、资格和前端没有重训或更改。没有根据新评价结果再选择门限、调整预算或补跑方案。

**后续适用范围更新**：随后按冻结参数运行的追加三段资料中，mixed和F2_only假采纳超预算，见[联合结果与采纳风险](同边际联合核验_结果与采纳风险_2026-11-17.md)。本页原六段数值及当时裁决保持，但不能继续外推为跨录制风险已通过。

## 1. 本次到底实现了什么

基础判断为原 Count 的完整采纳、未知、拒绝。新增正常条件反证为

`R_ind = -sum_(t,i:U_it=0) log(1-p_D,it)`。

p_D、有效未报事件和十扫描窗口统计直接复用原特征。只在原判决正常可读、尚未拒绝且具备拒绝资格时，若 R_ind 严格超过正常校准门限，就追加拒绝。原拒绝保持，数据故障未知保持，新模块失败回到 Base。所有原记录都经过同一个不读取真假标签的判决函数。

门限只用完整 clean 主真分母，以原父、query 生命周期、时刻均衡权重，限制新增误拒质量不超过 `min(.02,max(0,.05-e_B))`。评分不是目标不存在概率，不能将正常异常度直接解释成真实性后验。

本次新增模块只改变未报条件证据的使用。正报告仍通过原 Count、候选和资格参与判断，没有新增正报告条件强度或依赖修正。整体方法仍继承 Count 的真假监督，不能称完全不依赖攻击构造。

两个预先冻结的控制为 MissCount（按未报次数追加拒绝）和 BaseTail（按原 Count 分数扩大拒绝区）。三者共用原基础判断、正常校准预算和严格门限规则。BaseTail 允许带符号门限，没有人为平移。选择这两个控制，是为了检验增益是否只来自增加拒绝预算或改变旧门限。

## 4. 参数、覆盖与不利分层

| 方案 | Cond 门限 | 新增 cal 误拒预算，百分点 | 实际新增 cal 误拒，百分点 |

三方案的正常校准主真分母均为 13960 条。评价真类为 9878 条、6 个父录制、147 个 query 生命周期，生命周期不是独立物体或独立录制。mixed 假类为 784 条、5 个父、19 个注入实体。两个迁移方向的假类分别为 353 条/9 实体、431 条/10 实体。重复窗口和方案重复不构成新增独立证据。

需要同时保留以下限制：

- mixed 的 F2/k2 假拒绝只有 34.09%，假未知仍有 64.20%。这里没有完全解决困难假目标。
- 首窗没有新增改善。mixed 首窗 19 个假实体中原有 1 次误采，分级加权假误采为 6.25%；F1_only 首窗 9 个假实体中原有 1 次误采，加权为 12.50%。Cond 都继承了它们。因此不能声称所有时段误采都不超过 5%。
- F2_only 的 `test/2021_08_23_16_06_26` 父录制真误拒为 5.206%，高于 5%。F1_only 在同父为 4.992%。冻结门槛是总体和所列假层，不是每父统一风险保证。
- F1_only 在 `test/2021_08_23_17_22_47` 的父内 CD 比 Count 低 0.409 个百分点，其余有两类标签的父内 CD 为正增量。mixed 和 F2_only 的五个有真假分母的父均为正增量。第六个父没有可构造主假目标，不能把其 CD 缺失当正效果。
- mixed 原 cal 缺 F1/k1、F2/k1、F2/k2；F1_only 缺 F1/k1；F2_only 缺 F2/k1、F2/k2。新增反证只用 clean 校准，但基础模型仍继承这些限制。
- 本批是已看过的三车、k1/k2 开发资料，不推翻历史 k3 失败，也不证明未知攻击、任意串谋、条件污染或部署风险保证。
- 主真分母只取 clean，攻击回放中的真实背景不作为新增独立主真样本。本批主指标不能替代攻击扰动下真实目标风险的专门评价。
- 新模块只能追加拒绝，不能增加真实采纳或恢复原 Count 的真实误拒。多车依赖和正报告条件证据尚未由本批解决。

## 5. 方法决定

1. **保留 Cond 的当前冻结版本和参数**，作为有实际开发增益的有限条件核验模块，不继续因其不能修复所有错误而整体撤下。
2. 当前结果支持条件反证在这批固定工作点上超过原计数及两个同预算简单控制。不能扩大为独立终测已通过或论文创新性已经成立。
3. 联合研究继续以此处已得到的条件结果为参照，但联合贡献仍未成立。不能把本批增益记在联合模型名下，也不因资源充足自动启动新的联合训练。
4. 既有原模型失败记录和本批不利分层全部保留。本轮固定比较结束，不再根据评价结果微调门限求更多增益。
