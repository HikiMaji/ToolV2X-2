# gemi_re2 参考区域与尾拒绝审查

2026-11-15。依据[外部原文](../gemi_re/re2.md)、[完整设计](../REALLY_MAYBE/条件联合表征与类别参考区域_完整设计_2026-11-15.md)和已有审核记录。此次是数学、文献及设计审查，没有拟合、覆盖率重算或新效果实验，外部原文保留。

**结论**：采纳有限假参考限制明确拒绝范围、近邻相容不等于高密度、度量可能受相关或无关坐标影响这三项实质限制。原文没有证明跨族必然失败、大面积重叠或六维必然失效。三个修补也不能保证消除这些问题。当前方法仍是可计算的设计，其统计效用和贡献未建立。

## 1. 有限假参考确实限制了拒绝范围

令同类父 r 的邻域并集为

`U_yr = union_(v in R_yr) {z: ||D^-1(z-v)|| <= r_y}`。

第二近父距离定义得到的类别区域严格为

`A_y = union_(r<s) (U_yr intersection U_ys)`。

因此，相容要求至少两个不同父的邻域覆盖同一个完整表征。有限参考、有限正尺度及有限半径使 A_y 有界。当前拒绝域包含于假族区域的并集，所以也有界；它还包含排除 T 的严格不等式，不一定是闭集。

**当前能力限制是明确的**：一个强烈偏离正常参考、同时也偏离所有假参考的输入，会输出未知。该规则不保证未报信息量越大就越容易拒绝。这是选择了参考外保守处理的代价，必须在方法正文说明，不能只写优点。

但未知 F2 是否在 F1 区域之外，取决于其六维表征及实际半径，攻击族名称不同不证明不重叠。高 B^- 表示指定正常模型给该未报模式较低概率，未建模遮挡、条件失准等真实目标也可能如此，不能称铁证如山的假目标。

实际 W、来源数和概率截断还使可达 B^- 有限。沿 B^- 趋于无穷的环境空间论证，不能直接证明实际可达数据一定有该类覆盖洞。F1/F2 原注入时间规则相同，w=6 与 w=10 是可能的查询窗口差异，不是这两个攻击族天然使用不同持续时长。

## 2. 双父近邻不是密度估计，尾部支持风险需要承认

原文对此提出了有效批评。两个父如果都在相近的完整表征位置出现少量尾部窗口，它们确实可以形成相容区域。二近父约束防止一个父的复制独自构成支持，没有区分局部高密度核心与少量跨父尾部。

但只在 B^- 一个坐标上相近，不足以证明六维邻域相交。r_y 是校准窗口到第二近父的距离分位，不是窗口到类别中心的标准差半径。原文所谓通常 2.5 至 3.5 个标准差，以及由此得到 B^- 大片区间被覆盖，没有来源或本项目数据依据。

因此，可以确认几何敏感性，不能确认大面积未知或真采纳下降的实际程度。低可见真目标与低可见假目标在表征上真正重叠时，未知也可能来自信息不足，不应全部归咎于邻域膨胀。

### 原文的剪尾和 k0 修补没有自动解决问题

父内第 3 或第 5 近邻仍可能来自同一段持续遮挡产生的相邻重叠窗口。它们不能自动提供更多独立支持。即使只发生一次稀有事件，也可能生成足够多近似窗口。

删除 fit 中的少量困难真目标，会改变参考范围。若同类困难目标在 cal 中仍多于允许排除的质量，重新校准后的半径可能扩大，未必缩小重叠；在评价中也可能增加真实误拒。它是新的模型与风险取舍，不能作为清理异常点般的例行操作。

## 3. 文献不能替二近父距离证明最优，也不证明距离比能消除尾点

[Sadinle、Lei 与 Wasserman](https://www.tandfonline.com/doi/full/10.1080/01621459.2017.1395341)的最优类别集合与类别后验概率的水平集有关。当前二近父几何区域不是其最优估计器，原设计已明确不继承其最优性和风险保证。

[Shafer 与 Vovk](https://www.jmlr.org/papers/v9/shafer08a.html)的近邻示例使用同类最近距离除以异类最近距离。re2 写成了相反方向，也把距离比解释成保证消除孤立尾点，这不成立：输入靠近一个孤立同类参考点且远离异类时，同类距离很小，比例仍可能很小。

所以这两篇文献支持类别集合及非相容度的一般方法依据，不足以证明本项目二近父距离有效，也不足以证明改成距离比或固定帧数近邻就是修复。

## 4. 六维度量有待证实，两个具体反例表述不成立

当前距离是 `sum_j (z_j-v_j)^2 / scale_j^2`，原坐标具有固定尺度权重。缩放并不消除 B^+、报告次数、来源数、窗口长度之间的相关性，也没有学习任务相关的重要程度。它们可能重复强调暴露长度，或让无关坐标影响近邻与半径。这是需要承认的度量选择风险。

但不能用旧受约束线性头的 a_plus=0 证明新 B^+ 是噪声。旧零系数不排除非线性交互价值，新的联合 B^+ 也不是所有旧头中完全相同的变量。六维本身不构成失效定理，删除概率信息或按 m/w 分层也不自动更优。局部匹配会减少每类可用父和实体，需要重新定义空层、邻域和校准，不能只称更优雅。

**B^-=0 的真实目标被直接误拒的例子违反当前资格。** 只要有一份有效未报，边际保持及 p>=10^-6 意味着对应全未报事件概率严格小于 1，所以 B^->0。精确 B^-=0 表示窗口没有有效未报，拒绝资格不成立。它可能进入未知，但不能按当前规则直接拒绝。很小的正 B^- 则仍可能误拒，不能借此否认一般风险。

共同报告使 B^+ 变小，不保证更接近整个六维 T 区域，也可能更接近 F 区域。它不会天然防止串谋，这一限制保留；不能据单个坐标变化决定最终真假方向。

## 5. 同组占比不是完整方法 CD 增量的直接上界

在当前无跨帧隐状态的设计中，评价窗口只有在最近十扫描内出现有效多源组，才可能直接产生不同于独立版的联合表征。应统计窗口内是否发生，而不只是当前帧。

不过，I/J 的折外参考坐标、第三维尺度和校准半径也会改变。即使当前评价窗口本身没有联合事件，其到参考库的距离与最终决定仍可能不同。因此，评价集中同组窗口占比不能直接限制完整方法的所有决策变化。

只有固定全部下游参考、尺度、半径、资格和分母，且决策差异确实局限于受影响集合 S 时，才有

`abs(Delta CD) <= 0.5*(mu_T(S_T)+mu_F(S_F))`。

mu_T、mu_F 必须使用原来真假各自的分级权重。原文 5% 至 10% 的占比是假设，不是本项目事实。条件覆盖是合理可行性问题，但不能按其示意算术删除总体标准，或从只读统计直接推出因果贡献。使用评价特征决定后续模型也属于开发选择，不能仅因不看标签就称完全没有使用评价信息。

本轮没有重做数据盘点或启动覆盖统计。

## 6. 尾部拒绝的确切作用与缺口

设保持原区域、尺度、半径、资格及分母不变，只将满足拒绝资格、排除 T 且符合额外尾部条件的部分原 Unknown 改为 Reject。新增拒绝仍属于 T 排除集合，所以原同一 cal 分母内的经验真拒不超过 5% 的性质保留。这个包含关系正确，不意味着新录制风险有保证，也不能证明尾部条件本身合理。

设新增拒绝中真、假的类内加权比例为 t、f，则

| 指标 | 确定变化 |
| --- | --- |
| 真采纳、假采纳 | 不变 |
| 真拒绝 | 增加 t |
| 真未知 | 减少 t |
| 假拒绝 | 增加 f |
| 假未知 | 减少 f |
| CD=(真采纳+假拒绝)/2 | 增加 f/2 |

因此，它可能提高 CD 并同时伤害真实目标。这条修改不能降低既有假采纳，也不能恢复真实采用，不能称解决了迁移风险与采用代价。

“B^- 大于最近真实参考点的 B^-”不是已定义的极端尾检验。输入可能主要因 B^+、w 等坐标偏离 T，而 B^- 只比最近点大极小量；最近点还会跳变。若进一步设计尾拒绝，必须明确条件、比较单位及参考总体，把正常模型失准与物体不存在的区别保留。此次没有把该候选自动加入三态规则。

## 7. 对开头肯定与最终承诺的纠正

删除 Z 仅消除了报告残差显式更新质量状态的路径。re1 所称两三帧后必然饱和从未被证明，不能在 re2 中作为已经修复的实测根因。三个概率量是语义分解，不是统计正交变量。窗口长度也没有被证实为纯伪特征。

同边际比较更清楚、三量恒等成立、参考外保留未知，是当前可确定的结构性质。它们不证明新方案效果已经改善。相应地，修补后避开所有已知陷阱及跨族更稳健，也不能由原文推出。

## 8. 本轮决定

1. 在当前设计正文补充有界拒绝域、二近父非密度、固定度量及窗口覆盖的明确边界，保持计算规则不变。
2. 将正常侧定向尾拒绝作为有确定作用方向但尚未定稿的修改方向，不按最近参考点的 B^- 直接实施。
3. 不自动剪尾、不删除 B^+、不改为帧级 k0，也不同时加入上下文硬分层。
4. 当前方案仍是完整计算候选，但不能把可实施性当作统计合理性或实用收益已经充分建立。下一次修改应针对明确目标选择，不能把三项尚未验证的补丁捆成必然有效的新方案。
