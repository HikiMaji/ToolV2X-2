# 未知受控数量下多源支持的推断边界

2026-11-06。针对用户取消单攻击源限制的条件推理，不是新增数据核查、数学实验或方法效果。

1. 在至多一个来源可伪报且正常来源不产生错误支持的旧前提下，两份不同身份的新支持可以排除旧假侧。允许多个受控来源以后，两份报告可以同时来自受控来源，因此旧排除结论不再成立。这个结论不依赖是否存在自然误检样本。
2. 若真实和虚假两种情形能够产生同一合法可见输入分布，任何只读取该输入的判别器都不能保证区分这两种情形。随机化算法在同一输入分布下也不会凭空获得区分信息。此前提不表示所有多源攻击均不可检测，也不否定限定攻击族中的经验收益。
3. 正常报告模式概率P(U|X真实,C)与其联合修正项仅描述正常侧。未给出假侧或有标签的判别依据，不能称其为真假似然比或真实性后验。
4. 仅观测攻击活跃且当前有注入支持的选择样本，不能直接以该样本的频率估计完整暂停/停止过程。GT未匹配也不能直接当物理消失。此前代码选择条件沿用[已有核读](证据时序设计_文献代码与条件算例_2026-11-06.md)，本轮未重查数据。

相关原始研究：[Ren、Yan与Mo，Binary Hypothesis Testing with Byzantine Sensors](https://arxiv.org/abs/1707.09592)研究检测能力边界及未知受控数量扩展；[Kailkhura等](https://arxiv.org/abs/1307.3544)说明指定攻击行为对分布式检测的影响。这里不未经核对地继承其攻击预算、独立性或性能保证。

当前方案据此撤销单J、两源硬确认和相应状态递推。静态判别路线及可估参数仍属[候选设计](../研究点一_当前方案.md)，不因本条件推理而成为已验证方法。
