# 条件证据的实际作用范围与方法取舍

2026-11-16。用户要求先建立方法采用依据，再推进完整方案。本轮只使用最后一次已完成实验的预测、条件特征和合法历史窗口。没有重新训练、选择 rho、校准新门限、生成攻击或运行新判决。

**结论是保留单车观测条件这一有局部数据依据的研究内容，但不采用固定 Count 后只追加拒绝的设计作为完整主方案。多车联合仍是待证实的机制，不能列为已取得效果的贡献。** 这个决定不是否定所有条件或依赖方法，也不是判定当前数据完全不可用。

## 1. 本次究竟比较了什么

主输入为 `rq1_report_freeze_2026_11_13/run_001`。mixed 的评价主分母含 9878 条真实候选时刻和 784 条明确注入假候选时刻，真实来自 6 个父录制，虚假来自 5 个父录制、19 个注入实体。时刻和重叠窗口不是独立样本。真实只取 clean，攻击回放的重复真背景不重复计入。无查询、出生、未知标签等覆盖另列，GT 未匹配没有补假。

真类采用父录制、query 生命周期、时刻分级均衡。假类先按攻击族及受控数 k 分层，再按父、生命周期、时刻均衡。下表百分比都是**原完整类别的加权质量**，不是原始条数比例，也没有在筛选子集中重归一化。

独立条件反证直接读取旧特征中的
`R_ind = -L_minus = -sum log(1-p_D)`。
只对有效未报求和，p_D 来自已冻结正常模型。它是正常报告模型下的异常评分，不是真假概率。

对 Count 尚未拒绝、且有追加拒绝资格的记录，在同父录制、五个精确 Count 输入 `(n_plus,n_minus,w,d,m)` 及相同采纳/拒绝资格内，比较真假 R_ind 的排序。每层 AUC 是假记录评分较大的加权概率，并列计半。跨层以两类全局质量较小者加权。本分析是已看过开发资料上的回顾性描述，不是因果识别、独立终测或新方法性能。

## 2. 观测条件确有额外排序信息，但作用不均匀

mixed 评价的共同计数层有 27 个，覆盖 5 个父录制。进入比较的是 523 条真记录、32 个真 query 生命周期，以及 272 条假记录、10 个注入实体。其质量只占全体真类的 4.48%、假类的 34.30%。

| 比较范围 | 条件反证 AUC | 解释边界 |
| --- | ---: | --- |
| mixed 评价，共同计数及资格层 | 0.823 | 支持该局部总体中条件信息超过计数 |
| 其中 F1/k2 | 0.999 | 不能单独证明与注入规律无关 |
| 其中 F2/k2 | 0.622 | 区分较弱，与 F1 明显不同 |
| F1_only 基础模型下评价 F2 | 0.627 | 两个父录制分别为 0.060、0.393，存在排序反转 |
| F2_only 基础模型下评价 F1 | 0.999 | 不能平均抵消另一方向的问题 |

表内后两行使用旧族迁移方案的 Count 剩余集合。p_D 并未重新训练，不应把它们解释成“正常模型从 F1 迁移到 F2”的单独实验。不同剩余集合也会影响比较。

mixed 校准集相同规则的 AUC 为 0.497，只剩 5 个共同层，假侧全是 F0/k1。评价集只有 F1/F2，因此不能把 0.497 与 0.823 的差异直接归为泛化改善或退化。F1_only 校准集没有剩余可追加拒绝假记录。F2_only 校准比较只有一个假实体，AUC 为 0.179。这些域差异必须保留。

**取舍**：保留观测条件建模。撤回“较大的条件反证已经能稳定解决剩余假目标”的推断。总体秩区分并不证明在 mixed 仅剩 0.6524 个百分点的新增校准误拒预算下仍有有效收益。

## 3. 当前追加拒绝设计实际能处理哪类问题

| mixed 评价原 Count 状态 | 条数 | 原类别加权占比 | 当前追加拒绝机制的能力 |
| --- | ---: | ---: | --- |
| 虚假已被采纳 | 3 | 假类 0.43% | 全部没有有效未报，R_ind=0，且无拒绝资格，无法修复 |
| 虚假处于未知 | 324 | 假类 40.86% | 全部具有追加拒绝资格，是实际可处理对象 |
| 真实已被拒绝 | 95 | 真类 0.60% | 固定基础拒绝不变，无法恢复 |
| 真实尚未拒绝且有拒绝资格 | 3374 | 真类 27.94% | 可能被新增反证误拒，必须计入代价 |

3 条误采纳来自同一 F2/k2 注入实体，不能称为 3 个独立攻击。代表记录的 Count 输入为 `(4,0,2,2,2)`，当前报告状态为 `(1,1,未知)`。它们证明该机制在这些输入上无从追加反证，不证明一切合法输入都无法区分真假。

旧保存输出中，Count 未知而 D_zero 拒绝的假记录为 278 条，占假类 34.32%。同时，Count 采纳而 D_zero 拒绝的真记录为 23 条，占真类 0.19%，Count 未知而 D_zero 拒绝的真记录为 426 条，占真类 3.26%。这说明旧条件评分确实产生过有效拒假与真实代价。它不是新叠加政策的结果，没有用旧 D 门限替代新预算，也没有据此宣布新机制有效。

**取舍**：假未知转拒绝本身有研究价值，但不能代替用户原本包含真假两侧的完整核验目标。当前只追加拒绝的结构不能增加真实采纳，也不能减轻基础模型已有误拒。因此撤下其完整主方案地位，保留为有限拒假候选。

## 4. 多车联合的实际作用范围与原叙事不同

这里检查的是既定几何分组和冻结 p_D 下，候选同帧模型是否可能改变条件反证。没有估计真实依赖、拟合 rho 或计算新判决。

在 mixed 评价的上述剩余可追加拒绝集合中：

| 类别 | 含联合可作用组的窗口 | 原类别加权占比 | 独立覆盖 |
| --- | ---: | ---: | --- |
| 真实 | 281 | 真类 1.88% | 5 个父录制 |
| 虚假 | 72 | 假类 9.20% | 1 个父录制、2 个注入实体 |

假侧只来自 `test/2021_08_23_21_07_10`，分别为 F1/k2、F2/k2 的两个注入实体。以上窗口全部包含同组报告与未报并存的情况，没有同组至少两份有效未报，包括没有“一份报告加两份未报”的混合组。

为避免只凭组名误判作用方向，另检查了候选混合分布的导数。记独立部分完整事件与仅报告事件概率为 A、B，共单调部分为 C、D，则
`Q(M=0 | P=1)=((1-rho)A+rho C)/((1-rho)B+rho D)`，
其对 rho 导数的符号由 `CB-AD` 决定，负对数反证的符号相反。

实际评价输入中，上述 281 条真和 72 条假窗口都含增强反证的组，没有减弱反证的组。因此这部分候选作用是增强报告分歧，而非共同漏报降权。不能把“mixed 组”普遍等同于增强反证，多来源、多未报时方向可以不同。

校准集不同。剩余真记录有 39 个窗口含减弱分量，其中 2 个含报告与多份未报混合；626 个含增强分量，二者可以重叠。剩余假记录没有联合可作用组。联合模型仍可能改变正常校准门限，所以不能拿评价组占比直接给完整重新校准算法的增益设上界。

此外，Count 已误拒的真记录中，评价有 2 个、校准有 147 个窗口含纯共同未报组。固定基础拒绝会跳过它们。这里只证明相关输入存在，尚未证明这些误拒由重复计数造成，或降权后必然恢复。

**取舍**：共同原因仍是合理研究问题，但当前几何分组在剩余评价假目标上的覆盖很集中，且作用类型与原“减少重复反证”动机不一致。不能用这批记录认领稳定联合收益，也不能据此判定整个数据集没有共同漏报。只追加拒绝的政策还阻断了检验“恢复已有真实误拒”的路径。

## 5. 一个必须正面处理的真实重叠例

示例不是从极端分数挑选。先取真假共同质量最大的剩余计数层，再取各类加权中位记录。父录制为 `test/2021_08_23_16_06_26`，两侧 Count 输入均为 `(20,10,10,3,2)`。

| 项目 | 真实记录 | F2/k2 假记录 |
| --- | ---: | ---: |
| 原 Count | 未知 | 未知 |
| 当前报告状态 | 1、1、0 | 1、1、0 |
| 窗口条件反证 R_ind | 17.6462 | 17.5057 |
| 未报的等效报告概率 | 0.8287 | 0.8263 |
| 原 D_zero | 拒绝 | 拒绝 |

等效概率为 `1-exp(L_minus/n_minus)`，不是单帧概率算术均值。真记录键为 `["ee0edf9ae0ad9a0b",273,61]`，假记录键为 `["ae08703103d4e897",155,95]`。

较大的独立反证在这两例上反而来自真实目标。这个共同层有 245 条真记录、5 个生命周期，以及 54 条假记录、2 个实体，层内 AUC 为 0.661。它说明真实漏报与假目标反证会重叠。单例不证明全部在线输入不可识别，但完整方法必须说明重叠时如何保留未知、如何计算真实代价，不能靠换概率名称解决。

## 6. 本轮完成的决定与后续设计范围

| 内容 | 本轮决定 | 依据 |
| --- | --- | --- |
| 候选真实性、报告/未报/未知事件、共同前端及近期窗口 | 保留 | 与原研究问题一致，不需要重建系统 |
| 正常条件 p_D 及单车条件证据 | 保留为研究核心与已有实现资产 | 固定计数后存在局部排序信息 |
| 固定 Count 后只追加拒绝 | 不作为完整主方案，保留有限候选 | 无法处理现有误采纳，且不能恢复已有误拒 |
| 同帧联合修正 | 保留假设，暂不认领第二贡献 | 假侧覆盖集中，方向与原动机存在偏差，尚无净收益证据 |
| 新评分、新 rho、新门限或更换分类器 | 本轮不实施 | 本轮结果不足以确定其净作用 |

后续需要设计的是**证据形成后再做三态判决的规则**，而非继续在已经冻结的拒绝后追加拒绝。该规则必须允许观测受限使负证据减弱，也允许条件良好而无报告使负证据增强。报告证据的重复性同样要处理。未知受控数量和无可信本车仍保留，不能通过恢复“最多一辆攻击车”或假定多数诚实来换取可识别性。

这是后续机制的必要要求，不是本轮已确定的新算法。它仍需明确正常概率与真实性判断之间的经验依据，以及重叠区域和信息不足时的处理。本轮不再用另一套未经支持的公式填补这一缺口。

目前可以对外表述的是：观测条件提供了局部增量信息，当前判决设计限制了可改善的错误类型，多车依赖增量尚未建立。不能表述为完整方法已定型、已达到论文标准，或问题只是数据量不足。
