2026-11-12。审查对象为[re1原文](../CC_re/re1.md)和[re2原文](../CC_re/re2.md)。原文保留，不作为已批准方案。本次核读当前方案、11月6日证据、MATE实际更新源码及相关原始论文，做两个针对新命题的有界算术检查，没有运行车辆实验、拟合参数或新增攻击。

结论：采纳对实际证据不足、连续更新缺失和公平对照的批评。保留在成熟MATE流程内研究依赖处理的组织方式。re2的负证据累计封顶、原因可信性、参数识别及停止条件尚有实质问题，不进入直接编码，不以其替换当前唯一方案。当前LLR也没有实测增量证据，不能因为候选存在错误就认定现有方法有效。

## 2. re2需要实质修正的地方

### 2.1 两来源支持不能在当前威胁模型下保证阻挡物真实

re2第51至58、106行的保证依赖至多一个攻击者及正常来源不误检。当前用户允许未知数量受控来源。两个攻击者能够支持同一假框，持续三帧不能改变这一点。接收方自身观测可作为有条件的本地证据，但需明确接收方受保护及传感器误差；不能与两个远端支持混作同一保证。

即使阻挡物真实，也不能证明其后目标真实，更不能保证框的位置、尺寸和遮挡关系都准确。因此F2是真实阻挡物后放假目标这一核心风险。不能让F1/F3通过就认定方法保持假目标风险，同时将F2风险上升简单归为局限。在未知受控数量范围下，F4也不能仅因失败不利就移到可选项。

### 2.2 n_eff是有条件的方差折算，不是通用真实性证据

对同方差且任意两观测相关系数均为rho的观测，

`Var(mean Y)=Var(Y)/n * [1+(n-1)*rho]`。

据此可定义均值估计的方差等效样本量`n/[1+(n-1)*rho]`。这并未证明MATE中的信任参数、时变置信度及真假似然比都服从同一折算。空间和时间不同的rho合并成一个数还需要模型条件。

[Ribatet、Cooley和Davison原文§1.2、§2](https://arxiv.org/html/0911.5357v2)从H、J矩阵推导复合似然估计方差和幅度/曲率调整，明确讨论渐近条件和两种调整的差异。它不直接给出re2中逐负PSM增量加上原生遗忘的等价定理。Godambe信息也不能无条件等同完整联合分布的Fisher信息。

re2第69行的`c_bar*n_eff`只在相同c等限制下直接成立。不同时间的c乘不同m_k，通常不等于普通平均c乘n_eff；普适上界只能先用c_max/rho等更明确的条件表达。第一份不打折也是设计选择，不是由上述论文自动推出。

### 2.3 只封顶负证据与原生遗忘并存，会形成错误采纳

这不是声称实际批次已经发生，而是对re2可允许输入的条件反例。

冻结来源信誉、保持候选身份，初始化alpha=beta=.5。每帧一份正PSM，confidence=.5，两份负PSM，各confidence=.8。令两负PSM的公开原因相同、C_hat=1/3，持续不中断，rho=.5。使用原回放dt=.1、dt_return=1，每次将alpha、beta按.9保留并向.5插值。原目标negativity_bias=1时实际w_pos=w_neg=.5，不能直接把confidence当完整增量。

VIS每帧正增量.25，负增量`.5*2*.8*(1-1/3)`。VIS+DAE每帧正增量仍.25，负增量改为`.5*.8*(1-1/3)*(n_eff(2t)-n_eff(2t-2))`。

| 同一输入，200帧 | 目标均值 | 原生.4采用线 |
| --- | ---: | --- |
| VIS | 0.33962264 | 未采用 |
| VIS+DAE-neg | 0.85712480 | 采用 |

解析极限为VIS的alpha=3、beta=5.833333，DAE的alpha=3、beta=.5。随着m_k趋于0，保留的旧负证据也被原生传播消退，而持续正证据仍进入。这种输入若对应F2中的假目标，便增加假采纳。原因真实不能排除这一输入。

这说明re2默认主方法的主要安全风险是结构性的。观察受限需要体现证据不足，不能只把负证据逐渐移除并让单源持续正报告将目标推向采纳。DAE-sym能否解决这一点仍未证明，其正簇与负簇定义、rho+估计、恢复和过期策略均未完整给出。

源码依据为`docs/evidence/association_topic_audit_2026_10_02/mate_sources/avstack-trust/avtrust/distributions.py:155-204`、`updater.py:160-172`和`propagator.py`中的PriorInterpolationPropagator。原11月6日回放脚本验证目标bias=1、dt_return=1及采用线.4。本次算例复用其更新代数，未冒称重新运行原生整个系统。

复算核心为：

```python
n_eff = lambda n: n/(1+(n-1)*.5) if n else 0.
a = b = ad = bd = .5
for t in range(1, 201):
    a = .9*a + .05 + .5*.5
    b = .9*b + .05 + .5*2*.8*(1-1/3)
    ad = .9*ad + .05 + .5*.5
    bd = .9*bd + .05 + .5*.8*(1-1/3)*(n_eff(2*t)-n_eff(2*t-2))
print(a/(a+b), ad/(ad+bd))
```

### 2.4 全漏报似然有界命题缺少关键条件

re2第102行将受限漏报率趋近1与持续帧数增加的极限混在一起。取两状态等权、q_blocked=.99、q_clear=.1，则

`P_T(all miss)=.5*.99^n+.5*.1^n`。

在假侧全未报概率为1时，真实/虚假log比在n为10、100、1000时分别约为-.794、-1.698、-10.743，继续趋于负无穷。q_blocked再接近1，只要小于1，也不能保证永久封顶。若q_blocked恰为1，正常侧前项可有有限极限，但完整比值还依赖假侧概率随n如何变化。

11月6日的完全共同Bernoulli反例属于指定的极端共同模型，不能推成所有持续遮挡下的一般定理。

### 2.5 负结果选簇使rho估计面临选择偏倚

re2第48行说只对负PSM建原因键，第88至89行又希望在该簇内估计负事件的相关性。按当前文字，进入簇的记录几乎全有y=1，无法用这个选择后的样本识别报告与未报的共同概率。

须先对全部有效观测机会定义原因与持续段，再读取报告/未报结果；明确在正报告时是否保留原因键、缺包和无PSM如何处理。不规则簇长、来源差异及按C分箱不充分也可能影响ICC。统计rho与物理遮挡因果强度不能混同。

### 2.6 阶段0停止规则不能支持其拟写结论

CI包含0表示当前精度下未能排除0，不证明依赖不存在。可以因此决定当前开发预算不继续，却不能记作已证明方向无效。

原因簇覆盖的原生未采用时间不是总体可改善量的严格上界。历史更新会影响簇外后续时刻，11月6日已经有当帧非双负而被连续修改恢复的例子。10%可作预先声明的投入判断，不能称理论上限。

轨迹和父录制配对统计值得保留。按父bootstrap仍须承认独立父很少、LOPO训练集重叠及可能路线相关；“至少100假轨迹”不是通用风险保证。若从已看过的全部录制轮换，只能称开发交叉验证。

### 2.7 三态、正常误检和对照口径仍不完整

re2任务卡承诺六格，主体却只沿用MATE的单采用阈值。原生未采用不等于明确拒绝或未知，必须定义输出政策后才能交付真假三态。

GT未匹配不能当作正常误检。原用户已明确不重新核验数据中的正常误检缺失，re2第135行不能直接执行；真实性核验也不要求区分一个不存在目标的恶意起因与自然起因。

固定原生阈值是合理的机制对照，但改变评分尺度后仍需同风险或阈值曲线补充，不能用一个固定工作点自动宣称安全性改善。UNI匹配总减弱量、VIS与DAE析因值得保留；VIS的c*(1-C_hat)仍是手设映射，而不是自动代表最佳单车条件对照。

## 3. 文献位置与创新边界

[MATE原文附录A.2](https://arxiv.org/html/2503.04954#A1.SS2)确有点云投影和射线式FOV区域。它不是目标条件报告概率，也不提供跨车或跨帧的独立性证明。

[SABER原文§3与§4.1](https://arxiv.org/html/2610.07875v1#S4.SS1)对缺报告要求发送方声明可见且消息可用，然后以agent–track对累积异常。re1写“接收方声明”应改为发送方声明。其来源级目标和本项目目标真实性指标不能混用。未看到显式共同原因折算，不等于已经完成全领域新颖性证明。

[TrustFlip/TrustReflect原文](https://arxiv.org/html/2605.22122v2#S4.SS6)研究物理诱发的不同视角不一致如何造成正常来源信任下降，并通过屏蔽局部不确定区域减轻问题。它比re1只看摘要的引用更接近“观测不确定导致错误惩罚”的动机。若方向A只做负证据减弱，需要说明相对这种局部不确定性处理的新增机制。本文威胁模型并非普通消息假目标注入，不能把它直接当re2的F2/F3既有复现。

[复合似然论文](https://arxiv.org/html/0911.5357v2)支持研究依赖修正，但不能替代当前事件、信任参数与动态更新之间的推导。Conformal Risk Control控制可交换条件下的期望损失，见[官方说明](https://github.com/aangelopoulos/conformal-risk/blob/main/README.md)，不是给少量父录制加一个名称即可取得一般攻击保证。

## 4. 采用与不采用的决定

采纳：复用成熟回放，连续目标级评价，分离单车条件与依赖处理，保留UNI、VIS等有辨别力的对照，真实收益与假目标代价同报。当前主问题和双侧证据不变。

暂不采纳：永久负证据封顶作为主公式、两来源支持作为未知攻击者数量下的真实性保证、将53降0归因为时间依赖更强、将统计不显著等同不存在依赖、用正常GT未匹配构造误检标签，以及把F2安全失败从主要决策中排除。

候选下一项应是修正动态证据的语义。要求正负双方有一致的过期/重复处理定义；几何受限时进入未知，而非仅降低拒绝；原因的可信条件不偷换受控数量假设；理论先在声明模型下正确，再决定是否用ESS式折算。上述是修订要求，不是已经选定的新算法。

当前实际C批次仍按原授权保留，优先复用完成部分并补完中断后的既定比较，用于判断现有条件输入及联合候选，不因外部文字评价直接丢弃，也不追加同eval调参。此决定不表示当前LLR优于修订后的动态候选。
