# re5的MCS方案审查与取舍

2026-11-13。类型为外部设计审查、条件数学反例及单个冻结样例的分数重算。原文[re5](../CC_re/re5.md)保留，不执行其中禁止方法审查、限定按天安排或结果如何都结束实验的条款。用户当前要求是评价设计并决定怎样修订。

结论为不按原规格实施MCS，不将其设为下一主方法。可以保留复用缓存、固定对照和有界结束条件的组织建议。两帧支持是可单独比较的政策，但本轮不并入主要评分修改。此结论不表示所有最小集合或复合假设方法都无价值。

## 1. 有用的提醒与尚未证明的归因

re5正确提醒：本项目排除正常误报假目标，因此诚实来源在假目标上的支持不能继续由任意报告率描述。但来源身份未知，不能直接把每份未报都当作诚实来源的未报。首轮s敏感性说明参考依赖较强，不能独自证明所有真实采用损失均由盲区沉默正分造成。

MCS保留原四族攻击参考及s，又添加epsilon和pi。它没有消除参考假设，只把一部分作用转移到受控集合选择与数量惩罚。

## 2. 已复算的关键问题

证据为[计算脚本](../evidence/re5_math_review_2026_11_13/check_mcs.py)和[结果](../evidence/re5_math_review_2026_11_13/results.json)。脚本调用冻结kernel的false_window，忠实枚举re5子集公式；没有拟合、校准或改动研究产物。独立审核另行用纯内存计算确认前两项及逐帧分解问题。

### 2.1 最大惩罚解释不是规范的假侧分布

单来源单帧，epsilon=.001、pi=.1。原四族初始报告率为.225。MCS对未报告取值.999，对报告取值.0225，两者之和1.0215。因此不能把该包络直接当作规范的P(U|假)。

它可以作为惩罚式轮廓评分，经独立校准比较。非归一化不自动否定一个评分方法，但必须撤回原概率语义，也不能直接继承原预测概率分解。若改为归一化子集先验求和，仍需声明攻击数量分布，不能宣称已经无假侧假设。

### 2.2 epsilon为正时，全沉默非正命题不成立

两来源十帧全未报，正常每次报告概率p=.0001，epsilon=.001、pi=.1。最优子集为空，总分为

`20 * log(.9999/.999) = +.0180099067`。

该反例只否定“任意p下全沉默分数永不为正”的命题。全沉默仍不具备双支持采纳资格，不能由此声称它会造成假采纳。使用epsilon=0可处理当前范围内诚实来源不报假的假设，但它是范围假设，不是从无样本数据估得的参数。

re5建议在fit/clean且query_truth=0条件下估epsilon。当前fit清单只有6个clean、0个attack任务，且当前范围已排除正常误报假目标；该测量定义不能提供所声称的诚实来源误支持率。不再重新盘点自然误检，未知GT匹配也不能补成该类负样本。

### 2.3 pi偏好少受控，并可能显著抬高多源假报告分数

pi=.1使每增加一个受控来源，假侧解释被惩罚2.302585 nat。它没有硬性限定多数诚实，但引入了少受控来源的偏好。m_star是这一惩罚准则的最优集合大小，不能称为逻辑上至少需要的攻击者数量；epsilon为正时，空受控集合对任何报告组合都有非零解释。

对首轮唯一假采纳样例`cf2ad1a17529d018 / frame117 / id185`，实际U为`[1,1,1,0,-1]`。保持已冻结的正常侧似然不变：

| 假侧 | 假侧log分数 | 未校准J分数 |
| --- | ---: | ---: |
| 原Q_F | -4.471951 | 2.210307 |
| MCS，pi=.1、epsilon=.001 | -9.593334 | 7.331689 |

MCS选择前三个报告源为受控，数量惩罚把此例的真实性分数提高5.121382。pi取.3/.1/.03时，该例分数分别为4.035852、7.331689、10.943608，m_star仍为3。

这些是固定正常侧下的评分计算，不是重新校准后的错误率，不能断言MCS最终一定更差。但这足以说明该首窗例子的风险没有被MCS分数直接降低；两帧门控会按定义阻止该帧采纳，不能把它当成MCS识别改善。

### 2.4 整窗最优子集不能原样沿用当前steps

该真实样例的选中子集与诚实部分逐帧loglik之和为-2.685578，MCS整窗log分数为-9.593334，差值为3log(.1)=-6.907755。直接返回原false_window的steps会漏掉数量惩罚。原kernel的Jind/G依赖逐帧分解，因此会与J比较不一致。惩罚若显式加入，必须单列，不能归为依赖修正。

另有前缀`[[1,0]]`选择S={0}，完整窗口`[[1,0],[1,1]]`选择S={0,1}。按整窗S回溯，第二来源首帧的q从.001变为.225。终点评分没有读终点以后的数据，但回溯q已不是原来的观测前预测概率。MCS可以定义其他合法的整窗评分分解，原文目前没有完成这项定义。

## 3. 实验裁决不能按原文执行

1. 两帧支持统一施加于各方法，可以作为公平政策比较。但P3对一帧样例按定义成立，只是政策回归检查，不能证明MCS有效。若失败应修实现，不应看过结果后把门槛改成三帧。
2. P2只要求原20.18个百分点真采纳差距缩小5个百分点，仍容许约15.18个百分点差距，放宽了旧5个百分点容差。它还混合了政策变化与评分变化，应在同一政策下比较。
3. P4不要求联合超过简单条件、独立时序和组平均，因此整套方案可能通过而核心联合贡献仍不成立。原真误拒、假误采、未知和时延约束不能丢失。
4. P2失败不能直接定性为政策价格，P1失败也不能否定所有声明参考路线。都需要比当前证据更强的归因。
5. 表中3×3固定s网格已经9点，再加两个s点是11个MCS配置；若主epsilon实测值不在网格中还会增加。1145秒来自首轮五套配置，不是五个方法。复合枚举也不能直接沿用旧耗时估算。这些是次要实施错误，不是拒绝原方案的主要依据。

有限结束条件应约束当前批次，不能预先决定无论效果如何都足够写成方法贡献。研究叙事应由有效结果决定。

## 4. 主会话采用的修订

继续[真假侧方法取舍](../REALLY_MAYBE/真假侧问题_方法取舍与落实边界_2026-11-13.md)，不引入MCS、epsilon或pi。将原建议具体化为7系数可分解的判别头，未报直接项非正，联合项独立比较；明确fit训练攻击、父录制折外特征、固定偏置增量拟合与原政策。具体公式及实现边界见该文末节。

方法依据仍为正常报告概率建模及两类监督评分与独立校准，[Tong等2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC5804623/)支持该处理形式，不证明本项目收益。任意未知攻击的保证仍受[已有不可辨识边界](未知受控数量下多源支持的推断边界_2026-11-06.md)限制。当前替代候选尚未实施，不能因为MCS有缺陷就宣称它一定有效。
