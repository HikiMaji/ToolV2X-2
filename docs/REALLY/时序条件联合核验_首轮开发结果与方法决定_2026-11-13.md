# 时序条件联合核验首轮开发结果与方法决定

2026-11-13。实验事实与本批方法决定。冻结算法549e86f，证据目录为[run_001](../evidence/rq1_temporal_2026_11_12/run_001)。

**本轮已经完成。统计独立重计通过，时序模型有局部收益，联合项有小幅点估计增量，但完整方案未通过原定保留条件。不能汇报为整体优于MATE，也不能把联合机制写成已成立的论文贡献。**

## 1. 实际范围

14个已经使用过的开发父录制，6 fit、5 cal、3 eval，实际涉及3、4、5车。旧39任务加4个正常任务与27个新攻击尝试，共70任务。55个完成，15个因预定几何条件无法构造。没有任务运行错误。

总计136572条候选记录，不是136572个独立样本。eval主真6519条，来自3父99个轨迹epoch；主假531条，来自3父11个epoch。未知标签不冒充假目标，算法未知完整保留在主分母。

新增27攻击中12个实际回放，8个产生明确假目标query。F3假遮挡框污染的9个配置全部UNREALIZABLE，不能提供该类防御效果。所有多受控eval假层来自同一个父录制。F1/k1、F2/k2在cal缺少主假样本。没有形成query、标签不明确和未能构造分别记录，均不计作核验成功。

J相对T的正确明确率增加0.6436个百分点，真采纳增加0.2456个百分点，假拒绝增加1.0417个百分点，真拒绝也增加0.1582个百分点。J相对G的正确明确率增加0.7687个百分点。J/T/G都有22/99条主真epoch从未采纳，已采纳者延迟中位数相同。

J相对同政策MATE的真采纳减少20.1760个百分点，超过原定5个百分点损失容差。F1/k3假采纳为1/45，即2.2222%，MATE为0，点差已超过2个百分点容差。J有1/11条主假epoch曾误采纳，MATE为0/11。

所以，J比MATE高12.27个百分点的正确明确率主要伴随更多明确拒假，不能掩盖真实采用损失及假采纳风险。未知与拒绝在当前周期都不输出目标，明确拒绝增加不自动等于系统安全性增加。

原始计数与分级比例分开。例如J真拒绝417/6519，原始比例6.40%，分级比例4.89%；5%工作点只对应预声明的分级口径。

## 3. 参数与敏感性说明问题在哪里

23824条clean fit输入提供41330份有效单源监督，各组件均可估，没有优化失败或数值失败。rho=.9，fit折外正常窗口NLL从4.973373降到4.948439，约0.5%，主要改善来自一个父录制。eval正常NLL反为J4.323033、T4.321800，不能把fit似然改善当成判决收益。

冻结主分数的事后分解还显示，同政策MATE采纳、J未采纳的真目标加权质量为21.65个百分点，其中19.94个百分点转为未知，1.70个百分点转为拒绝。约11.05个百分点的J分数非正，10.59个百分点为正但低于A。该差异不是资格不同造成的。

唯一假采纳发生在F1/k3的首个核验窗口，窗口仅1帧、3个支持来源、4个有效来源，J=2.2103超过A=1.1531。它是多源初始证据问题的具体实例，不能用后续能够拒绝把这次误采抹去。未在本轮添加暖启动门控或修改初始化。

另用冻结主分数生成了[事后风险与覆盖图](../evidence/rq1_temporal_2026_11_12/execution_2026_11_13/operating_curves_posthoc.png)。只在cal取0/1/2/5/10%预算门限，再评eval；5%六格与主结果精确复现，未选择新的主工作点。这些点上MATE的采用权衡仍更好，不能简单归因于5%门限恰巧选坏了。

## 4. 本批方法决定

1. 保留冻结代码、D/T/J/G和全部正负结果。T保留为时序研究底座，J保留为待改进候选；撤下整体优于MATE及联合贡献已经成立的主张。
2. 不再追加联合算子。当前主要问题是采用分数的解释、假侧持续性参考的影响，以及观测条件经回波代理传递后未表现出预期作用。
3. 不将C代理模块作为已证实必要组件，不把s=.5换成主参数。下轮最小修订及未决假设另记[修订重点](../REALLY_MAYBE/时序核验首轮后_修订重点_2026-11-13.md)，不写成已实施效果。
4. 新攻击失败属于本批覆盖限制。后续若修订构造器，必须在新批次中先固定合法条件，不能按防御得分挑位置；不用默认扩数据或重训练替代上述方法问题。

三父bootstrap只作描述，J-T区间为正，J-G区间跨0；它们不能支持普遍非劣性。特别是多控假层各仅一父一epoch，无法证明2个百分点风险上界。
