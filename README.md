## 版本如何使用

| 版本 | 角色 |
| --- | --- |
| D_zero，数值实现b0572cd | 原研究机制的结构起点；直接条件证据、完整评分后作三态判断 |
| D_old | 检查只未报来源常数约束的代价 |
| Count、Count+Cond | 计数及有限条件反证效果对照 |
| Local、LocalCount、LocalCond | 使用可信接收车输入时的共同信息对照 |
| 旧J、J_zero、Joint及分组采纳修正 | 历史比较，未恢复为已有效主方法 |

当前没有确定新联合机制。恢复完整评分、重新加入正报告公式均不构成新的有效性依据；C/F采纳修补仍是未实施备选，已撤回近期优先推荐。用户允许可信接收车并要求保留远端采纳，这些授权保持，但不能把新增可信输入的收益归因于依赖建模。

## 已完成结果

- [D_zero额外六段评价](docs/REALLY/汇报前完整实验_结果与方法决定_2026-11-13.md)：mixed假采纳5.40%，其中F2/k2为21.59%；反向迁移真采纳损失5.12个百分点。完整保留条件未通过。
- [独立条件反证](docs/REALLY/独立条件核验_开发结果与保留决定_2026-11-17.md)：原六段取得有限效用，后续追加资料暴露采纳风险。
- [同边际联合比较](docs/REALLY/同边际联合核验_结果与采纳风险_2026-11-17.md)：联合评价增量及正常预测未改善，未保留Joint。
- [可信接收车比较](docs/REALLY/可信接收车核验_开发结果与远端采纳缺口_2026-11-17.md)：同本地信息下条件反证有增益，完整风险未通过。
- [远端采纳分组校准](docs/REALLY/远端采纳分组校准_开发结果与停止条件_2026-11-17.md)：mixed误采3.22%降至1.82%，真采纳64.47%降至62.51%，逐层风险或采用代价仍未全部达标。

各轮数据范围、政策和对照不同，不能把百分比直接串成持续提升曲线。已有数值独立复核不等于研究创新成立。旧正负结果均保留，不因选择D_zero起点而重判旧失败。

## 代码与复现边界

D_zero在`scripts/rq1_score_revision/no_miss_constant.py`；条件反证在`scripts/rq1_independent_supplement.py`；可信本地对照在`scripts/rq1_trusted_receiver/`。对应规格、运行绑定、审核和小型统计产物位于`docs/REALLY_MAYBE/`和`docs/evidence/`。

本仓库提供代码、配置、选定参数、结果报告、图表和审查记录。原始数据、完整点云、逐帧事件/特征/预测及运行环境仍在主服务器，异地仅凭Git快照不能完整重跑。保存的绝对路径属于服务器执行来源，不能当成异地可直接使用的路径。

后续协作以本分支为准，`research/rq1-current-2026-11-12`是历史快照。进入任务前按AGENTS.md阅读经验教训、当前方案、最新要求与状态；新实验需有具体改动、数据范围和结束条件，不自动恢复已结束批次。
